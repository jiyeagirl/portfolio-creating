# welllog - Product Spec

## 1. Overview

welllog는 Apple Health, Google Fit 데이터를 자동으로 연동하고, 음식 사진 한
장으로 칼로리를 계산해주는 습관 기반 헬스케어 앱이다.

기존 진단형 헬스케어 앱과 달리, 매일 아침 생성되는 리듬 카드로 오늘의 컨디션을
가볍게 기록하고 친구와 함께 완주율을 채워가는 리듬 챌린지를 통해 지속 가능한
건강 습관을 만드는 저널형 UX로 기획했다. 민감한 개인 건강정보를 다루는 서비스
특성을 고려해 데이터 암호화와 안전한 DB 구조를 설계했고, 2차 고도화(구독 및
커머스)를 대비한 유연한 회원, 상품 DB 아키텍처를 사전에 반영했다. 사용자가 입력
부담 없이 자신의 건강 리듬을 자연스럽게 들여다볼 수 있는 경험을 제공하는 것을
목표로 한다.

- **플랫폼**: 모바일 앱(iOS, Android)
- **포지셔닝**: 진단, 수치 중심 헬스케어 앱과 달리 리듬 카드와 챌린지로
  건강 습관을 저널링하는 습관 기반 헬스케어 서비스
- **제작 목적**: 포트폴리오용 고품질 UI 목업. 실제 Health 연동, Vision AI
  음식 인식, 백엔드는 구현하지 않으며 mock 데이터로 화면 완성도를 우선한다.

## 2. Non-goals

- 실제 Apple Health, Google Fit API 연동
- 실제 사진 기반 음식 인식, 칼로리 계산 Vision AI 모델
- 실제 푸시 알림 발송 및 친구 초대, 응원 실시간 통신
- 실제 구독, 커머스 결제 로직

## 3. Information Architecture

1. **온보딩 및 헬스 데이터 연동** 서비스 핵심 가치 전달, 권한 연결이 목적,
   Apple Health, Google Fit 연동, 알림 권한 설정, 건강 목표 선택, 닉네임 및
   프로필 생성

   포인트: "오늘부터 건강을 기록해보세요" 메시지, Health 연동 CTA 강조

2. **홈, 리듬 카드** 메인 화면이자 프로젝트 대표 화면, 오늘의 리듬 카드,
   수면, 걸음, 활동 자동 표시, 오늘 컨디션 한 줄 기록, 오늘의 습관 체크,
   오늘의 AI 제안

3. **식단 기록(Vision AI)** : 사진 촬영, 음식 자동 인식, 칼로리 계산, 영양소
   표시, 검색으로 직접 입력. 포트폴리오에서 AI 기능이라 가장 임팩트 있는
   화면이다.

4. **리듬 챌린지(친구와 함께)** : 친구 초대, 완주율 표시, 오늘 체크, 남은
   일수, 응원 보내기. 순위 대신 완주율(Completion Rate)이 강조되도록
   구성한다.

5. **리포트(주간 트렌드)** : 주간 활동, 평균 수면, 운동량 변화, 식단 점수,
   AI 요약. 그래프 중심 화면이다.

6. **리듬 히스토리(캘린더)** : 날짜별 기록, 감정, 활동, 식단, 메모. 저널 UX가
   잘 드러나는 화면이다.

7. **알림(제안형 넛지)** : AI 추천, 운동 알림, 수분 섭취, 챌린지 리마인드.
   경고 느낌보다 따뜻한 카드 UI로 구성한다.

8. **마이페이지 및 건강 프로필** : 연동 상태, 목표 수정, 개인정보, 앱 설정,
   Health 연결 관리

핵심 화면은 2. 홈, 리듬 카드이며, 이 프로젝트의 대표 화면이다.

## 4. Key Focus

- 매일 아침 생성되는 리듬 카드로 수면, 걸음, 활동 데이터를 가볍게 확인하고
  기록하는 저널형 홈 경험 설계
- 진단, 수치 중심이 아닌 오늘 컨디션 한 줄 기록과 AI 제안으로 부담 없이
  건강 리듬을 들여다보는 경험 제공
- 음식 사진 한 장으로 칼로리, 영양소를 자동 계산해 식단 기록의 입력 장벽을
  낮춘 Vision AI 기능
- 순위 경쟁이 아닌 완주율 중심의 리듬 챌린지로 친구와 함께 지속 가능한
  습관을 만드는 경험 설계
- 민감한 개인 건강정보를 다루는 서비스 특성에 맞춘 데이터 암호화, 안전한
  DB 구조와 구독, 커머스 확장을 고려한 유연한 아키텍처 반영
