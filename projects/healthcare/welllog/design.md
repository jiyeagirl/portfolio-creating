# welllog — Design Notes

## 적용 규칙

- `스타일:` / `디자인시스템:` 지정이 spec.md에 없다 → `design-taste-frontend`(v2)의 판단에
  맡긴다. 이 스킬은 대시보드/관리자 UI는 범위 밖이라 명시하지만 welllog는 모바일 소비자
  앱(랜딩/포트폴리오형 화면과 동일한 판단 축)이라 이번에는 스킬의 다이얼과 안티-슬롭
  규칙이 그대로 적용 대상이다.
  - `DESIGN_VARIANCE 6 / MOTION_INTENSITY 5 / VISUAL_DENSITY 3` — 저널형 습관 앱이라
    진단 대시보드처럼 촘촘하게 채우지 않고(밀도 낮음), 리듬 카드/챌린지 화면은 카드
    비대칭 배치를 일부 허용하되(variance 중간), 모션은 감정을 상하지 않는 절제된 수준.
  - 프리미엄 소비자 palette ban 체크: 베이지+브라스+오브록스 조합을 쓰지 않았다(아래
    참조). Warm Cream 계열이지만 세이지 그린 액센트로 가족을 분리했다.
- 플랫폼이 모바일 앱(iOS, Android)이므로 `components/shared/phone-frame.tsx`(iPhone 16
  Pro, 393×852) 프레임을 그대로 쓴다. `components/shared/screen-header.tsx`(뒤로가기 +
  상태바 회피용 `pt-[59px]`)와 `components/shared/toggle.tsx`를 직접 import해서 재사용하고
  새로 만들지 않는다.
- `_reference-design-system.md`/`_reference-styles/`(filmate)는 색상 출처로 쓰지 않았다
  (필름 카메라 앱의 다크/앰버 톤은 웰니스 저널과 무관). 구조적으로는 filmate의 스프링
  모션 철학(화면 진입 `x:32→0` + fade, stiffness 300/damping 30, `prefers-reduced-motion`
  존중)과 8px 스페이싱 그리드, iPhone 16 Pro 캔버스(393×852, top 59pt/bottom 34pt 세이프
  에어리어)만 재사용했다.
- 같은 healthcare 카테고리인 `habitkong`과 색을 겹치지 않게 분리했다. habitkong은
  그레이-크림 캔버스 + 오렌지 마스코트 포인트인 반면, welllog는 세이지그린 톤(자연/호흡/
  성장 연상)을 단일 액센트로 쓰고 캔버스도 더 그린빛이 도는 아이보리로 다르게 잡았다.
  마스코트 캐릭터는 spec.md에 없어 만들지 않는다 — 사진(리듬 카드 배경, 식단 사진)과
  타이포로 저널 무드를 낸다.
- Badge/Button/Card/ProgressRing/EmptyState는 habitkong/orderlog와 이름이 같아 보여도
  톤 어휘/radius 문법/프레스 피드백이 다른 이 프로젝트만의 컴포넌트로 새로 만들었다
  (`components/ui.tsx`, `components/shared/*`에 두지 않음).

## Tokens / 팔레트 (`styles/welllog.css`, `.welllog` 스코프)

| --- | --- | --- | --- |
| 캔버스 | `--wl-canvas` | `#F6F9F3` | 화면 배경 (세이지빛 아이보리) |
| 서페이스 | `--wl-surface` | `#FFFFFF` | 카드, 시트 |
| 서페이스(연) | `--wl-surface-soft` | `#EEF3EA` | 보조 블록, 비활성 칩 |
| 잉크 | `--wl-ink` | `#22271F` | 주요 텍스트 |
| 본문 | `--wl-body` | `#5B6355` | 본문, 설명 |
| 보조 | `--wl-mute` | `#8B9284` | 캡션, 플레이스홀더 |
| 헤어라인 | `--wl-hairline` | `#E3E8DE` | 구분선 |
| 액센트(세이지) | `--wl-accent` | `#4F7D5D` | 버튼, 활성 탭, 링크, 링 강조 |
| 액센트(연) | `--wl-accent-soft` | `#E1EEE3` | 선택 배경, 태그 |
| 액센트(짙) | `--wl-accent-deep` | `#33573F` | hover, 강조 텍스트 |

리듬 카드 전용 히어로 그라디언트(액센트 규칙의 예외 — 오직 홈 화면의 "오늘의 리듬 카드"
배경 한 곳에만 사용, 다른 UI 요소로 번지지 않는다): `--wl-dawn-a` `#4F7D5D` →
`--wl-dawn-b` `#F4C089`(잔잔한 새벽빛 살구색). 세이지에서 살구로 흐르는 대각선
그라디언트로 "아침 리듬"을 표현한다.

상태/태그 톤(장식이 아니라 완주/주의/수면 같은 실제 의미를 나타내는 기능색, 5단계 고정):

| 톤 | 색 | 쓰이는 곳 |
| --- | --- | --- |
| `neutral` | `--wl-surface-soft` 위 `--wl-mute` | 기록 전, 비활성 |
| `sage`(기본/완료) | `--wl-accent-soft` 위 `--wl-accent-deep` | 완주, 기록 완료, 목표 달성 |
| `amber` | `#FBEFD7` 위 `#8A6B1F` | 주의, 넛지 알림, 리마인드 |
| `coral` | `#FCE3D6` 위 `#B85C33` | 챌린지 연속 기록(스트릭), 활력 |
| `periwinkle` | `#E3E7FB` 위 `#4B57A6` | 수면 데이터 전용 태그 |

3-링(수면/걸음/활동)은 각각 `periwinkle`, `--wl-accent`, `coral`을 고정 매핑해 Apple
Health류 활동 링과 동일한 문법(3색 고정, 링마다 색이 바뀌지 않음)을 지킨다.

## Shape

- 반경 3단계만 쓴다: 버튼/칩/태그/아바타 = `9999px`(pill), 카드/시트/모달 = `20px`(부드러운
  저널 카드 느낌 — habitkong의 12px, orderlog의 10px보다 한 단계 더 소프트), 인풋/작은
  타일 = `14px`.
- 그림자는 아주 옅은 2단 스택만(`--wl-shadow`): `0 1px 2px rgba(34,39,31,.04),
  0 10px 24px rgba(34,39,31,.06)`. 리듬 카드에만 살짝 더 진한 `--wl-shadow-pop` 허용.
- 폰트 굵기 천장 700(리듬 카드 헤드라인, 온보딩 타이틀만 700, 나머지는 600 이하).

## Typography

Pretendard 고정. 진단형 수치 앱이 아니라 저널형이라 Display를 한 단계 낮추고 Body 위주로
설계했다:

| Role | Size / Line | Weight | 용도 |
| --- | --- | --- | --- |
| Display | 26 / 32 | 700 | 리듬 카드 인사말, 온보딩 히어로 |
| Title | 19 / 26 | 600 | 섹션 타이틀, 카드 제목 |
| Body | 15 / 22 | 400 | 본문, 설명 |
| Label | 13 / 18 | 500 | 칩, 버튼, 폼 라벨 |
| Caption | 11 / 15 | 500 | 타임스탬프, 보조 정보 |

걸음/칼로리/수면 시간 등 숫자는 `.wl-num`(Pretendard 그대로, `font-feature-settings:
"tnum"`)으로 자릿수만 정렬한다 — orderlog처럼 모노스페이스로 폰트를 바꾸지 않는다(금융
수치가 아니라 건강 수치라 같은 서체 안에서 정렬만 맞추는 쪽이 더 부드럽다).

## 기기 프레임 안쪽 규칙

- `PhoneFrame` 클리핑(`overflow-hidden` + `rounded-[50px]`)을 지키기 위해 하단 탭바와
  상단 헤더는 항상 불투명 서페이스(`bg-[var(--wl-surface)]`)를 쓰고 `backdrop-blur`는
  기기 화면 경계에 걸치는 요소에 절대 쓰지 않는다.
- 탭바, 리듬 카드 상단 인사 헤더 모두 `absolute`로 화면 안쪽에 고정하고 화면 밖으로
  튀어나오는 `fixed`/음수 오프셋을 쓰지 않는다.
- 캡처 전 하단 모서리(홈 인디케이터 주변)에 흰 테두리가 새지 않는지 확인한다.

## Motion

- `MOTION_INTENSITY 5`: 화면 진입은 filmate 철학 재사용(`opacity + x:32→0`, spring
  stiffness 300/damping 30). 탭 전환은 즉시 스왑(과한 슬라이드 없음 — 습관 앱은 반복
  사용성이 중요해 탭마다 무거운 전환을 넣지 않는다).
- 3-링(수면/걸음/활동)은 진입 시 0→목표% 로 `stroke-dashoffset` 애니메이션(600ms
  ease-out), 리듬 카드는 로드시 은은한 페이드만.
- 식단 기록의 "AI 분석 중" 로더만 예외적으로 무한 루프 펄스를 쓴다(실제 처리 중 상태를
  의미하므로). `prefers-reduced-motion`에서는 모든 링 애니메이션이 즉시 목표값으로,
  펄스는 정적 스피너로 대체된다.

## 화면 구성

핵심 화면(대표)은 2. 홈/리듬 카드. 하단 탭 5개(홈/식단/챌린지/리포트/마이페이지)로
구성하고, 리듬 히스토리(캘린더)와 알림은 habitkong의 `FULLSCREEN` 패턴과 동일하게 탭이
아니라 홈 상단 아이콘에서 진입하는 뒤로가기 화면으로 뺐다(spec.md 8개 화면 중 탭 5 +
풀스크린 3: 온보딩/히스토리/알림).
