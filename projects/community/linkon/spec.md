# LinkON — Product Spec

## 1. Overview

LinkON(링크온)은 창업지원기관의 **선정기업·입주기업만 참여 가능한 회원 인증 기반
폐쇄형 네트워킹 커뮤니티 플랫폼**이다.

- **슬로건**: 검증된 창업기업만 연결되는 네트워크
- **플랫폼**: 웹 (반응형, 데스크톱 1920/1440, 태블릿 1024, 모바일 393 대응)
- **사용자**: 선정·입주기업 담당자 (운영기관 관리자는 별도 서비스인 LinkON 운영 콘솔 사용)
- **가명 처리**: 회원 기업은 `A테크`, `B소재`처럼 알파벳 기반 가명을 쓴다. 기관명,
  인물명, 사업자등록번호, 연락처도 모두 실존 대상과 무관한 가상 데이터다.
- **로고**: 기업 로고는 도형 마크(shape + 브랜드 컬러)로 생성하고, 기업 소개 사진은
  내용을 확인한 고정 id의 사진만 사용한다.
- **제작 목적**: 포트폴리오용 고품질 UI 목업. 실제 인증/결제/실시간 채팅/파일 업로드
  백엔드는 구현하지 않으며 내부 state 기반 mock 데이터로 화면 완성도를 우선한다.

## 2. Non-goals

- 실제 사업자등록번호 조회 API, OAuth(카카오/네이버) 실연동, 실시간 소켓 채팅
- 파일 업로드 스토리지, 이메일 발송, 권한 기반 실제 인가 처리
- 딥링크 가능한 하위 라우트 (모든 화면 전환은 `src/index.tsx` 내부 state로 처리)

## 3. Information Architecture

단일 URL(`/community/linkon`) 안에서 아래 화면을 내부 상태로 전환한다.

1. **기업 인증 가입** — 3스텝 온보딩
   - Step 1 회원가입: 이메일 가입, 카카오/네이버 로그인, 비밀번호 설정, 약관 동의
   - Step 2 기업 인증: 사업자등록번호 입력 → 기업명 자동 조회, 소속 창업지원기관 선택,
     선정사업(입주기업/지원사업) 선택, 인증서류(PDF·이미지) 업로드, 담당자 정보 입력
   - Step 3 가입 완료: 인증 심사 진행 상태, 승인 예상 안내, 승인 후 이용 안내
2. **홈** — 사용자·기업 정보, 알림, 검색, 메인 배너(지원사업/네트워킹 행사/공지),
   추천 기업(관심 분야 기반·최근 가입), 최신 커뮤니티(인기 게시글·최근 질문·협업 모집),
   일정(신청한 행사·예정 프로그램), 빠른 메뉴
3. **회원 기업 찾기** — 기업명·대표자명 검색, 필터(산업 분야/지역/기업 규모/창업 연차/
   투자 여부/관심 분야/협업 가능 여부), 기업 리스트
4. **기업 상세** — 기업 소개, 보유 기술, 진행 프로젝트, 모집 중인 협업, 관심 기업 등록,
   채팅하기, 프로필 공유
5. **기업 채팅** — 채팅방 목록(최근 대화·안 읽은 메시지), 텍스트/이미지/파일 전송,
   명함(PDF)·기업 소개 카드·프로젝트 제안서 공유, 기업 프로필 바로가기, 대화 검색,
   신고·차단
6. **네트워킹 피드** — 피드 작성(텍스트/이미지/태그/협업 모집 설정), 좋아요·댓글·저장·
   공유, 카테고리(협업 모집/투자 이야기/창업 후기/정부지원사업/행사 후기), 추천(인기·관심 분야)
7. **정보게시판** — 카테고리(지원사업/공지사항/투자 정보/교육 프로그램/창업 자료실),
   제목·태그·기간 검색, 게시글 상세(첨부파일/조회수/댓글/북마크)
8. **멘토 Q&A** — 질문 등록(제목/내용/카테고리/파일), 카테고리(투자/법률/특허/마케팅/
   세무/정부지원사업), 질문 상세(멘토 답변·추가 질문·채택·좋아요), 멘토 프로필

운영기관 관리자 화면은 이 서비스에 포함하지 않는다. 창업기업 계정이 운영 권한을 가진
것처럼 보이지 않도록 `projects/community/linkon-admin/` (`/community/linkon-admin`)로
완전히 분리했다.
