# Waypoint - Product Spec

## 1. Overview
- 플랫폼: Mobile App (사용자, Android/iOS) + Web (관리자 백오피스)
- 포지셔닝: '동네'가 아닌 집과 직장을 모두 인증한 '출퇴근 동선'을 기준으로 매칭하는 하이퍼로컬 안전 중고거래 플랫폼. 듀얼 위치 인증, 인앱 보안 채팅, 웨이스팟(안전 거래 장소) 지정을 통해 장거리 출퇴근 환경에서도 쉽고 안전하게 거래할 수 있도록 설계
- 제작 목적: 포트폴리오용 UI 목업, 백엔드 미구현 (동선 매칭 알고리즘, 실시간 채팅 서버, 위치 인증 로직은 목업 데이터로 표현)

## 2. Non-goals
- 실제 GPS 기반 위치 인증 및 반경 검증 로직 구현
- 실제 SIM/PASS 본인인증 연동
- 실제 대중교통 노선 API 연동 및 동선 매칭 엔진 구현
- 실제 실시간 1:1 채팅 서버(웹소켓 등) 구현
- 실제 신고/제재 처리 및 계정 정지 백엔드 로직
- 실제 푸시 알림 발송

## 3. Information Architecture

### 사용자 App
1. 온보딩 (6단계): [스플래시 화면] 앱 로고 및 브랜드 아이덴티티, 자동 로그인 여부 확인, 위치/GPS 권한 체크, 앱 버전 검사 및 업데이트 안내 · [간편 소셜 로그인] 카카오/Apple/Google 로그인, 이용약관 및 개인정보 동의, 기존 회원 자동 로그인 · [휴대폰 본인인증] PASS/SMS 본인인증, SIM 기반 실명 인증, 중복 계정 가입 방지, 인증 완료 후 신뢰 계정 생성 · [집 동네 GPS 인증] 현재 위치 기반 GPS 인증, 지도에서 위치 확인, 인증 반경 표시, 집 위치 등록 완료 · [직장 동네 GPS 인증] 회사 위치 GPS 인증, 지도에서 회사 위치 확인, 인증 반경 확인, 집/회사 듀얼 인증 완료 · [출퇴근 경로 등록] 출발지/도착지 설정, 대중교통 경로 등록, 자주 이용하는 노선 선택, 출퇴근 시간대 설정, 동선 기반 추천 활성화
2. 홈 (2가지): [내 동네 홈 — 집 주변 거래 중심] 우리 동네 인기 상품, 카테고리별 상품 탐색, 거리순 정렬, 검색, 관심상품 등록, 최근 본 상품, 우리 동네 인증 상태 표시 · [내 동선 홈 — 출퇴근 경로 기반 추천, ★핵심 차별점] 출퇴근 노선 기반 추천 상품, 지하철역/버스정류장 기준 상품 노출, 오늘의 추천 거래, 거래 가능 예상 시간 표시, 웨이스팟 거래 가능 상품 표시, 지도 기반 동선 보기
3. 웨이스팟 설정: 지도에서 거래 장소 선택, 추천 웨이스팟 자동 제안(지하철역/편의점/카페/스터디카페), 즐겨찾기 웨이스팟 저장, 안전도(혼잡도) 표시, 거래 가능 시간 확인, 상대방과 웨이스팟 공유
4. 인앱 채팅: [채팅 목록] 진행 중 거래 리스트, 안 읽은 메시지 표시, 거래 상태(거래중/예약중/거래완료), 상대 신뢰지수 표시, 최근 대화 시간 · [채팅 상세, ★웨이스팟 공유 Floating Button 강조] 실시간 1:1 채팅, 사진 전송, 거래 일정 조율, 웨이스팟 공유, 웨이스팟 위치 바로 보내기, 지도 열기, 거래 완료 요청, 신고하기, 차단하기, 개인정보(전화번호) 노출 차단
5. 마이페이지: [프로필] 프로필 사진, 닉네임, 듀얼 인증 완료 배지 · [신뢰지수] 신뢰 점수, 거래 성공 횟수, 거래 후기, 시간 약속 준수율, 응답률 · [안심거래] 본인인증 상태, 집 인증, 회사 인증, 최근 로그인 기기, 차단 사용자 관리 · [기타] 관심상품, 판매내역, 구매내역, 설정

### 관리자 Web
6. 관리자 대시보드: [대시보드] 전체 회원 수, 오늘 가입자, 거래 건수, 신고 현황, 차단 회원 수 · [회원 관리] 회원 조회, 신뢰지수 조회, 계정 정지, 본인인증 상태 확인 · [게시글 관리] 상품 삭제, 허위매물 숨김, 신고 게시글 검토 · [신고 관리] 신고 내역 조회, 신고 처리, 제재 이력 · [운영 관리] 푸시 알림 발송, 공지사항 등록, 웨이스팟 관리

## 4. Key Focus
- '내 동선 홈'을 Waypoint의 핵심 차별점으로 가장 강조 — 단순 거리순이 아닌 출퇴근 노선/역·정류장 기준으로 상품이 노출되는 구조를 시각적으로 부각해, 동네 기반 중고거래 앱과의 차이를 명확히 전달
- 온보딩의 듀얼 GPS 인증(집+회사) 플로우를 순차적으로 강조해, 가입 단계부터 신뢰 기반 거래 환경을 구축하고 있음을 전달
- 채팅 상세 화면에서 웨이스팟 공유 버튼을 Floating Button으로 크게 배치해, "연락처 노출 없이 안전한 장소로 바로 이동"하는 핵심 UX를 한눈에 보이게 강조
- 마이페이지의 신뢰지수·안심거래 섹션을 통해 단순 프로필이 아닌 거래 신뢰도를 수치화·시각화한 안전 생태계임을 부각
- 관리자 백오피스의 신고 관리·게시글 관리 화면을 통해 사기·허위매물에 대한 실시간 대응 체계가 갖춰진 운영 구조임을 강조

## 5. 관리자 분리

관리자 백오피스는 사용자 앱과 별도 프로젝트 `community/waypoint-admin`(URL: `/community/waypoint-admin`)으로 분리한다. 화면 코드는 이 프로젝트의 `components/admin/` 아래에 두고, `waypoint-admin`은 별도 로그인/URL을 갖기 위한 얇은 엔트리로만 존재한다. 사용자 앱에는 관리자 진입점(내비 항목, 로그인 역할 선택지)을 두지 않는다. 색상/타이포 토큰은 `waypoint-admin`에 따로 두지 않고 본 프로젝트 `styles/waypoint.css`를 그대로 상속한다.
