# LOCLY — Product Spec

## 1. Overview

LOCLY(로클리)는 지역 주민들이 생활 정보와 동네 소식을 공유하고, 주민과 지자체가
직접 소통할 수 있는 주민 참여형 지역 커뮤니티 플랫폼이다.

- **슬로건**: 우리 지역의 모든 이야기가 연결되는 공간
- **플랫폼**: 웹 (반응형, 데스크톱 1920/1440, 태블릿 1024, 모바일 393 대응)
- **배경 지역 설정**: 서울특별시 마포구 연남동 — 실제감 있는 목업 콘텐츠 생성을 위한
  가상의 배경 무대. 실존 상호/인물과 무관한 가상의 이름과 데이터를 사용한다.
- **포지셔닝**: 당근마켓의 동네 밀착감 + 네이버 카페의 게시판 커뮤니티 + 지자체
  공식 채널을 하나의 플랫폼으로 통합한 지역 허브
- **제작 목적**: 포트폴리오용 고품질 UI 목업. 실제 인증/결제/지도 API·백엔드는
  구현하지 않으며 내부 state 기반 mock 데이터로 화면 완성도를 우선한다.

## 2. Non-goals

- 실제 회원 인증, 실시간 채팅, 지도 API 연동
- 실제 결제/후원 로직
- 딥링크 가능한 하위 라우트 (모든 화면 전환은 `src/index.tsx` 내부 state로 처리)

## 3. Information Architecture

단일 URL(`/community/locly`) 안에서 아래 화면을 내부 상태로 전환한다.

1. **홈** — 오늘의 소식, 인기 게시글, 이번 주 지역 행사, 베스트 맛집/가게, 모집 중인
   모임, 최근 질문, 공지사항
2. **커뮤니티** — 게시판 탭(자유/동네소식/질문/맛집추천/생활꿀팁/육아/반려동물/
   분실물/벼룩시장/모임후기), 게시글 목록, 글쓰기, 게시글 상세(댓글/대댓글/좋아요/
   북마크/신고/해시태그)
3. **지역 행사** — 목록/캘린더 보기, 공식(구청) 배지, 행사 상세(참가 신청/후기)
4. **동네 가게** — 카테고리 필터, 가게 목록, 가게 상세(정보/후기/별점/즐겨찾기/
   이벤트)
5. **모임** — 모임 목록/개설, 모임 상세(참가 신청/정원/후기)
6. **주민참여** — 정책 제안, 설문/투표, 처리 현황 타임라인
7. **통합 검색** — 게시글/행사/모임/가게/사용자 통합 검색, 최근·인기 검색어
8. **알림** — 활동 알림 목록
9. **마이페이지** — 내 게시글/댓글/북마크/활동내역, 관심 지역·카테고리, 알림 설정
10. **관리자** — 회원/게시글/신고/행사 승인/가게 승인/후기/주민참여/통계 관리
    (상단 유틸리티 바의 "관리자 모드" 진입점을 통해 접근하는 별도 운영 화면)
