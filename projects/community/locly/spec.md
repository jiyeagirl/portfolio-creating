# LOCLY — Product Spec

## 1. Overview

LOCLY(로클리)는 지역 주민들이 생활 정보와 동네 소식을 공유하고, 주민과 지자체가
직접 소통할 수 있는 주민 참여형 지역 커뮤니티 플랫폼이다.

- **슬로건**: 우리 지역의 모든 이야기가 연결되는 공간
- **플랫폼**: 웹 (반응형, 데스크톱 1920/1440, 태블릿 1024, 모바일 393 대응)
- **배경 지역 설정**: "나인시 나인구 나인동" — 실제 지역을 특정할 수 없도록 가명 처리한
  가상의 배경 무대. 실존 지역·상호·인물과 무관한 가상의 이름과 데이터를 사용한다.
- **포지셔닝**: 당근마켓의 동네 밀착감 + 네이버 카페의 게시판 커뮤니티 + 지자체
  공식 채널을 하나의 플랫폼으로 통합한 지역 허브
- **제작 목적**: 포트폴리오용 고품질 UI 목업. 실제 인증/결제/지도 API·백엔드는
  구현하지 않으며 내부 state 기반 mock 데이터로 화면 완성도를 우선한다.

## 2. Non-goals

- 실제 회원 인증, 실시간 채팅, 지도 API 연동
- 실제 결제/후원 로직
- 딥링크 가능한 하위 라우트 (모든 화면 전환은 `src/index.tsx` 내부 state로 처리)

## 3. 디자인 시스템

이 프로젝트의 UI는 워크스페이스 루트의 **`design-systems/claude_design_compact.md`** 를 따른다.
색·타이포·간격·라운드·컴포넌트 스펙은 모두 그 문서의 토큰을 출처로 하며, 프로젝트
스코프 CSS 변수(`styles/locly.css`)로 옮겨 사용한다. 적용 방식과 프로젝트 고유의
해석·예외는 `design.md`에 정리한다.

핵심 원칙 요약:

- **크림 캔버스**(`#faf9f5`)가 기본 바닥. 순백/쿨그레이 금지.
- **코랄**(`#cc785c`)은 주요 CTA와 full-bleed 코랄 콜아웃에만. 남발 금지.
- **다크 네이비**(`#181715`) 표면으로 밴드 리듬을 만든다
  (크림 → 크림카드 → 다크 → 크림 → 코랄 → 다크푸터).
- **서체는 Pretendard 하나**. `claude.md`에서 가져오는 것은 서체가 아니라 스타일이며,
  워크스페이스 `CLAUDE.md`의 Pretendard 고정 규칙이 언제나 우선한다. 디스플레이와
  본문의 구분은 서체가 아니라 크기·굵기·자간으로 만든다.
- 섹션 리듬 96px, 카드 내부 패딩 32px, 라운드 8/12/16px 위계.

## 4. Information Architecture

단일 URL(`/community/locly`) 안에서 아래 화면을 내부 상태로 전환한다. 이 프로젝트는
**주민용 웹사이트만** 담는다.

### 4.1 주민용 웹사이트 (`components/site/`)

1. **홈** — 오늘의 소식, 인기 게시글, 이번 주 지역 행사, 베스트 맛집/가게, 모집 중인
   모임, 최근 질문, 공지사항
2. **커뮤니티** — 게시판 탭(자유/동네소식/질문/맛집추천/생활꿀팁/육아/반려동물/
   분실물/벼룩시장/모임후기), 게시글 목록, 글쓰기, 게시글 상세(댓글/대댓글/좋아요/
   북마크/신고/해시태그)
3. **지역 행사** — 목록/캘린더 보기, 공식(구청) 배지, 행사 상세(참가 신청/후기)
4. **동네 가게** — 카테고리 필터, 가게 목록, 가게 상세(정보/후기/별점/즐겨찾기/
   이벤트)
5. **모임** — 모임 목록/개설, 모임 상세(참가 신청/정원/후기)
6. **주민참여** — 정책 제안, 설문/투표, 처리 현황 타임라인
7. **통합 검색** — 게시글/행사/모임/가게/사용자 통합 검색, 최근·인기 검색어
8. **알림** — 활동 알림 목록
9. **마이페이지** — 내 게시글/댓글/북마크/활동내역, 관심 지역·카테고리, 알림 설정

### 4.2 관리자 콘솔은 별도 프로젝트

운영자용 화면은 이 프로젝트에 없다. `projects/community/locly-admin/`
(`/community/locly-admin`)로 완전히 분리했고, 상세 IA는 그쪽 `spec.md`에 있다.
주민용 화면에는 상단 네비게이션에도 푸터에도 **관리자 진입점을 두지 않는다** —
실제 서비스와 마찬가지로 주소와 계정이 다르다.

콘솔은 이 프로젝트의 `lib/`·`styles/`·`components/site/ui.tsx`를 가져다 쓰지만,
반대 방향 의존은 만들지 않는다.

## 5. 스타일

`스타일:` 라인으로 지정된 스타일-변형 스킬은 없다. 대신 위 3항의
`design-systems/claude_design_compact.md`를 디자인 소스로 삼고, 워크스페이스 `CLAUDE.md`의
UI Generation Rules를 함께 적용한다.
