# LinkON 운영 콘솔 — Product Spec

## 1. Overview

LinkON 운영 콘솔은 창업지원기관 담당자만 사용하는 **별도 관리자 서비스**다. 회원 기업이
쓰는 [LinkON](../linkon/spec.md)과 화면·URL·로그인 주체를 완전히 분리한다.

- **URL**: `/community/linkon-admin` (회원용 서비스는 `/community/linkon`)
- **사용자**: 운영기관 담당자 (예: 나인창업지원재단 심유라 운영자)
- **분리 이유**: 회원용 화면에 관리자 진입점이 있으면 창업기업 계정이 운영 권한을 가진
  것처럼 읽힌다. 실제 서비스와 마찬가지로 관리자는 별도 주소와 별도 계정으로 접근한다.

## 2. 공유 자원

같은 제품군이므로 아래는 `projects/community/linkon/`에서 그대로 가져다 쓴다. 데이터
정의를 두 벌로 복제하지 않기 위한 의도적인 의존이다.

- `lib/mock-data.ts`, `lib/types.ts` — 회원·기업·행사·신고 등 운영 데이터
- `components/layout/ui.tsx` — 배지, 버튼, 통계 타일 등 공통 프리미티브
- `styles/linkon.css` — 색상·타이포 토큰 (`.linkon` 스코프)

관리자 전용 컴포넌트(`components/admin-*.tsx`)는 이 폴더 안에만 둔다.

## 3. Information Architecture

좌측 사이드 내비게이션으로 전환되는 7개 영역.

1. **대시보드** — 전체 회원 수, 승인 대기, 신규 가입, 성사된 협업, 일간 활성 사용자,
   커뮤니티 현황, 승인 대기 목록, 최근 가입·협업 요청
2. **회원·기업 관리** — 검색, 상태 필터, 승인/반려, 권한 변경, 계정 비활성화, 상세 드로어
3. **인증 서류 관리** — 사업자등록증·선정 증빙·기관 정보 확인, 승인 / 보완 요청 /
   반려(사유 입력)
4. **행사·프로그램** — 행사 등록, 모집 인원 조정, 신청자·참석 관리, 프로그램 일정과
   공지 발송
5. **기업 네트워크** — 협업 요청 내역, 기업 간 연결 현황, 매칭 통계
6. **커뮤니티 관리** — 게시글·댓글 관리, 신고 처리
7. **운영 통계** — DAU/MAU, 네트워킹 참여율, 산업 분야별 가입, 인기 기업·게시글

## 4. Non-goals

- 실제 인가·감사 로그, 권한 그룹 관리
- 회원용 화면으로 이동하는 링크 (두 서비스는 서로 진입점을 두지 않는다)

## 5. 스타일

`스타일:` / `디자인시스템:` 지정 없음. 회원용 LinkON과 같은 토큰을 쓰되 밀도만
`VISUAL_DENSITY: 7` 수준으로 올린다.
