# VeriWed - Product Spec

## 1. Overview
- 플랫폼: Mobile App (사용자, Android/iOS)
- 포지셔닝: "결제한 사람만 말할 수 있다"는 원칙으로, 영수증/계약서 인증을 거친 예비부부만 리뷰를 남길 수 있는 스드메(스튜디오/드레스/메이크업) 결제 인증 기반 웨딩업체 리뷰 커머스 플랫폼
- 제작 목적: 포트폴리오용 UI 목업, 백엔드 미구현 (OCR 자동 추출, 관리자 검수, AI 자동 답변, 실결제가 집계는 목업 데이터로 표현)

## 2. Non-goals
- 실제 OCR 기반 영수증/계약서 정보 자동 추출 로직
- 실제 관리자 검수 워크플로우 및 승인/반려 처리 백엔드
- 실제 OpenAI API 연동 AI 자동 답변 생성
- 실제 업체 결제/예약 처리 및 PG 연동
- 실제 실시간 랭킹 집계 알고리즘

## 3. Information Architecture

### 사용자 App
1. 홈 화면 (업체 탐색 & 실시간 랭킹): 지역/예식일 기반 업체 추천, 스드메 카테고리 선택(스튜디오/드레스/메이크업), 실시간 인기 업체 랭킹, 평점 + 리뷰 개수 표시, 평균 실결제가 표시, 최근 등록된 인증 리뷰 미리보기, 검색창, 추천 기획전(가성비 업체/인기 업체 등), AI Q&A 바로가기
2. 업체 상세 / 결제 인증 리뷰: 업체 기본 정보, 평균 평점, 항목별 평점(친절도/가격 만족도/결과물 만족도/사후 대응), 실제 계약 금액(실결제가), 계약 구성(패키지 포함 항목), 옵션 추가 비용, 결제 인증 여부 배지, 인증 리뷰 목록, 사진 리뷰, 업체 비교 추가, 북마크
3. 탐색 화면 (검색·필터·업체 비교): 검색, 지역 필터, 예산 필터, 카테고리 필터, 평점 필터, 실결제가 범위 필터, 정렬(인기순/평점순/실결제가 낮은 순/리뷰 많은 순), 업체 비교 선택, 비교하기 버튼 / [업체 비교 화면] 업체 최대 3개 비교, 평균 평점 비교, 실결제가 비교, 패키지 구성 비교, 옵션 가격 비교, 후기 개수 비교, 저장
4. 영수증·계약서 인증 업로드: 영수증 업로드, 계약서 업로드, OCR 자동 정보 추출, 업체 자동 인식, 계약 금액 확인, 계약일 입력, 개인정보 마스킹 안내, 인증 신청, 검수 진행 상태(접수/검수중/승인/반려), 반려 사유 확인, 재업로드
5. 커뮤니티 (질문·정보 공유): 질문 작성, 카테고리(스튜디오/드레스/메이크업/예식 준비), AI 자동 답변, 사용자 답변, 좋아요, 댓글, 인기 게시글, 최신 게시글, 검색
6. 리뷰 (결제 인증 리뷰 모아보기): 인증 리뷰만 보기, 카테고리별 리뷰, 업체별 리뷰, 실결제가 공개, 계약 구성 표시, 사진 리뷰, 항목별 평점, 후기 검색, 정렬(최신순/평점순/실결제가 낮은 순), 도움이 돼요, 신고하기
7. 마이페이지: [내 인증 관리] 인증 진행 현황, 승인된 업체, 반려 내역, 재인증 / [내 리뷰 관리] 작성 리뷰, 임시 저장, 수정, 삭제 / [관심 업체] 북마크 목록, 비교함 / [활동 내역] 작성 게시글, 작성 댓글, 좋아요한 글 / [고객센터] 1:1 문의, FAQ, 공지사항 / [계정 관리] 개인정보 수정, 로그아웃, 회원탈퇴

## 4. Key Focus
- 영수증·계약서 인증 업로드부터 검수 진행 상태(접수/검수중/승인/반려)까지 이어지는 인증 플로우를 강조해, "결제한 사람만 리뷰를 쓸 수 있다"는 핵심 신뢰 구조를 시각적으로 전달
- 업체 상세 화면에서 결제 인증 여부 배지와 실결제가, 항목별 평점을 함께 노출해 업체가 숨기는 정보 비대칭을 해소하는 UX임을 부각
- 업체 비교 화면(최대 3개, 실결제가·패키지 구성·옵션 가격 비교)을 통해 예비부부가 계약 전 합리적으로 의사결정할 수 있는 정량 비교 경험을 강조
- 커뮤니티의 AI 자동 답변 기능을 통해 서비스 초기에도 콘텐츠 공백 없이 유저가 체류할 수 있는 구조임을 시각적으로 전달
