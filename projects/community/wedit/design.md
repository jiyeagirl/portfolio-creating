# VeriWed (wedit) — Design Notes

## 적용 규칙

- `스타일: high-end-visual-design` (spec.md 지정) + 워크스페이스 `CLAUDE.md`의 UI Generation Rules.
- 타이포는 CLAUDE.md가 최우선이라 Pretendard 고정. 스킬이 제안하는 Geist/Clash Display 등
  프리미엄 웹폰트는 쓰지 않는다. spacing도 8px 그리드(CLAUDE.md)를 따르고, 스킬의
  `py-24~40` 같은 랜딩페이지 전용 수치는 적용하지 않는다 — 이 프로젝트는 모바일 앱 화면이라
  스킬의 히어로/내비/마퀴 규칙 대부분은 해당 없음. 가져온 것은 톤: 더블베젤(외곽 셸 + 이너
  코어) 카드 구조, 스프링 물리 모션, 절제된 그라디언트, "저가형 AI 카드 그리드" 회피.
- `spec.md` 1행 "컬러: 핑크색 사용" 지정 → 팔레트 최우선 출처는 이 지정이며, 톤은
  `design-taste-frontend`(v2)의 4.2 색상 캘리브레이션 기준(채도 80% 미만, 원 팔레트 락)을
  따라 절제된 로즈 톤 하나로 설계했다. baby-pink/파스텔 핑크가 아니라 신뢰감 있는 딥 로즈 —
  "결제 인증"이라는 이 서비스의 핵심 개념과 어울리는 무게감을 위해서다.
- 디자인시스템 문서(`design-systems/`)는 지정 없음이라 미적용.
- `DESIGN_VARIANCE 7 / MOTION_INTENSITY 5 / VISUAL_DENSITY 4` — 프리미엄 컨슈머 프리셋에
  가깝게 잡았다. 결제 인증/검수 상태 등 신뢰가 중요한 화면은 밀도를 낮추고 여백을 넉넉히 뒀다.

## Tokens / 팔레트

컴포넌트 스코프 CSS 변수(`.wedit` 클래스 내부), 워크스페이스 전역 토큰은 건드리지 않는다.

| Token | Value | 용도 |
|---|---|---|
| `--wd-canvas` | `#FFF8F9` | 앱 배경 (거의 화이트, 아주 옅은 블러쉬) |
| `--wd-surface` | `#FFFFFF` | 카드/시트 표면 |
| `--wd-surface-tint` | `#FFF1F4` | 강조 카드, 히어로 배경 (인증 배지, 랭킹 1위 카드 등) |
| `--wd-ink` | `#241019` | 주요 텍스트 (와인 빛이 도는 웜 블랙) |
| `--wd-body` | `#5C4650` | 본문 텍스트 |
| `--wd-muted` | `#9A828C` | 보조 텍스트, 캡션 |
| `--wd-border` | `#F2DEE3` | 미세한 구분선 |
| `--wd-accent` | `#B23A6E` | 프라이머리 액센트 — CTA, 선택 상태, 브랜드 포인트 (유일한 액센트) |
| `--wd-accent-strong` | `#8C2A54` | 액센트 프레스 상태, 진한 텍스트 강조 |
| `--wd-accent-soft` | `#F7DCE6` | 칩/배지 배경, 선택되지 않은 강조 영역 |

**상태 배지(검수 진행 상태)는 브랜드 액센트와 별도의 시맨틱 세트**를 쓴다. 4단계
(접수/검수중/승인/반려)를 구분하려면 로즈 하나로는 판별이 안 되기 때문 — habitkong의
파스텔 상태색 선례와 같은 이유:

| 상태 | 텍스트 | 배경 |
|---|---|---|
| 접수 | `#6B7280` | `#F1F2F4` |
| 검수중 | `#92650B` | `#FDF1DA` |
| 승인 | `#1F6C4E` | `#E4F5EC` |
| 반려 | `#9F2F2D` | `#FDEBEC` |

컬러 락: 브랜드 액센트는 로즈 하나로 페이지 전체에서 고정한다. 상태 배지 4색은 검수
플로우 배지에서만 등장하고 CTA/내비/브랜드 요소에는 쓰지 않는다.

## Shape

- 카드 16px, 히어로/배지 카드는 20px. 버튼은 `rounded-full`(필) — 하이엔드 스킬의
  "Island Button" 구조를 따라 CTA는 필 형태 + 내부 트레일링 아이콘은 별도 원형 wrapper.
  입력 필드 12px.
- 더블베젤: 업체 히어로 카드, 인증 배지 카드는 아우터 셸(`p-1.5`, `bg-white/60`,
  `ring-1 ring-[var(--wd-border)]`, `rounded-[20px]`) + 이너 코어(자체 배경,
  `rounded-[16px]`, `shadow-[inset_0_1px_0_rgba(255,255,255,0.6)]`) 2겹 구조.
  나머지 리스트형 카드(업체 리스트, 리뷰 카드)는 단일 레이어 + 1px 보더로 절제.
- 그림자는 항상 `--wd-accent`를 틴트한 로즈 계열(`rgba(178,58,110,0.08~0.14)`), 순수 블랙
  그림자 금지.

## Typography

- Pretendard 고정. Display 28/34 700, Title1 20/26 700, Title2 17/22 600,
  Body 14.5/21 400, Callout 13/18 500, Caption 11.5/16 500.
- 실결제가, 평점, 날짜, 리뷰 개수는 전부 `tabular-nums`.
- 중간점(·)/em dash(—) 금지 — 콤마/슬래시/파이프로 대체(CLAUDE.md 규칙).

## 기기 프레임 안쪽 규칙

하단 탭바(`bottom-nav.tsx`), 업체 상세의 플로팅 CTA 바, 스크롤 상단 `ScreenHeader`는
전부 불투명 서페이스(`bg-white` 또는 `var(--wd-surface)`)이며 `backdrop-blur`를 쓰지
않는다 — `PhoneFrame`의 `rounded-[50px]` 클립을 뚫고 모서리에 흰 틈이 새는 반복 버그
때문(CLAUDE.md "Device edge integrity"). 엣지 고정 요소는 전부 화면 박스 안쪽
`absolute`(음수 offset 없음), `fixed` 미사용.

## Motion

- 화면 전환: `x: 24→0` + fade, 스프링(`stiffness 300, damping 30`) — filmate 레퍼런스
  구조값 재사용.
- 인증 진행 상태 스텝퍼는 단계 전환 시 체크마크가 `scale 0.8→1` 스프링 팝인.
- 랭킹 리스트 진입 시 `translate-y-8→0` + fade 스태거(`delay 0.05 * index`), `viewport
  once: true`.
- CTA 버튼 프레스: `active:scale-[0.97]`.
- `prefers-reduced-motion` 존중(워크스페이스 전역 CSS에 이미 정의됨).
