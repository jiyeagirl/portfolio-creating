# Enclave - Product Spec

## 1. Overview
- 플랫폼: Mobile App (사용자, Android/iOS) + Web (관리자 백오피스)
- 포지셔닝: 아파트/오피스텔 입주민 인증을 기반으로, 같은 단지 사람들끼리만 안전하게 거래하고 무인택배함으로 비대면 픽업까지 가능한 하이퍼로컬 중고거래 플랫폼
- 제작 목적: 포트폴리오용 UI 목업, 백엔드 미구현 (단지 인증 검증, 실시간 채팅, 무인택배함 연동은 목업 데이터로 표현)

## 2. Non-goals
- 실제 단지/주소 인증(등본, 관리비 고지서 등) 검증 로직
- 실제 무인택배함 하드웨어 연동 및 QR/인증번호 발급 시스템
- 실제 실시간 1:1 채팅 서버(웹소켓 등) 구현
- 실제 신고 처리 및 계정 정지 백엔드 로직
- 실제 이웃평판 산정 알고리즘

## 3. Information Architecture

### 사용자 App
1. 로그인 / 회원가입: 이메일·소셜 로그인, 회원가입 및 약관 동의, 휴대폰 본인인증, 자동 로그인
2. 단지 인증: 아파트/오피스텔 검색, 단지 선택 및 인증 진행, 인증 상태 표시(인증 완료/대기), 인증 완료 후 서비스 이용 안내
3. 프로필 설정: 프로필 사진 등록, 닉네임 및 자기소개 설정, 관심 카테고리 선택, 거래 가능 시간 설정
4. 홈 (중고거래 메인): 단지 내 최신 게시글 조회, 인기 상품 노출, 카테고리별 상품 목록, 판매 상태(판매중/예약중/거래완료) 표시, 상품 등록 버튼
5. 탐색 (검색): 상품명 검색, 카테고리 필터, 가격 범위 필터, 정렬(최신순/가격순), 우리 단지 거래만 보기
6. 채팅: 판매자/구매자 실시간 채팅, 거래 제안 및 가격 협의, 이미지 전송, 거래 예약 상태 변경, 거래 완료 버튼
7. 무인택배함 픽업: 무인택배함 선택, 보관함 번호 확인, QR/인증번호 생성, 픽업 상태 확인, 거래 완료 처리
8. 마이페이지: 내 판매/구매 내역, 찜 목록, 이웃평판 및 후기 조회, 신고 내역 조회, 프로필 수정 및 로그아웃

### 관리자 Web
9. 관리자 대시보드: 전체 회원 수, 신규 가입 현황, 거래 건수 통계, 거래 완료율, 신고 접수 현황, 단지별 이용 현황, 최근 신고 리스트, 주요 운영 지표(Dashboard Chart)
10. 회원·신고 관리 (★운영자가 가장 많이 사용하는 화면): 회원 목록 조회, 회원 검색 및 필터, 단지 인증 상태 확인, 신고 내역 조회, 신고 처리(경고/정지), 계정 활성화·비활성화, 이웃평판 및 신고 이력 확인
11. 단지 및 게시글 관리 (★Enclave 핵심 차별점): 단지 등록/수정/삭제, 단지 인증 요청 승인, 게시글 조회, 게시글 숨김 및 삭제, 카테고리 관리, 공지사항 등록, 신고 게시글 검수

## 4. Key Focus
- 단지 인증부터 홈 진입, 거래, 무인택배함 픽업까지 이어지는 흐름을 "같은 단지 사람들끼리만 만나는" 신뢰 기반 여정 중심으로 강조
- 무인택배함 픽업 화면을 통해 직접 대면 없이도 안전하게 거래를 완료할 수 있는 비대면 거래 프로세스를 시각적으로 부각
- 관리자의 단지 및 게시글 관리 화면을 Enclave의 핵심 차별점으로 강조 — 단지 인증 승인 운영이 실제로 어떻게 이루어지는지 보여줘 다른 중고거래 서비스와의 차이를 명확히 전달
- 회원·신고 관리 화면을 "운영자가 가장 많이 쓰는 화면"으로 부각해, 단순 기능 나열이 아닌 실제 운영 관점에서 설계된 백오피스임을 강조
- 마이페이지의 이웃평판·후기 조회를 통해 단지 인증만으로 끝나지 않고 거래 이력 기반 신뢰가 축적되는 구조임을 전달
