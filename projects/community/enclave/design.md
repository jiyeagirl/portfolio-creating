# Enclave — Design Documentation

## 적용 규칙

- 스타일: `high-end-visual-design` (spec.md 지정) — Double-Bezel(아우터 셸+이너 코어) 카드 구조와 스프링 모션, 필-버튼 CTA는 그대로 가져오되, 이 워크스페이스에서 이미 같은 스킬로 만든 `waypoint`/`wedit`와 겹치지 않도록 Double-Bezel은 화면당 핵심 순간(단지 인증 완료, 무인택배함 픽업 코드) 한 곳에만 절제해서 쓴다. 나머지는 아파트 우편함/인터폰 패널을 연상시키는 하드라인 + 탭형 정보구조로 차별화한다. 폰트/기기프레임/8px 그리드는 워크스페이스 CLAUDE.md 규칙(Pretendard, iPhone 16 Pro, 단일 기기, 흰 배경)이 항상 우선.
- 디자인시스템: 미지정 — `design-systems/`는 참조하지 않음.
- `design-taste-frontend`(v2)는 배경 원칙으로만 참고 — em dash 금지, 실제 이름/데이터, 사진 소싱 우선순위(생성 도구 없으면 손으로 확인한 picsum id), 색상 채도 절제(80% 미만) 원칙만 차용한다. 랜딩페이지 전용 규칙(히어로/네비/마퀴)은 이 프로젝트(모바일 프로덕트 UI)에 해당 없음.
- **컬러 방향 결정 배경**: 사용자가 "여태까지 안 했던 디자인"과 "waypoint가 파랑이니 파랑 말고"를 명시. 현재 워크스페이스 기존 액센트를 조사한 결과 — `waypoint` 코발트 블루, `linkon` 딥 틸(청록), `locly` 코랄+다크네이비 에디토리얼, `wedit` 딥 로즈, `filmate` 필름 앰버. Enclave는 이 중 어느 것과도 겹치지 않는 **모스/파인 그린**(청록이 아닌 황록 계열, 실제 아파트 단지 안내판·조경에서 흔히 쓰는 톤)을 단일 액센트로 선택했다. `linkon`의 틸과는 색상환에서 확실히 구분되는 방향(블루 방향 vs 옐로 방향)으로 채도도 낮춰 겹치지 않게 했다.
- `DESIGN_VARIANCE: 6` / `MOTION_INTENSITY: 5` / `VISUAL_DENSITY: 6`(회원 화면) · `7`(관리자 화면) — 입주민 인증·신고 처리 등 행정적 정보가 많은 서비스라 waypoint(4)보다 밀도를 한 단계 높였다. 수치는 `tabular-nums`.
- 관리자 분리: 관리자 콘솔은 별도 프로젝트 `community/enclave-admin`(URL `/community/enclave-admin`)이다. 화면 코드는 이 프로젝트의 `components/admin/`에 있고, 토큰(`styles/enclave.css`)을 그대로 상속한다. `enclave-admin`에는 별도 `styles/`·`design.md`를 두지 않는다. 사용자 앱 쪽에는 관리자 진입점을 두지 않는다.
- 목업 내 표시 기간: 2025.03 ~ 2025.06 (가입일, 게시글 등록일, 채팅 타임스탬프, 신고 접수일, 공지/운영 로그 전부 이 구간 내 날짜만 사용).
- **신뢰 지표 네이밍**: "매너온도"는 당근마켓 고유 기능명이라 사용하지 않는다. Enclave는 **"이웃평판"**(0~100점, `점` 단위)을 쓴다. `lib/types.ts`의 `Resident.reputationScore` / `AdminMember.reputationScore`, `components/ui.tsx`의 `ReputationBar`가 이 이름을 따른다.
- **아바타**: 이웃마다 다른 이니셜 모노그램을 쓰면 화면마다 매번 다른 "가입 아바타"처럼 보여 어색하다. `components/ui.tsx`의 `Avatar`는 실제 사진 대신 **단일 캐릭터(Phosphor `UserCircle`)로 통일**하고, `tone`(accent=나, neutral=상대)만으로 구분한다.

| `--ec-border` | `#DDE3D9` | 헤어라인 |

| `--ec-ink` | `#151B12` | 주요 텍스트 |
| `--ec-body` | `#4A5245` | 본문/보조 텍스트 |

## Shape

- 히어로급 카드(단지 인증 완료 카드, 무인택배함 픽업 코드 카드, 온보딩 완료 카드): Double-Bezel — 아우터 셸 `rounded-[26px]` + `p-1.5` + `bg-[var(--ec-surface-soft)]`, 이너 코어 `rounded-[20px]`.
- 일반 카드(상품 카드, 목록 카드): `rounded-[16px]`, `border border-[var(--ec-border)]` — waypoint(18px)보다 한 단계 각진 값을 써서 "인터폰 패널/우편함" 쪽에 가까운 약간 더 구조적인 인상을 준다.
- 동/호수 칩(예: "104동 1502호"): `rounded-[8px]`, `bg-[var(--ec-surface-sunken)]`, `tabular-nums`, 실제 우편함 라벨처럼 각진 픽토그램 느낌.
- 칩/배지: `rounded-full`.
- 프라이머리 버튼: `rounded-full`(필 버튼), 트레일링 아이콘은 버튼-인-버튼.
- 인풋: `rounded-[12px]`.
- 무인택배함 보관함 UI: `rounded-[10px]` 격자 타일(실제 무인택배함 도어 그리드를 CSS grid로 표현, 사진 대신 형태로 은유).

## Typography

Pretendard 고정, Apple HIG 스케일 재해석 (waypoint와 동일 스케일 공유 — 워크스페이스 공통 산문 기준):

| Role | Size / Line | Weight | 용도 |
|---|---|---|---|
| Display | 30 / 36 | 700 | 온보딩 스플래시, 인증 완료 타이틀 |
| Heading | 21 / 27 | 700 | 화면 타이틀 |
| Title | 16.5 / 21 | 600 | 카드 제목, 섹션 헤더 |
| Body | 14.5 / 21 | 400 | 본문 |
| Callout | 12.5 / 18 | 500 | 캡션, 메타 정보 |

동/호수, 가격, 날짜, 보관함 PIN 코드는 전부 `tabular-nums`. 인라인 메타 스트립(가격 | 거리 | 관심수처럼 이질적 정보가 섞이는 곳)은 CLAUDE.md 규칙대로 중간점이 아니라 파이프(`|`)로 구분한다.

## 기기 프레임 안쪽 규칙

하단 탭바, 채팅 상세 상단 고정 헤더는 전부 불투명 서페이스(`bg-[var(--ec-surface)]`)이며 `backdrop-blur`를 쓰지 않는다. 엣지 고정 UI는 화면 박스 안쪽 `absolute`(음수 offset, `fixed` 금지)로만 배치한다.

## Motion

- 온보딩 스텝 전환: `AnimatePresence` + `x: 24→0` 페이드, 스프링(`stiffness 300, damping 30`) — waypoint와 동일한 워크스페이스 표준 스프링 값.
- 하단 탭 활성 인디케이터: `layoutId` 공유 레이아웃 애니메이션.
- 무인택배함 픽업 코드 카드: 진입 시 살짝 스케일업(`0.96→1`) + 페이드로 "발급" 느낌.
- `prefers-reduced-motion` 존중 (워크스페이스 전역 CSS에 이미 정의됨).
