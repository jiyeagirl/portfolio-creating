# ColorRecipe - Product Spec

## 1. Overview
- 플랫폼: Mobile App (iOS, Android)
- 포지셔닝: 사진 촬영을 즐기는 일반 사용자와 콘텐츠 크리에이터를 위한 프리미엄 카메라 필터 앱. 사용자가 직접 색감 레시피(Preset)를 생성, 저장, 재사용해 일관된 사진 스타일을 손쉽게 적용
- 제작 목적: 포트폴리오용 UI 목업, 백엔드 미구현 (실시간 3D LUT 렌더링, GPU 이미지 처리, 클라우드 동기화는 목업 데이터로 표현)

## 2. Non-goals
- 실제 3D LUT 렌더링 및 GPU 기반 실시간 이미지 처리 파이프라인 구동
- 실제 카메라 하드웨어 제어(초점, 노출, ISO, 셔터속도 등은 UI 컨트롤만 구현)
- 실제 클라우드 동기화 및 계정 인증 로직
- 실제 SNS 공유, AirDrop, 링크 공유 API 연동
- 실제 RAW 파일 처리 및 EXIF 데이터 추출

## 3. Information Architecture
1. 온보딩: 서비스 소개(색감 레시피 기반 촬영), 주요 기능 안내(나만의 레시피 만들기, 실시간 필터, 저장 및 공유), 카메라와 사진 보관함 권한 허용, 알림 권한(선택), 로그인/회원가입, 둘러보기
2. 홈과 갤러리: 최근 촬영 사진, 최근 사용한 레시피, 즐겨찾기 레시피, 추천 레시피, 사진 가져오기, 카메라 바로가기, 최근 편집한 사진, 레시피 검색, 카테고리별 레시피, 내 레시피 바로가기
3. 카메라: 실시간 프리뷰와 레시피 적용, 좌우 스와이프로 레시피 변경, 현재 적용 레시피 표시, 촬영 버튼, 전면/후면 전환, 줌, 초점, 노출, 화이트밸런스, ISO, 셔터속도, Grid On/Off, 타이머, 플래시, RAW/JPEG 저장 선택, 촬영 후 미리보기
4. 색감 편집: 기본 보정(밝기, 대비, 노출, 채도, 생동감, 색온도, Tint, Highlights, Shadows, Whites, Blacks), 색상 조정(RGB Curve, HSL, Tone Curve), 필터 조절(LUT 강도, Before/After 비교, 원본 보기), 레시피 저장 및 덮어쓰기
5. 광학 효과: Bloom(강도, Threshold), Grain(입자 크기, 강도), Vignette(강도, Feather), Soft Focus(Blur, Glow), 기타 효과(Sharpen, Fade, Noise, Chromatic Aberration), 효과 On/Off와 초기화
6. 색감 레시피: 레시피 목록(내가 만든 레시피, 기본 레시피, 즐겨찾기, 최근 사용), 레시피 생성(편집 내용 저장, 이름, 썸네일, 카테고리, 설명, 태그), 레시피 관리(수정, 복제, 삭제, 즐겨찾기, 검색과 정렬)
7. 사진 상세: 사진 확대, Before/After 비교, 적용된 레시피 확인과 재적용, 색감 편집과 광학 효과 수정, EXIF 정보, 히스토그램 보기, 삭제, 즐겨찾기, 공유
8. 저장 및 공유: 사진 저장(JPEG/PNG, 고해상도, 메타데이터 유지, 파일명 지정), 사진 공유(SNS, 링크, AirDrop, 기기 저장), 레시피 공유(JSON 내보내기/가져오기, QR 코드, 링크)
9. 설정: 계정(프로필, 클라우드 동기화), 카메라(기본 저장 포맷, RAW 설정, 기본 레시피, Grid, 셔터음), 색감 레시피(자동 백업, 가져오기, 내보내기), 앱 설정(다크모드, 언어, 버전 확인, 문의하기)

## 4. Key Focus
- 카메라 화면의 실시간 색감 프리뷰와 좌우 스와이프 레시피 전환을 통해 "찍으면서 바로 확인하는" 경험을 시각적으로 강조
- 색감 편집과 광학 효과 화면에서 슬라이더 기반의 세밀한 파라미터 조정 UI로 프로급 보정 도구라는 인상 전달
- 색감 레시피를 생성, 관리, 공유하는 흐름을 하나의 축으로 묶어 "필터 선택"이 아닌 "레시피 자산화"라는 차별점 강조
- Before/After 비교와 히스토그램 같은 상세 화면 요소로 정교한 이미지 처리 엔진을 다루는 느낌을 부각
