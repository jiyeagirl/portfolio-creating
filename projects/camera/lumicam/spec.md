# Lumi Cam - Product Spec

## 1. Overview
- 플랫폼: iOS App (iPhone 촬영 + iPad 편집 스튜디오) + Web (관리자 페이지)
- 포지셔닝: 3D LUT와 Metal 기반 실시간 렌더링으로 필름 카메라 특유의 색감을 온디바이스에서 구현하는 필름 감성 카메라 필터 애플리케이션. 필터 설정을 JSON 외부 파일로 관리해 코드 수정 없이 손쉽게 확장 가능한 구조로 설계
- 제작 목적: 포트폴리오용 UI 목업, 백엔드 미구현 (실제 Metal 렌더링 파이프라인, 3D LUT 연산, 필터 스토어 결제는 목업 데이터로 표현)
- 참여 기간 : 2022.03 ~ 2022.07 사이기 때문에 목업 날짜도 이 사이로 진행한다.

## 2. Non-goals
- 실제 AVFoundation 기반 60fps 카메라 프리뷰 및 Metal GPU 렌더링 파이프라인 구현
- 실제 3D LUT 색상 변환 연산 및 Grain/Bloom/Vignette/Soft Focus/Halation/Light Leak 렌더링 로직
- 실제 필터 스토어 결제(구매) 처리
- 실제 JSON 필터 Import/Export 및 QR 코드 공유 생성 로직
- 실제 관리자의 3D LUT 업로드·필터 엔진 파라미터 반영 백엔드 처리
- 실제 GPU 렌더링 상태 모니터링 및 로그 수집 시스템

## 3. Information Architecture

### 사용자 App (iPhone / iPad)
1. 온보딩 (6 Step): Lumi Cam 소개, 필름 감성 촬영 방식 안내, 선호하는 필름 프리셋 선택, 카메라 권한 요청, 사진 라이브러리 접근 권한 요청, 설정 완료 및 촬영 시작 — ★첫 실행 시 사용자 취향에 맞는 기본 필터를 설정해 개인화된 촬영 경험 제공
2. 실시간 카메라 프리뷰: AVFoundation 기반 60fps 카메라 프리뷰, 3D LUT 실시간 필터 적용, 좌우 스와이프로 필터 전환, 필름 썸네일 미리보기, 촬영 버튼 및 렌즈 전환, 플래시/노출/그리드 설정, 현재 적용된 필터 정보 표시 — ★Metal 기반 GPU 렌더링으로 끊김 없는 실시간 필터 적용
3. 필터 조정: 필름 프리셋 선택, 조정 파라미터(톤/컬러/텍스처 그룹의 양방향·단방향 슬라이더), 광학 효과 6종(토글 온오프 + 강도 슬라이더), Before/After 비교, JSON 기반 파라미터 자동 적용 — ★필터 설정값을 JSON으로 관리해 코드 수정 없이 새로운 필터/효과를 손쉽게 추가
4. 촬영 결과: 원본/필터 적용 비교, 확대 보기, 적용된 필터 정보 확인, 고해상도 저장, 사진 라이브러리 저장, 공유하기, 다시 편집하기 — ★모든 렌더링을 온디바이스에서 처리해 원본 품질을 유지한 고해상도 이미지 저장
5. 편집 스튜디오 (iPad 전용): 대형 이미지 미리보기, 필름 프리셋 변경, 광학 효과 조합, 원본/편집 비교, 히스토그램 확인, RGB 색상 분포 확인, 확대 보기, 해상도 선택, JPEG/PNG Export — ★iPad 레이아웃을 활용해 프리셋과 광학 효과를 한 화면에서 비교·편집
6. 필터 스토어: 필터 컬렉션, 인기 필터, 신규 필터, 필터 미리보기, 다운로드, 구매, 보유 필터 관리 — ★다양한 필름 감성을 손쉽게 확장할 수 있는 구조 제공
7. 필터 공유: iOS 공유 시트(Share Sheet), AirDrop 공유, 메시지 및 SNS 공유, 공유 링크 생성, QR 코드 공유, JSON 필터 내보내기, JSON 필터 가져오기(Import) — ★JSON 기반 필터 설정을 그대로 전달해 동일한 필름 색감을 손쉽게 공유·재현

### 관리자 Web
8. 3D LUT 라이브러리 관리: 3D LUT 업로드, LUT 미리보기, 필터 등록, 카테고리 관리, 버전 관리, 활성/비활성 설정 — ★새로운 필름 프리셋을 손쉽게 등록·운영 가능
9. 필터 엔진 관리: JSON 파라미터 수정, Tone 값 설정, Grain 강도 설정, Bloom 설정, Soft Focus 설정, Vignette 설정, 실시간 Preview, 필터 매핑 관리 — ★코드 수정 없이 JSON 기반으로 필터를 운영해 유지보수성과 확장성 향상
10. 시스템 운영: 필터 캐시 관리, GPU 렌더링 상태 확인, 렌더링 로그 조회, 오류 로그 관리, 필터 다운로드 통계, 사용자 이용 현황, 앱 버전 및 리소스 배포 관리 — ★실시간 렌더링 환경을 안정적으로 운영하고 성능을 모니터링

## 4. Key Focus
- 온보딩부터 실시간 카메라 프리뷰, 촬영 결과까지 이어지는 흐름을 강조해, AI 보정 없이도 Metal 기반 실시간 렌더링만으로 자연스러운 필름 감성을 구현하는 핵심 파이프라인을 시각적으로 전달
- 필터 & 광학 효과 설정 화면에서 Tone/Grain/Bloom/Vignette 등 세부 슬라이더와 Before/After 비교를 함께 보여줘, 단순 프리셋 선택이 아닌 정교한 필름 색감 튜닝 경험임을 부각
- iPad 편집 스튜디오를 별도 화면으로 구성해, 같은 필터 엔진이 디바이스 폼팩터에 따라 다른 편집 경험(대형 미리보기 + 히스토그램/RGB 분포)으로 확장됨을 강조
- 필터 공유 화면의 JSON Import/Export와 QR 코드 공유를 통해, 필터가 단순 이미지 프리셋이 아니라 재현 가능한 데이터로 관리되는 구조임을 시각적으로 전달
- 관리자의 3D LUT 라이브러리·필터 엔진 관리 화면을 통해, 필터 설정값이 코드가 아닌 JSON 기반 외부 리소스로 운영되어 새로운 필름 프리셋을 유지보수 없이 손쉽게 추가할 수 있는 확장형 구조임을 강조

## 5. 구현 노트

- 관리자 웹(8~10)은 사용자 앱과 완전히 분리된 별도 프로젝트 `camera/lumicam-admin`(URL: `/camera/lumicam-admin`)이다. 실제 화면은 이 프로젝트의 `components/admin/`에 있고, 사용자 앱 쪽에는 관리자 진입점을 두지 않는다.
- 편집 스튜디오(5, iPad 전용)도 같은 이유로 별도 프로젝트 `camera/lumicam-ipad`(URL: `/camera/lumicam-ipad`)로 분리했다 — iPhone 앱과 URL도, 진입 흐름도 다른 별도 제품으로 취급한다. 실제 화면(`components/screens/studio-screen.tsx`)과 전용 기기 프레임(`components/ipad-frame.tsx`)은 이 프로젝트 소유이고, `lumicam-ipad`는 그걸 가져다 렌더링만 하는 얇은 엔트리다. iPhone 앱 쪽에는 스튜디오로 가는 인앱 진입점을 두지 않는다. 자세한 색상/타이포/사진 매핑 규칙은 `design.md` 참고.
