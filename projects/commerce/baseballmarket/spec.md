# BaseballMarket - Product Spec

## 1. Overview
- 플랫폼: Web (사용자, 모바일 반응형) + Web (관리자 페이지)
- 포지셔닝: 야구 팬을 위한 유니폼, 굿즈, 티켓 중고거래와 구단 기반 팬 커뮤니티를 결합한 팬덤 거래 플랫폼
- 제작 목적: 포트폴리오용 UI 목업, 백엔드 미구현 (안전거래 결제, 티켓 검증, 실시간 채팅은 목업 데이터로 표현)

## 2. Non-goals
- 실제 PG 결제 및 안전거래 에스크로 정산 처리
- 실제 티켓 진위 검증, 예매처 API 연동, 모바일 티켓 양도 처리
- 실제 본인인증 및 소셜 로그인 인증
- 실시간 채팅 서버 및 푸시 알림 발송
- 실제 택배사 연동 및 배송 추적
- 실제 KBO 경기 일정, 구단, 선수 데이터 실시간 연동

## 3. Information Architecture

### 사용자 Web
1. 회원가입 및 홈: 이메일/소셜 로그인, 회원가입, 응원 구단 선택, 관심 카테고리 설정, 구단 테마가 반영된 홈, 오늘의 경기 배너, 실시간 인기 매물, 카테고리 진입, 최근 본 상품, 통합 검색
2. 상품 탐색 및 필터: 카테고리(유니폼, 굿즈, 티켓), 구단 필터, 선수와 등번호 필터, 시즌과 유니폼 종류(홈, 원정, 서드) 필터, 사이즈, 상태 등급, 가격대, 거래 방식 필터, 정렬, 찜하기, 검색어 저장과 알림 등록
3. 상품 상세 및 판매자 신뢰 정보: 상품 이미지와 상세 설명, 상태 등급과 하자 표기, 유니폼 실측 사이즈 정보, 정품 여부와 구매 시기, 판매자 프로필, 매너 점수, 거래 후기, 응답률, 찜, 채팅 문의, 안전거래 구매, 직거래 희망 지역
4. 티켓 거래: 경기 정보(일자, 구장, 홈/어웨이), 좌석 구역과 열 정보, 정가 대비 판매가 비교 표시, 정가 초과 매물 경고, 양도 방식 선택, 경기 임박 안내, 취소와 환불 정책, 안전거래 유도
5. 판매 등록: 카테고리 선택, 사진 등록과 순서 편집, 상태 등급 선택, 야구 특화 항목 입력(구단, 시즌, 선수, 등번호, 사이즈), 티켓 항목 입력(경기, 좌석, 정가), 가격 제안 허용 여부, 거래 방식 선택, 임시저장과 미리보기
6. 채팅 및 거래 진행: 채팅 목록, 1:1 채팅, 상품 카드 공유, 가격 제안과 수락, 거래 상태 변경(예약중, 거래중, 거래완료), 안전거래 결제, 배송 정보 입력, 구매 확정, 거래 후기 작성
7. 팬 커뮤니티: 구단별 게시판, 자유 게시판, 직관 후기, 굿즈 자랑, 경기 실시간 응원 스레드, 사진 첨부, 댓글과 좋아요, 인기글, 게시글에 내 판매 상품 연결
8. 마이페이지: 판매 내역, 구매 내역, 찜 목록, 내 게시글과 댓글, 매너 점수와 받은 후기, 정산 계좌 관리, 알림 설정, 프로필과 응원 구단 수정

### 관리자 Web
9. 운영 대시보드: 가입 회원 수, 등록 매물 수, 거래 성사율, 거래액 현황, 카테고리별 거래 비중, 구단별 활성도, 티켓 거래 추이, 신고 접수 현황, 최근 문의
10. 매물 및 티켓 관리: 매물 조회, 수정, 노출 중단, 삭제, 카테고리와 구단 마스터 관리, 금지 품목 키워드 관리, 티켓 정가 기준표 관리, 정가 초과 매물 자동 탐지 목록, 신고 매물 처리
11. 회원 및 거래 관리: 회원 조회, 거래 이력 조회, 매너 점수와 제재 이력, 안전거래 정산 관리, 분쟁 접수와 조정, 환불 처리, 계정 제재와 정지 관리
12. 커뮤니티 및 신고 관리: 게시글과 댓글 조회, 신고 사유별 분류 처리, 사기 의심 계정 패턴 분석, 금칙어 관리, 공지사항 등록, 1:1 문의 관리

## 4. Key Focus
- 구단, 시즌, 선수, 등번호, 실측 사이즈 등 야구 특화 속성 기반 탐색을 전면에 배치하여 일반 중고거래 서비스와의 차별성 부각
- 티켓 정가 기준표와 정가 초과 자동 탐지 화면을 통해 암표 방지를 운영 관점에서 설계했음을 시각적으로 전달
- 상품 상세에서 채팅, 가격 제안, 안전거래 결제, 구매 확정, 후기까지 이어지는 거래 플로우를 사용자 여정 중심으로 강조
- 구단 기반 커뮤니티와 매물이 서로 연결되는 구조로 커뮤니티 활동이 거래 유입으로 이어지는 선순환 설계 강조
