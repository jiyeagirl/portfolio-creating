# PawFit - Product Spec

## 1. Overview
- 플랫폼: Mobile App (사용자) + Web (관리자 페이지)
- 포지셔닝: 반려동물 보호자를 위한 맞춤 사이즈 추천과 개인화 상품 추천을 제공하는 반려동물 의류 브랜드 자사몰
- 제작 목적: 포트폴리오용 UI 목업, 백엔드 미구현 (사이즈 추천 로직, 결제, 배송 연동은 목업 데이터로 표현)

## 2. Non-goals
- 실제 AI 기반 추천 모델 연동. 사이즈 추천은 룰 기반 로직을 시각적으로 표현하는 수준까지만
- 실제 PG 결제 처리 및 카드 등록 연동
- 실제 재고, 배송 추적 시스템 연동
- 실제 이메일/소셜 로그인 인증
- 실시간 리뷰, 문의 알림 발송

## 3. Information Architecture

### 사용자 App
1. 회원가입 및 홈: 이메일/소셜 로그인, 회원가입, 웰컴 쿠폰 지급, 반려동물 등록 유도, 등록된 반려동물 선택, 추천 상품 배너, 카테고리, 인기상품, 개인화 추천상품, 최근 본 상품, 검색
2. 반려동물 프로필 등록: 기본정보(이름, 품종, 성별, 생년월일), 체형 정보(몸무게, 등길이, 가슴둘레, 목둘레), 프로필 사진 등록, 여러 마리 관리, 프로필 수정. 사이즈 추천의 핵심 데이터를 입력받는 화면
3. 체형 기반 사이즈 추천: 선택한 반려동물 정보와 입력 정보 표시, 추천 사이즈 결과, 추천 신뢰도(예: 매우 적합), 추천 근거(몸무게 기준, 가슴둘레 기준), 브랜드별 추천 사이즈, 다시 계산, 추천 상품 바로가기
4. 상품 상세 및 사이즈 비교: 상품 이미지와 설명, 색상/사이즈 선택, 추천 사이즈 강조, 사이즈표 비교, 착용 예시, 사이즈 추천 근거, 리뷰, 장바구니, 바로 구매
5. 주문 결제 및 마이페이지: 주문 상품 확인, 배송지 관리, 쿠폰 적용, 결제수단 선택, 주문 완료, 주문내역과 배송조회, 쿠폰 조회, 반려동물 관리, 회원정보 수정
6. 사이즈 피드백: 구매 상품 선택, 실제 구매 사이즈, 착용 만족도(작아요/딱 맞아요/커요), 후기 작성, 착용 사진 등록, 추천 정확도 피드백, 다음 추천 개선 안내. AI 추천 확장을 위한 데이터 수집 화면

### 관리자 Web
7. 운영 대시보드: 가입 회원 수, 등록 반려동물 수, 주문 현황, 매출 현황, 인기 상품, 추천 사용률, 사이즈 추천 성공률, 피드백 통계, 최근 문의
8. 사이즈 기준표 관리: 브랜드별, 품종별 사이즈 기준 관리, 몸무게, 가슴둘레, 목둘레 기준 관리, 추천 룰 추가/수정/삭제, 미리보기 테스트
9. 상품 관리: 상품 등록/수정/삭제, 카테고리 관리, 재고 관리, 옵션 관리, 상품 이미지 관리, 추천 대상 설정, 상품 노출 여부
10. 회원 및 피드백 관리: 회원 조회, 반려동물 프로필 조회, 주문 이력 조회, 쿠폰 지급, 사이즈 피드백 조회, 추천 실패 사례 분석, 후기 관리, 문의 관리

## 4. Key Focus
- 반려동물 프로필 등록부터 체형 기반 사이즈 추천, 상품 상세의 사이즈 비교까지 이어지는 추천 플로우를 사용자 여정 중심으로 강조
- 사이즈 피드백 화면을 통해 룰 기반 추천이 실사용 데이터를 축적하며 AI 추천으로 확장 가능한 구조임을 시각적으로 전달
- 관리자의 사이즈 기준표 관리 화면에서 브랜드별, 품종별 추천 룰을 직접 편집하고 미리보기 테스트까지 할 수 있는 운영 중심 설계 강조
- 단순 회원 관리를 넘어 추천 실패 사례 분석까지 포함한 회원 및 피드백 관리로 추천 정확도 운영 관점의 차별성 부각
