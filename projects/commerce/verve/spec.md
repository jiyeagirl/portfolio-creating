# FitScan - Product Spec

## 1. Overview
- 플랫폼: 반응형 Web + Mobile App (모바일 퍼스트 반응형, 단일 사용자 앱/웹)
- 포지셔닝: 360° 상품 뷰어로 정면 이미지의 한계를 보완하고, 키·체중·운동 목적·선호 핏 기반 AI 사이즈 추천으로 반품과 이탈을 줄이는 브랜드 중심 스포츠웨어 자사몰
- 제작 목적: 포트폴리오용 UI 목업, 백엔드 미구현 (AI 사이즈 매칭 로직, 360° 뷰어 렌더링, PG 결제, 배송 연동은 목업 데이터로 표현)

## 2. Non-goals
- 실제 AI 기반 사이즈 매칭 모델 연동 (규칙 기반 로직을 시각적으로 표현하는 수준까지만)
- 실제 360° 상품 뷰어 촬영/렌더링 파이프라인 구현
- 실제 PG 결제 처리 및 카드 등록 연동
- 실제 재고, 배송 추적 시스템 연동
- 실제 이메일/SNS 로그인 인증
- 실시간 리뷰 신고 처리 및 알림 발송

## 3. Information Architecture

### 사용자 Web/App
1. 메인(Home): 브랜드 비주얼 배너(Hero), NEW ARRIVALS, BEST 상품, 카테고리 바로가기, 사이즈 추천 시작 CTA, 이벤트 배너, 360° 상품 체험 배너, 리뷰 많은 상품, 브랜드 스토리, Footer
2. 상품 목록(Shop): 상품 리스트(Grid), 카테고리 필터, 운동 종류별 필터, 가격 필터, 색상 필터, 사이즈 필터, 정렬(인기순/최신순/낮은 가격순/높은 가격순), Quick View, 찜(Wishlist)
3. 상품 상세 (★핵심 화면): 상품 이미지 갤러리, 360° 상품 뷰어, 확대보기(Zoom), 컬러 선택, 사이즈 선택, AI 사이즈 추천 결과, 재고 표시, 상품 상세 설명, 소재 정보, 세탁 방법, 배송/교환 안내, 장바구니, 바로구매, 공유, 찜
4. AI 사이즈 추천 (메인에서도 진입 가능): [STEP1] 키 입력, 몸무게 입력, 성별, 운동 목적, 선호 핏(Slim/Regular/Oversized) / [STEP2 추천 결과] 추천 사이즈, 추천 이유, 착용 예상 핏, 모델과 비교, 상품 바로가기
5. 장바구니: 담은 상품, 수량 변경, 사이즈 변경, 쿠폰 적용, 예상 배송비, 총 결제금액, 추천 상품, 주문하기
6. 주문 / 결제: 배송지 입력, 배송 메모, 주문 상품 확인, 쿠폰, 포인트, 결제수단 선택, 약관 동의, 결제하기
7. 주문 완료: 주문번호, 주문 내역, 배송 예상일, 주문 상세 보기, 쇼핑 계속하기
8. 마이페이지: 프로필, 주문내역, 배송조회, 취소/반품, 찜 목록, 최근 본 상품, 쿠폰, 포인트, 회원정보 수정
9. 리뷰: 리뷰 작성, 별점, 착용 사진 업로드, 키/몸무게 공개, 구매 인증, 핏 만족도, 사이즈 만족도, 리뷰 정렬, 리뷰 신고
10. 브랜드 소개: 브랜드 스토리, 브랜드 철학, 룩북, 캠페인, 컬렉션 소개, SNS 연결
11. 로그인 / 회원가입: 이메일 로그인, SNS 로그인, 회원가입, 비밀번호 찾기, 약관 동의
12. 고객센터: FAQ, 1:1 문의, 배송 안내, 교환/반품 안내, 공지사항

## 4. Key Focus
- 상품 상세 화면을 핵심 화면으로 강조 — 360° 상품 뷰어와 AI 사이즈 추천 결과를 같은 화면 안에서 함께 노출해, "보는 것"과 "맞는 것"을 동시에 해결하는 구조를 시각적으로 전달
- 메인 화면에 사이즈 추천 시작 CTA를 상단에 배치해, 사용자가 쇼핑 흐름에 진입하기 전부터 사이즈 확인 과정을 우선 유도하는 설계 의도를 부각
- AI 사이즈 추천의 STEP1(신체·운동 정보 입력) → STEP2(추천 사이즈·근거·모델 비교)로 이어지는 2단계 플로우를 통해, 단순 사이즈표 대신 개인화된 추천 경험임을 강조
- 리뷰 화면의 키/몸무게 공개, 착용 사진, 핏·사이즈 만족도 항목을 통해 AI 추천의 정확도가 실사용 데이터로 검증·보완되는 구조임을 시각적으로 전달
- 모바일 퍼스트 반응형 레이아웃을 강조해, 하나의 디자인 시스템으로 웹과 모바일 앱 경험이 일관되게 이어짐을 부각
