# SnowPeak - Product Spec

## 1. Overview
- 플랫폼: Mobile App / 반응형 Web (사용자) + Web (관리자 페이지)
- 포지셔닝: 스키 리조트 이용객을 위해 객실, 리프트권, 시즌권, 장비 렌탈, 패키지를 하나의 플랫폼에서 통합 예약하는 리조트 예약 서비스
- 제작 목적: 포트폴리오용 UI 목업, 백엔드 미구현 (실시간 재고, PG 결제, ERP 연동은 목업 데이터로 표현)

## 2. Non-goals
- 실제 PG 결제 처리 및 카드 등록 연동
- 실제 ERP 시스템과의 데이터 연동 (연동 화면 UI까지만 구현)
- 실제 재고/좌석 실시간 동기화 로직
- 실제 이메일/SNS 로그인 인증 및 본인인증(PASS 등) 처리
- 실시간 푸시 알림 발송

## 3. Information Architecture

### 사용자 App
1. 회원가입 및 로그인: 이메일/휴대폰 회원가입, 로그인 및 자동 로그인, SNS 로그인(카카오, 네이버, Apple, Google), 아이디/비밀번호 찾기, 본인인증, 약관 및 개인정보 동의, 푸시 알림 수신 설정
2. 메인 홈: 리조트 및 시즌 배너, 객실/리프트권/장비 렌탈 예약 바로가기, 패키지 상품 추천, 실시간 예약 가능 여부 표시, 이벤트 및 프로모션, 공지사항, 인기 상품 추천
3. 객실 예약: 체크인/체크아웃 날짜 선택, 객실 타입 조회, 예약 가능 객실 확인, 객실 상세 정보(사진, 시설, 인원), 옵션 추가 선택, 인원 선택, 실시간 요금 확인, 예약하기
4. 리프트권·시즌권·장비 렌탈·패키지 예약: 리프트권 종류 선택, 시즌권 구매, 장비 렌탈(스키, 보드 등), 렌탈 기간 선택, 사이즈 및 수량 선택, 패키지 상품 예약, 실시간 재고 확인, 할인 및 프로모션 적용
5. 장바구니 및 결제: 예약 상품 확인, 객실/리프트권/렌탈 통합 주문, 쿠폰 및 할인 적용, 포인트 사용, 결제 금액 계산, PG 결제, 예약 완료, 예약 확인서 발급
6. 마이페이지: 예약 내역 조회, 예약 상세 확인, 예약 취소 및 환불 신청, 결제 내역 조회, 쿠폰 및 포인트 관리, 회원정보 수정, 비밀번호 변경, 알림 확인, 고객센터 문의

### 관리자 Web
7. 관리자 대시보드: 예약 현황 요약, 오늘 예약 건수, 객실 이용률, 장비 대여 현황, 매출 통계, 실시간 예약 모니터링, 공지사항 관리
8. 예약 관리: 예약 목록 조회, 예약 상세 확인, 예약 승인/취소, 환불 처리, 예약 상태 변경, 예약 검색 및 필터, 예약 이력 관리
9. 상품 관리: 객실 등록 및 수정, 리프트권 상품 관리, 시즌권 관리, 장비 렌탈 상품 관리, 패키지 상품 관리, 가격 설정, 프로모션 관리, 이미지 관리
10. 회원 관리: 회원 목록 조회, 회원 상세 정보, 회원 등급 관리, 예약 이력 조회, 휴면 회원 관리, 회원 검색, 관리자 권한 관리
11. 재고 관리: 객실 재고 관리, 장비 재고 관리, 리프트권 판매 수량 관리, 실시간 재고 현황, 재고 부족 알림, 점검 및 사용 불가 설정
12. ERP 연동: 예약 데이터 연동, 결제 데이터 연동, 상품 정보 연동, 재고 정보 동기화, 회원 데이터 연동, 매출 데이터 연동, 정산 및 회계 데이터 연계, 연동 로그 및 오류 관리

## 4. Key Focus
- 객실, 리프트권, 장비 렌탈이 개별 시스템이 아닌 하나의 장바구니로 이어지는 통합 예약 여정을 사용자 플로우 중심으로 강조
- 예약부터 결제, 확인서 발급까지 자연스럽게 이어지는 UX를 통해 분산된 예약 절차를 단일 흐름으로 재설계했음을 시각적으로 전달
- 관리자 대시보드에서 예약/재고/매출 현황을 실시간으로 모니터링하고, 재고 관리에서 점검·품절 상태까지 직접 제어할 수 있는 운영 중심 설계 강조
- 단순 예약 관리를 넘어 ERP 연동 화면을 통해 예약·결제·재고 데이터가 실제 리조트 운영 시스템과 맞물려 돌아가는 구조임을 부각
