# 포은문화제 현장안내 — Design System

용인시 축제, 행사장 QR 진입형 기간 한정 모바일웹. 워크스페이스 `CLAUDE.md`의 UI Generation
Rules를 상속하고, `_reference-design-system.md`(filmate)에서는 **구조적 값만** 가져온다.
색상과 무드는 이 문서에서 새로 정의한다.

목업 인스턴스는 **제24회 포은문화제**(2026. 9. 18 금 ~ 9. 20 일, 처인구 모현읍 포은 정몽주
선생 묘역 일원)로 고정했다. spec.md가 예로 든 세 축제 중 하나를 골라야 배너 사진, 프로그램명,
부스명, 색 무드가 한 방향으로 정리된다. 화면 안의 "현재 시각"은 **9. 19(토) 14:20**(2일차
오후)으로 못 박아, 진행 중 프로그램과 곧 시작하는 프로그램이 동시에 보이는 상태를 만든다.

쓴다. 상업 브랜드가 등장하는 자리만 CLAUDE.md의 익명 표기 규칙을 따른다).

### 야외 주간 사용 대응 (이 프로젝트 고유 결정)

QR로 들어와 **행사장 한복판에서 서서 보는** 화면이다. 실내 앱 기준을 그대로 쓰면 안 된다.

- 본문 기본 15px, 최소 11.5px. 시간, 구역 코드처럼 멀리서 훑는 값은 16px 이상 bold.
- 본문 대비 `--fs-body` on `--fs-canvas` = 9.4:1, 보조 `--fs-muted` = 4.9:1. AA 이상.
- 모든 인터랙티브 요소 최소 44×44pt. 지도 핀의 히트 영역은 시각 크기와 무관하게 44×44pt.
- 상태를 색으로만 표현하지 않는다. 운영 상태는 색 + 도트 + 텍스트 라벨(운영 중 / 운영 종료 /
  혼잡) 3중으로 구분하고, 지도 핀은 색 + 아이콘 모양으로 구분한다.
- 설치, 로그인, 온보딩이 없다. 첫 화면이 곧 정보 화면이다.

## Tokens / 팔레트

컨셉은 **"단심(丹心)"**. 정몽주 선생의 단심가에서 온 단청 적색 하나를 강조색으로 쓰고,
바탕은 한지 톤의 따뜻한 오프화이트로 깐다. 야외 축제의 들뜬 색이 아니라, 전통문화제의
차분한 채도를 유지한다. 형제 프로젝트 `youngin/book`(잉크 그린)과 강조색으로 구분된다.

| Role | Token | Value | 용도 |
| --- | --- | --- | --- |
| Canvas | `--fs-canvas` | `#F8F5F0` | 앱 배경 (한지) |
| Surface | `--fs-surface` | `#FFFFFF` | 카드, 시트 |
| Surface soft | `--fs-surface-soft` | `#F0EBE3` | 칩, 보조 면, 입력 배경 |
| Surface sunk | `--fs-surface-sunk` | `#E6DFD4` | 진행바 트랙, 빈 슬롯 |
| Ink | `--fs-ink` | `#1C1A17` | 제목 |
| Body | `--fs-body` | `#3D3934` | 본문 |
| Muted | `--fs-muted` | `#736D64` | 보조 텍스트, 메타 |
| Faint | `--fs-faint` | `#A49C90` | 비활성, 플레이스홀더 |
| Line | `--fs-line` | `#E3DCD1` | 카드 테두리, 구분선 |
| Line soft | `--fs-line-soft` | `#EFE9DF` | 리스트 내부 구분선 |
| **Accent** | `--fs-accent` | `#B3332B` | 유일한 강조색. 단청 적 |
| Accent deep | `--fs-accent-deep` | `#8C241E` | 눌린 상태, 다크 면 위 강조 |
| Accent soft | `--fs-accent-soft` | `#F7E7E4` | 강조색 배경 칩 |
| On accent | `--fs-on-accent` | `#FDF9F4` | 강조색 위 텍스트 |
| Dark | `--fs-dark` | `#1F1C19` | QR 스캐너, 인증 완료, 히어로 오버레이 |
| Dark soft | `--fs-dark-soft` | `#2B2723` | 다크 면 위 보조 블록 |
| On dark | `--fs-on-dark` | `#F5F1E9` | 다크 면 위 본문 |
| On dark muted | `--fs-on-dark-muted` | `#A8A197` | 다크 면 위 보조 |

강조색은 **하나**다. `--fs-accent`는 CTA, 활성 탭, 진행률, 선택된 핀에만 쓴다. 프로그램
카테고리 색으로도 겹쳐 쓰는데, 프로그램이 이 축제의 본체라 의도적으로 같은 색을 준 것이다.

### 시설 분류 색 (semantic, 두 번째 강조색이 아님)

지도 핀은 **분류가 색으로 구분되지 않으면 기능이 성립하지 않는다.** 그래서 강조색과 별개로
단청 오방색에서 뽑은 분류 톤을 둔다. 이 색들은 핀, 범례, 필터 칩, 분류 배지에서만 등장하고
버튼이나 링크에는 쓰지 않는다.

| 분류 | Token | Value | Soft | 포함 시설 |
| --- | --- | --- | --- | --- |
| 프로그램 (단청 적) | `--fs-cat-program` | `#B3332B` | `#F7E7E4` | 메인무대, 소공연장, 전통체험마당, 다례관, 전시마당, 먹거리장터, 묘역 |
| 편의시설 (단청 청록) | `--fs-cat-conv` | `#1F6360` | `#E0EDEC` | 화장실, 주차장, 수유돌봄쉼터, 그늘쉼터, 분실물센터, 셔틀 승강장, 무장애 관람석 |
| 안전시설 (단청 군청) | `--fs-cat-safety` | `#2A4A82` | `#E5EAF4` | 종합안내소, AED, 응급의료소 |
| 완료, 보상 (단청 황) | `--fs-gold` | `#9B6E14` | `#F6EDD9` | 미션 완료 도장, 배지, 이벤트 응모 |

운영 상태 톤은 별도 색을 만들지 않는다. 운영 중은 `--fs-cat-conv`, 혼잡은 `--fs-gold`,
운영 종료는 `--fs-faint`를 재사용하고 항상 텍스트 라벨을 붙인다.

## Shape

| 요소 | radius |
| --- | --- |
| 카드, 배너, 시트 내부 블록 | 14px |
| Bottom Sheet 상단 | 20px |
| 버튼, 입력, 셀렉트 | 12px |
| 칩, 배지, 필터 | full |
| 지도 핀 | full (원형) + 아래 꼭지 |
| 썸네일 | 10px |

그림자 정책: **떠 있는 것에만 그림자를 준다.** 카드는 `1px` 테두리(`--fs-line`)로만 구분하고
그림자를 쓰지 않는다. 그림자는 세 곳뿐이다.

- Bottom Sheet: `0 -8px 32px -12px rgba(28,26,23,0.28)`
- 지도 위 떠 있는 컨트롤(검색, 확대 축소, 현재 위치): `0 2px 10px -2px rgba(28,26,23,0.18)`
- 선택된 지도 핀: `0 4px 12px -2px rgba(179,51,43,0.45)`

하단 탭바는 그림자 대신 `box-shadow: 0 -1px 0 var(--fs-line)` 한 줄로 경계를 만든다
(기기 프레임 안쪽 규칙 참고).

## Typography

Pretendard 고정. `_reference-design-system.md`의 스케일을 야외 가독성 기준으로 한 단계
올려 쓴다.

| Role | Size / Line | Weight | 용도 |
| --- | --- | --- | --- |
| Display | 26 / 32 | 700 | 히어로 행사명 |
| Title 1 | 20 / 26 | 700 | 화면 제목, 시설명 |
| Title 2 | 16.5 / 22 | 600 | 카드 제목, 프로그램명 |
| Body | 15 / 22 | 400 | 본문, 설명 |
| Label | 13 / 18 | 600 | 섹션 라벨, 버튼 |
| Caption | 12 / 16 | 500 | 메타, 구역 표기 |
| Micro | 11.5 / 15 | 600 | 배지, 핀 라벨 |

- 시각, 잔여 시간, 진행률, 거리는 `.festival-num`(`tabular-nums`)으로 자릿수를 고정한다.
  시간표에서 숫자가 흔들리면 목록이 지저분해진다.
- `word-break: keep-all; overflow-wrap: break-word` — 한글은 어절 단위로만 줄바꿈한다.
  `anywhere`는 `keep-all`을 무력화하므로 쓰지 않는다.
- 중간점(·)과 em dash는 렌더링 텍스트에 쓰지 않는다. 복합 라벨은 슬래시(`편의 / 안전`),
  메타 스트립은 파이프(`A구역 어울마당 | 14:00 시작`), 문장 안 나열은 콤마를 쓴다.
  숫자 범위(`14:00–15:30`)만 en dash를 허용한다.

## 행사장 지도 (이 프로젝트 고유 시스템)

지도는 이 서비스의 중심이라 **직접 그린 SVG 부지도**로 만든다. 항공사진 위에 핀을 얹는 방식은
사진과 핀의 위치가 실제로 맞지 않아 어색해진다.

- 좌표계: `viewBox="0 0 720 980"` 세로형.
- 지면 레이어 순서: 바닥 → 하천(경안천) → 숲 → 잔디, 광장 → 포장로 → 건물 → 구역 라벨 → 핀.
- 구역: A 어울마당(메인무대), B 전통체험마당, C 먹거리장터, D 전시마당, E 묘역 참배길,
  P 임시주차장. 구역 라벨은 원형 배지 + 구역명.
- 지면 색은 UI 토큰이 아니라 지도 전용 상수(`MAP_INK`)로 `lib/venue.ts`에 둔다. UI 팔레트와
  섞이면 핀이 배경에 묻힌다.
- 확대 축소는 `scale` 0.8 ~ 2.4, 버튼은 0.3 스텝. 이동은 포인터 드래그. `transform`만
  애니메이션하고 `width`/`height`/`top`/`left`는 건드리지 않는다.
- 핀 히트 영역은 44×44pt. 선택된 핀만 `scale(1.15)` + 그림자, 나머지는 그대로 둔다.
- 필터(프로그램 / 편의시설 / 안전시설)를 끄면 핀을 `opacity 0`이 아니라 DOM에서 제거한다.
  반투명 핀이 남으면 야외에서 켜진 것으로 오독된다.

## 기기 프레임 안쪽 규칙 (모바일)

- 화면은 `PhoneFrame`의 `overflow-hidden` + `rounded-[50px]`으로 잘린다. **엣지에 닿는 어떤
  요소에도 `backdrop-blur` / `backdrop-filter`를 쓰지 않는다.** Chromium에서 backdrop filter가
  조상의 라운드 코너 클립을 뚫고 모서리에 흰 틈을 만든다.
  - 대상: 하단 탭바, 지도 상단 검색바, Bottom Sheet, 스캐너 상하단 바, 히어로 위 상태바 스트립.
  - 전부 **불투명 면**을 쓴다. `bg-white/95` 같은 반투명도 쓰지 않는다. 스크롤된 콘텐츠가
    비쳐 렌더링 버그처럼 보인다.
- 엣지 고정 UI는 전부 화면 박스 안쪽 `absolute`다. 음수 offset과 `fixed`를 쓰지 않는다.
- 스캐너의 어두운 카메라 처리는 블러가 아니라 사진 위에 얹은 **단색 오버레이 div**로 만든다.
- 완료 전 **하단 모서리를 확대**해 검은 섀시 밖으로 흰색이 새지 않는지 확인한다.

## Motion

`prefers-reduced-motion: reduce`에서 아래 전부를 `0.01ms`로 무력화한다 (`styles/festival.css`).

| 대상 | 타이밍 |
| --- | --- |
| 화면 전환 (fade + `translateY(6px)`) | 260ms `cubic-bezier(.16,1,.3,1)` |
| Bottom Sheet 전개 | 320ms `cubic-bezier(.16,1,.3,1)` |
| 지도 확대 축소, 이동 | 220ms `cubic-bezier(.22,1,.36,1)`, 드래그 중에는 트랜지션 없음 |
| 버튼, 카드 프레스 | `scale(0.98)` 150ms |
| 지도 핀 선택 | `scale(1.15)` 180ms |
| 현재 위치 펄스 | 2.4s 무한, `transform`/`opacity`만 |
| 미션 완료 도장 | `scale(1.6) → 1` + 회전 `-8deg → 0`, 420ms, 1회 |

`transform`과 `opacity`만 애니메이션한다.

## 관리자 분리

이 프로젝트는 방문객용 모바일웹만 담는다. QR 이용 건수, 시설별 조회 수 집계(spec.md 3절)를
보는 운영자 콘솔은 이 프로젝트에 들어가지 않는다. 필요해지면 워크스페이스 관례대로
`youngin/festival-admin` 엔트리를 따로 만들고 화면 코드는 이 프로젝트
`components/admin/`에 둔다. 방문객 화면에는 운영자 진입점을 노출하지 않는다.
