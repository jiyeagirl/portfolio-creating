Product Spec
1. Overview

용인어린이상상의숲, 장난감도서관, 어린이도서관, 공원 놀이터 등 누구나 이용 가능한 개방형 아동 놀이시설에 QR을 설치하고, 아이가 자라는 동안 계속 새로운 미션이 열리는 상시형 모바일웹 서비스다.

무료 공공 놀이시설 정보는 여러 부서/페이지에 흩어져 있고, 민간 앱은 유료 상업시설 위주라 공공시설 정보를 다루지 않는다. 부모가 아이 프로필(연령)을 등록하면 연령대에 맞는 시설과 미션이 자동으로 추천되고, 방문할 때마다 QR 인증과 사진이 쌓여 나들이 기록으로 남는다. 관리자 페이지에서는 시청 담당자가 아이 연령대별 복지 혜택(부모급여, 장난감도서관 이용 안내 등)을 배너로 등록해 자연스러운 이용 흐름 속에서 노출한다. 아이가 자라면서 이용 가능한 시설과 혜택이 계속 바뀌는 구조를 그대로 반영해, 완주형이 아닌 성장형 콘텐츠로 운영한다.

플랫폼: Mobile Web (QR 스캔 진입형)
포지셔닝: 연령별 시설 추천 + 성장형 미션 + 복지 배너를 결합한 용인시 아동 놀이시설 상시 이용 및 나들이 기록 서비스
2. Information Architecture
2.1 사용자(부모)용 웹사이트
홈(메인) — 아이 프로필(이름, 연령), 현재 연령대 및 다음 연령대까지 남은 기간, 연령별 추천 시설/미션 카드, 복지 배너(부모급여, 장난감도서관 이용안내, 모집 중 프로그램, 예방접종/육아지원 등), 이번 시즌 미션 진행률, 방문 시설 수 및 스탬프 개수, 빠른 메뉴(QR 스캔, 시설 찾기, 나들이 기록)
시설 상세 / QR 인증 — 시설명, 위치, 운영시간, 대상 연령, 소개, 사진, 현재 가능한 미션(놀이터 이용 완료, 장난감 대여 등), QR 스캔 및 인증, 방문 사진 업로드, 스탬프 획득 및 리워드 지급, 시즌 미션 반영
미션 — 진행 중인 미션(방문 미션, 시즌 미션, 연령별 미션), 완료 현황 (진행률, 남은 미션, 완료 예정 리워드), 잠금 미션(다음 연령대 도달 시 열리는 미션 예고)으로 성장형 콘텐츠 강조
나들이 기록(타임라인) — 날짜/방문 시설/인증 사진 기반 방문 타임라인, 월별 기록(방문 횟수, 방문 시설 개수, 획득 스탬프), 추억 보기(사진 모아보기, 가족 공유, SNS 공유)
2.2 관리자 콘솔은 별도 영역

운영자용 화면은 사용자용 웹사이트와 분리된 백오피스로 구성한다.

관리자 대시보드 — 복지 배너 등록, 연령별 노출 설정, 시즌 미션 등록, 시설 관리, 이용 통계, 방문 데이터 확인

관리자는 별도 프로젝트
운영자용 콘솔은 /youngin/child-admin 으로 URL을 분리한다. 화면 코드는 워크스페이스 관례대로 본 프로젝트 components/admin/ 안에 두고, projects/youngin/child-admin 은 URL을 하나 더 얻기 위한 얇은 엔트리(src/index.tsx + src/meta.ts)로만 쓴다. child-admin 은 styles/ 와 design.md 를 따로 두지 않고 본 프로젝트의 토큰(styles/child.css)을 그대로 상속한다. 사용자용 화면에는 관리자 진입점(내비 항목, 로그인 역할 선택지)을 두지 않는다.

구현 범위
사용자용은 위 IA 4개 화면(홈, 시설 상세 / QR 인증, 미션, 나들이 기록)을 모두 구현했다. 하단 탭바는 홈 / 미션 / 기록 3개이고 시설 상세는 푸시로 열린다. 관리자 콘솔은 대시보드 1개만 구현했고, 나머지 항목(배너 / 미션 / 시설 / 통계)은 내비게이션 라벨로만 남아 있고 이동하지 않는다.
3. Key Focus
아이 연령 프로필을 기준으로 시설, 미션, 복지 배너를 자동 매칭해 검색이 아닌 자연스러운 노출로 정보 접근성 확보
완주 개념이 아닌 성장형 미션 구조(연령대가 바뀔 때마다 새 미션이 열리는 구조)로 장기 재방문을 유도
방문 인증 사진과 날짜가 누적되는 나들이 타임라인을 통해 개인 기록 자산화 및 이탈 방지
관리자가 텍스트/이미지 배너로 복지 정보를 직접 운영할 수 있는 단순한 구조로 개발 부담을 낮추면서 실질적 체감 효과 확보
시설명이 아닌 표준 카테고리(놀이터, 도서관 등) + 연령별 로직 기반 설계로 타 지자체 확산 용이성 확보
