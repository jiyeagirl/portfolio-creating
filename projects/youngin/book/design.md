# 책도장 — Design System

용인시 공공도서관 방문/완독 인증 모바일웹. 워크스페이스 `CLAUDE.md`의 UI Generation Rules를
상속하고, `_reference-design-system.md`(filmate)에서는 **구조적 값만** 가져온다. 색상과 무드는
이 문서에서 새로 정의한다.

## 적용 규칙

| 항목 | 값 |
| --- | --- |
| `spec.md` `스타일:` | 없음 → style-variant skill 미적용 |
| `spec.md` `디자인시스템:` | 없음 → `design-systems/` 미참조 |
| `spec.md` `프리미엄디테일:` | 없음 → `supanova-premium-aesthetic` 미적용 |
| 기본 스킬 | `supanova-design-engine` (디자인 판단만 채택. 이 워크스페이스는 standalone HTML을 만들지 않으므로 출력 형식 규정은 CLAUDE.md 우선) |
| 레퍼런스 | `_reference-design-system.md` / `_reference-styles/filmate.css` — spacing, 타입 스케일, radius, motion 타이밍, 안전 영역, 44pt 터치 타깃만 재사용. 색상은 재사용하지 않음 |

`supanova-design-engine` 다이얼 (기본값에서 조정한 항목과 이유):

| 다이얼 | 값 | 이유 |
| --- | --- | --- |
| `DESIGN_VARIANCE` | 8 (기본 유지) | 홈/도서관/인증/기록 네 탭이 각각 다른 레이아웃 골격을 쓴다. 동일 카드 그리드 반복 금지 |
| `MOTION_INTENSITY` | 5 (기본 6에서 하향) | 전 연령 대상 공공 서비스다. 모션은 "도장이 찍힌다"는 피드백에만 쓰고 장식적 플로팅/시네마틱 연출은 뺀다 |
| `VISUAL_DENSITY` | 4 (기본 3에서 상향) | 스탬프판, 도서관 목록, 타임라인처럼 한 화면에 실제로 밀도가 필요한 데이터가 있다. 다만 랜딩페이지식 여백은 유지 |
| `LANDING_PURPOSE` | 해당 없음 | 랜딩페이지가 아니라 앱 프로토타입이다 |

`supanova-design-engine`에서 채택하지 않은 것: standalone HTML / Tailwind CDN / 다크모드 기본값
(공공 서비스는 라이트가 기본) / "프리미엄 한국어 브랜드명 창작"(실제 지자체 시설명을 쓴다).

### 전 연령 대응 (이 프로젝트 고유 결정)

`spec.md`의 "전 연령 대상 설계와 정보취약계층 우선 미션"이 정책 목표이므로 다음을 강제한다.

- 본문 기본 15px, 최소 11.5px. filmate 레퍼런스보다 한 단계 크게 잡는다.
- 모든 인터랙티브 요소 최소 44×44pt. 리스트 행은 최소 56px.
- 본문 대비 `--bk-body` on `--bk-canvas` = 8.9:1, 보조 `--bk-muted` = 4.7:1. AA 이상.
- 상태를 색으로만 표현하지 않는다. 방문/미방문은 색 + 도장 유무 + 텍스트 라벨 3중으로 구분.

## Tokens / 팔레트

컨셉은 **"종이 위에 찍는 도장"**. 따뜻한 종이 캔버스 위에 짙은 잉크 그린 하나로만 강조한다.
용인시가 녹지 비중이 높은 도시라는 점과 도서관의 차분함을 같이 가져가는 색이다.

## Shape

- radius: `10px` 버튼·입력·칩 / `14px` 카드 / `20px` 히어로·바텀시트 / `9999px` 배지·필
  (CLAUDE.md의 "Cards 12–16px" 안에서 14px로 고정)
- 기본 구획은 **1px hairline 테두리**(`--bk-line`)로 만든다. 그림자는 남용하지 않는다.
- 그림자는 실제로 떠 있는 두 가지에만 허용:
  - 하단 고정 CTA 바: `0 -1px 0 var(--bk-line), 0 -12px 24px -16px rgba(26,29,25,.18)`
  - 획득 카드/공유 카드: `0 1px 2px rgba(26,29,25,.04), 0 12px 28px -12px rgba(26,29,25,.16)`
- 스탬프판의 빈 칸만 예외적으로 **점선 테두리**(`1.5px dashed`)를 쓴다. 아직 찍히지 않았다는
  의미를 형태로 전달하는 유일한 지점이라, 다른 곳에서는 점선을 쓰지 않는다.

## Typography

Pretendard 단일 서체(CLAUDE.md 고정 규칙). filmate 레퍼런스 스케일을 전 연령 대응으로
한 단계 키워 사용한다.

| Role | Size / Line | Weight | Tracking | 용도 |
| --- | --- | --- | --- | --- |
| Display | 30 / 38 | 700 | -0.02em | 홈 챌린지 수치, 획득 화면 |
| Title 1 | 22 / 29 | 700 | -0.02em | 화면 타이틀 |
| Title 2 | 17.5 / 24 | 600 | -0.01em | 카드 제목, 도서관명 |
| Body strong | 15 / 22 | 600 | 0 | 리스트 주요 값 |
| Body | 15 / 22 | 400 | 0 | 본문 |
| Callout | 13 / 18 | 500 | 0 | 캡션, 메타 |
| Micro | 11.5 / 15 | 600 | 0.01em | 배지, 스탬프 라벨, 탭 |

- 숫자(권수, 방문 횟수, 달성률, 날짜)는 `.book-num` 유틸의 `tabular-nums`로 자리를 고정한다.
- 한글 줄바꿈은 `.book` 루트에 `word-break: keep-all; overflow-wrap: break-word`.
  (`anywhere`는 `keep-all`을 무력화하므로 쓰지 않는다.)
- 렌더링 텍스트에 중간점(·)과 em dash(—)를 쓰지 않는다. 복합 라벨은 슬래시, 메타 나열은
  파이프, 문장 내 나열은 콤마로 쓴다.

## 기기 프레임 안쪽 규칙

`PhoneFrame`은 `overflow-hidden` + `rounded-[50px]`으로 화면을 클립한다. 이 클립을 뚫는 두 가지를
이 프로젝트에서 금지한다.

- **`backdrop-blur` / `backdrop-filter` 전면 금지.** 하단 탭바, 하단 고정 CTA 바, 스캔 화면의
  상단/하단 컨트롤 바 전부 불투명 색으로 채운다. 반투명(`bg-white/95`)도 쓰지 않는다. 스크롤된
  본문이 비쳐 스크린샷에서 렌더링 버그처럼 보인다.
  - 탭바: `bg-[var(--bk-surface)]` + 상단 1px 라인
  - 하단 CTA 바: `bg-[var(--bk-canvas)]` + 상단 1px 라인
  - 스캔 화면 바: `bg-[var(--bk-dark)]`
- **엣지 고정 UI는 화면 박스 안쪽 `absolute`로만 배치한다.** `fixed` 금지, 음수 offset 금지.
  탭바는 `absolute inset-x-0 bottom-0`, 하단 CTA도 동일.
- 스캔 화면의 어두운 카메라 뷰는 `backdrop-blur`가 아니라 사진 위에 불투명도를 낮춘 **단색
  오버레이 div**를 얹어 만든다.
- 하단 여백: 탭바가 있는 화면은 본문 `pb-[104px]`, 하단 CTA가 있는 화면은 `pb-[116px]`으로
  홈 인디케이터(34pt)와 겹치지 않게 한다.
- **상태바와 홈 인디케이터의 반전은 별도 목록으로 관리한다** (`lib/navigation.ts`).
  화면 위아래의 밝기가 서로 다를 수 있어 하나로 묶으면 한쪽이 반드시 묻는다.
  - `DARK_STATUS_BAR` = `scan`, `certifyDone`, `libraryDetail` (사진 히어로가 상태바 밑까지 올라옴)
  - `DARK_BOTTOM` = `scan`, `certifyDone` (`libraryDetail`은 하단이 밝은 CTA 바라 제외)
  - `libraryDetail` 히어로의 상단 그라디언트는 `rgba(22,33,28,0.74)`에서 시작한다. 이보다
    옅게 하면 밝은 실내 사진 위에서 흰 상태바 글자가 읽히지 않는다.
- 가로 스크롤 칩 줄(`-mx-5 overflow-x-auto`)을 `grid` 안에 직접 넣지 않는다. 그리드 트랙 폭이
  화면보다 넓어져 같은 그리드의 입력칸이 전부 오른쪽으로 밀려난다. 별도 `<section>`으로 빼거나
  `grid-cols-[minmax(0,1fr)]`을 명시한다 (완독 인증 폼에서 실제로 발생했던 문제).

완료 선언 전에 기기 하단 모서리를 확대해 검은 섀시 밖으로 흰 틈이 새지 않는지 확인한다.

## Motion

filmate 레퍼런스의 타이밍 감각을 쓰되, 물리 스프링 대신 CSS keyframes로 구현한다
(`MOTION_INTENSITY` 5).

| 대상 | 값 |
| --- | --- |
| 화면 진입 | `opacity 0→1`, `translateY 10px→0`, `320ms cubic-bezier(.16,1,.3,1)` |
| 리스트 순차 등장 | 위와 동일 + `animation-delay: index * 40ms`, 최대 6개까지만 지연 |
| **도장 찍힘 (시그니처)** | `scale 1.7→0.94→1` + `rotate -14deg→2deg→0` + `opacity 0→1`, `520ms cubic-bezier(.34,1.56,.64,1)` |
| 도장 잉크 번짐 | 도장 뒤 원형 링 `scale 0.6→1.9`, `opacity .35→0`, `700ms ease-out` |
| 진행률 바 채움 | `width` 대신 `transform: scaleX()`, `560ms cubic-bezier(.16,1,.3,1)` |
| 스캔 라인 | `translateY` 왕복, `2.4s ease-in-out infinite` |
| 버튼 press | `active:scale-[0.97]`, `140ms` |
| 탭 전환 | 색상만 `160ms`, 위치 이동 없음 |

애니메이션은 `transform`과 `opacity`만 건드린다. `prefers-reduced-motion: reduce`에서는
`book.css`의 전용 블록이 위 애니메이션을 모두 무효화하고 최종 상태로 고정한다
(워크스페이스 `globals.css`의 전역 블록에 더해 도장/스캔 라인처럼 무한 반복하는 것을
명시적으로 끈다).

## 스탬프 · 배지 에셋 시스템

이 프로젝트 고유 자산이므로 `components/shared/`로 올리지 않고 `components/stamp.tsx`에 둔다.

- **`Stamp`** — 손도장을 흉내낸 SVG. 이중 원형 테두리(바깥 실선 2px, 안쪽 점선), 중앙 픽토그램,
  상단 아치 텍스트(지점 약칭), 하단 연월. 잉크가 고르게 묻지 않은 느낌을 주려고 전체에
  `opacity .92`와 미세한 회전을 준다. 회전각은 랜덤이 아니라 id 해시에서 결정론적으로 뽑아
  리렌더에도 각도가 변하지 않는다.
- **`EmptyStamp`** — 점선 원 + 회색 지점명. 아직 방문하지 않은 지점.
- **`BadgeMark`** — 방패형 SVG. tier(bronze/silver/gold)에 따라 테두리 색과 안쪽 채움만 바뀌고
  형태는 동일하다. 미획득은 채도를 죽이고 불투명도를 낮춘다.
- **`BookCover`** — 사진 없는 타이포그래피 표지. 제목/저자를 조판하고 배경은 도서 분류별로
  정해진 5색(전부 종이 톤과 잉크 그린 계열의 명도 변주) 중 하나를 id로 고정 선택한다.
