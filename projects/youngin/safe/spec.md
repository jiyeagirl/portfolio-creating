Product Spec
1. Overview

안전디딤돌 등 기존 정보 서비스가 제공하는 위치 데이터를 활용해, 실제 응급 상황을 게임으로 체험하며 대처 행동을 익히는 용인시 생활안전 대응 인터랙티브 콘텐츠다.

안전디딤돌 등 국가 앱은 대피소, AED 위치 정보는 제공하지만, 실제 응급 상황에서 신속하게 대응하는 행동력까지 길러주지는 못한다. 정보를 "알고 있는 것"과 "실제로 해낼 수 있는 것" 사이의 격차가 골든타임을 놓치는 주요 원인이며, 오프라인 응급처치 교육은 시간·장소 제약으로 참여율이 낮다. 본 서비스는 정보 조회 대신 심정지, 폭염/한파, 재난 등 실제 상황을 미션형 게임으로 구성하고, 용인시 실제 지도와 AED·쉼터·대피소 데이터를 게임 맵에 그대로 반영해 우리 동네 상황으로 체감하게 만든다.

플랫폼: Mobile Web (인터랙티브 시뮬레이션 게임형)
포지셔닝: 실제 용인시 안전시설 데이터 기반 시나리오 게임으로 시민의 응급 대응 행동력을 실질적으로 키우는 생활안전 훈련 콘텐츠
2. Information Architecture
2.1 사용자용 웹사이트
안전 미션 선택 화면 — "용인시 생활안전 훈련"이라는 서비스 목적이 드러나는 진입 화면. 시나리오 카드 3~4종(심정지, 폭염/한파, 재난 등 상황별 미션), 난이도 및 예상 소요시간, 완료 여부/배지 표시, 미션 시작하기, 하단에 전체 미션 보기
실제 상황 대응 게임 화면(핵심) — 용인시 실제 지도 기반 게임맵, 현재 상황 및 미션 목표 안내, 주변 AED·쉼터·대피소 위치 표시(시설명, 거리 표기), 목적지까지 이동/경로 탐색, 거리 및 이동시간 표시, 상황별 선택지 및 행동 판단, 제한시간/반응시간, 단계별 미션 진행 표시(예: 119 신고 → AED 탐색 → 이동 → AED 사용), AED 사용 순서 등 세부 인터랙션(전원 켜기 → 패드 부착 → 분석 대기 → 안내에 따라 행동)
미션 결과 / 안전 리포트 화면 — 미션 성공/실패 결과, 총 대응 시간 및 반응시간, 안전 대응 점수, 올바르게 수행한 행동 체크리스트, 놓친 행동/ 개선 포인트, 실제 상황에서의 행동 가이드(단계별 안내), 획득 배지, 다시 도전하기 / 다른 미션 선택
2.2 관리자 콘솔은 별도 영역

학교, 경로당, 주민센터 등 기관 배포를 위한 최소 기능의 백오피스로 구성한다.

관리자 대시보드 — 학교·기관 단위 콘텐츠 이수 현황 관리, 시나리오별 완료 배지 및 반응속도 기록 확인

> 구현 범위 메모 (2026-08-07)
> 현재 구현된 것은 2.1의 사용자용 화면 3종뿐이다. 관리자 콘솔은 아직 만들지 않았다.
> 착수할 때는 이 워크스페이스 관례대로 `/scaffold youngin/safe --with-admin`으로
> `youngin/safe-admin` 얇은 엔트리를 만들고, 실제 관리자 화면 코드는 본 프로젝트의
> `components/admin/`에 둔다. 관리자 콘솔은 웹 콘솔이므로 `b2b/assetflow`의
> 셸과 엔터프라이즈 프리미티브를 구조 기준으로 참조하고, 색상 토큰은
> 본 프로젝트 `styles/safe.css`를 그대로 상속한다.
> 사용자 화면에는 관리자 진입점을 두지 않는다.

3. Key Focus
정보 조회형 서비스가 아닌 시나리오 기반 시뮬레이션 게임으로 "알고 있는 것"과 "실제로 해낼 수 있는 것"의 격차를 좁히는 행동 학습 경험 설계
용인시 실제 AED·무더위쉼터·한파쉼터·대피소 위치 데이터를 게임 맵에 직접 반영해 우리 동네 체감도와 데이터 활용 가시성을 동시에 확보
게임 결과 화면을 단순 성공/실패가 아닌 대응 시간, 점수, 개선 포인트, 실제 행동 가이드까지 포함한 학습 리포트로 설계해 "학습했다"는 신뢰 확보
랭킹이 아닌 완주 중심 설계로 반복 학습에 대한 부담을 낮추고, 배지 시스템 으로 지속적 참여 유도
학교·경로당·주민센터 등 오프라인 교육 현장에서 바로 활용 가능한 콘텐츠 형태로 설계해 배포 활용처를 명확히 함
