# Product Spec

## 1. Overview

시민이 보행 중 발견한 위험 요소와 불편 사항을 사진과 위치 기반으로 간편하게
제보하고, 용인시는 이를 관리·분석하여 보행환경 개선에 활용하는 시민 참여형
안전지도 모바일웹 서비스다.

파손된 보도블록, 울퉁불퉁한 인도, 휠체어 이동이 어려운 경사, 유모차 통행
불편, 불법 적치물, 가로등 고장, 어린이보호구역 위험요소 등 보행환경의 위험
요소는 행정에서 모두 파악하기 어렵고, 시민이 가장 먼저 발견하지만 기존 민원
접수 절차가 번거로워 즉시 참여하기 어렵다. 본 서비스는 사진 촬영과 현재
위치 자동 입력만으로 제보를 등록하게 하고, 담당 부서 검토와 승인 절차를
거친 제보에 대해 용인시 시티포인트 또는 캠페인 리워드를 지급해 시민 참여를
활성화한다. 제보 데이터는 용인시 지도 위에 누적되어 우리 동네 보행 위험
지도로 시민에게 다시 공개된다.

- **플랫폼**: Mobile Web (사진·위치 기반 제보형)
- **포지셔닝**: 사진·위치 기반 간편 제보 + 처리 현황 확인 + 시티포인트
  리워드를 결합한 용인시 보행 위험, 불편 지적도 서비스

## 2. Information Architecture

1. **위험, 불편 제보하기** — 사진 촬영 및 업로드, 현재 위치 자동 입력,
   지도에서 제보 위치 확인 및 수정, 위험 유형 선택(보도블록 파손, 보행로
   불량, 휠체어/유모차 이동 불편, 불법 적치물, 가로등 고장, 어린이보호구역
   위험, 기타), 상세 내용 입력, 제보 등록 버튼, 개인정보 및 위치정보 활용
   동의
2. **제보 완료 및 처리 현황** — 제보 접수 완료 안내, 제보 유형 및 위치
   확인, 제보 접수일 표시, 처리 상태 표시(접수 완료, 검토 중, 처리 중,
   처리 완료), 담당 부서 검토 안내, 승인된 제보에 대한 시티포인트 지급
   안내, 내 제보 목록 보기, 제보 상세 내용 확인
3. **우리 동네 보행 위험 지도** — 용인시 지도 기반 제보 위치 표시, 내 현재
   위치 표시, 주변 위험/불편 제보 조회, 위험 유형별 필터, 처리 상태별
   필터, 제보 마커 클릭 시 상세 정보 확인(위험 유형, 위치, 제보일, 처리
   상태), 지도 확대/축소, 현재 위치로 이동, 위험 제보하기 버튼

### 화면 흐름

우리 동네 보행 위험 지도(현황 확인) → 위험, 불편 제보하기(사진·위치 기반
제보 등록) → 제보 완료 및 처리 현황(접수 → 검토 → 처리 상태 확인 →
승인 시 시티포인트 지급) → 우리 동네 보행 위험 지도에 반영

## 3. Key Focus

- 사진 촬영과 현재 위치 자동 입력을 중심으로 제보 단계를 최소화해, 기존
  민원 접수 대비 참여 진입장벽을 크게 낮춤
- 제보 접수부터 검토, 처리 완료까지 상태를 시민이 직접 추적할 수 있게
  해, "제보했지만 어떻게 됐는지 모르는" 불신을 해소
- 관리자 승인 및 중복 여부 확인을 거친 제보에 한해 시티포인트를 지급하는
  구조로 제보 품질을 관리하면서 참여 동기를 확보
- 개별 제보를 지도 위에 누적해 우리 동네 보행 위험 지도로 재공개함으로써,
  제보가 개인 민원에 그치지 않고 시민 전체가 활용하는 공공 데이터로
  전환되게 함
- 휠체어·유모차 이동 불편, 어린이보호구역 위험 등 취약 이동권 관련
  유형을 별도 카테고리로 명시해, 보행 약자 관점의 데이터 수집을 강화
