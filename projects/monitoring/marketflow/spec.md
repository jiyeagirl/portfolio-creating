# MarketFlow - Product Spec

## 1. Overview
- 플랫폼: Web (관리자/CMS 콘솔) + Mobile (승인/알림 전용 뷰, 반응형)
- 포지셔닝: 기업 마케팅 담당자를 위한 AI 기반 콘텐츠 자동화 SaaS. 데이터 수집부터 AI 콘텐츠 생성, 검수/승인, 발행, 고객 관리(CRM), 성과 리포트까지 하나의 관리자 플랫폼으로 통합
- 제작 목적: 포트폴리오용 UI 목업, 백엔드 미구현 (AI 생성/RSS API 수집/발행 결과는 목업 데이터로 표현)
- 기간 : 2025.03 ~ 2025.09 목업 날짜는 이 안에서 진행.

## 2. Non-goals
- 실제 AI 모델(카드뉴스/블로그/숏폼 대본/아바타 영상) 생성 로직 연동. UI상 결과는 더미 데이터로 표현
- 실제 RSS/뉴스/외부 API 데이터 수집 파이프라인 구동
- 실제 SNS 채널 발행(API 연동). 발행 상태는 시뮬레이션
- 결제/과금, 플랜 관리
- 실시간 다중 사용자 동시 편집

## 3. Information Architecture
1. 관리자 대시보드: 콘텐츠 생성/발행 KPI, 승인 대기 현황, AI 생성 성공률, 신규 고객 현황, 채널별 게시 현황, 최근 활동 로그, 빠른 실행
2. AI 콘텐츠 생성: 콘텐츠 유형(블로그/카드뉴스/숏폼) 선택, 주제와 키워드 입력, 브랜드 톤앤매너 설정, AI 카피/이미지/아바타 영상 생성, 재생성, 임시 저장 및 승인 요청
3. 콘텐츠 캘린더: 월/주/일 뷰, Drag & Drop 일정 변경, 예약 발행, 채널별 일정 관리, 상태(초안, 승인대기, 예약, 발행완료) 표시, 담당자 지정과 필터 검색
4. 콘텐츠 에디터 & 승인: AI 생성 콘텐츠와 이미지, 카드뉴스 편집, 미리보기, 승인/반려/수정 요청, 관리자 코멘트, 버전 관리 및 변경 이력
5. 고객 관리(CRM): 고객 목록 검색, 등록, 수정, 계약/이용 현황, 고객별 생성 콘텐츠 조회, AI 맞춤 리포트 생성, 메모와 상담 이력
6. 자동화 워크플로우: 노코드 워크플로우 빌더, 데이터 수집(RSS/API) 설정, AI 생성 단계 구성, 승인/발행 자동화, 외부 서비스 연동, 실행 이력과 오류 로그, 활성화/비활성화
7. AI 프롬프트 관리: 프롬프트 템플릿 관리, 브랜드별 프롬프트 설정, AI 모델 선택, 프롬프트 버전 관리
8. 데이터 수집 관리: RSS 등록과 관리, 뉴스/API 연동 설정, 수집 키워드와 주기 설정, 수집 이력 조회
9. 시스템 설정: 사용자 및 권한 관리, 조직/브랜드 관리, SNS 채널 연동, API Key 관리, 알림 설정, 로그 관리

## 4. Key Focus
- 데이터 수집(RSS/API)에서 AI 콘텐츠 생성, 관리자 승인, 예약 발행으로 이어지는 자동화 파이프라인을 하나의 플로우로 시각화
- 관리자 중심의 콘텐츠 검수와 승인 환경(코멘트, 버전 관리, 반려 사유)을 통해 운영 신뢰성 강조
- 노코드 워크플로우 빌더와 AI 프롬프트 관리 화면으로 "AI 자동화를 직접 설계하고 운영할 수 있는 SaaS"라는 확장 가능한 아키텍처 인상 전달
- 모바일 승인 전용 뷰를 통해 관리자가 이동 중에도 빠르게 검수와 발행 결정을 내릴 수 있는 운영 편의성 강조
