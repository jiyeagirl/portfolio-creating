# TaxDesk - Product Spec

## 1. Overview

TaxDesk는 개인사업자와 소상공인이 부가가치세 신고에 필요한 사업정보와 증빙을 웹에서
제출하고 신고대리를 의뢰하면, 담당 세무사가 자료를 검토해 신고 내용을 확정하고
홈택스에 자동 입력 및 첨부되어 제출되는 세무대리 업무지원 플랫폼이다.

고객이 사업정보를 입력하고 증빙자료를 제출한 뒤, 의뢰 내용을 확인하고 수수료를 결제하면
신고 의뢰가 접수된다. 이후 담당 세무사가 자료를 검토하고 필요한 내용을 보완해 최종 신고
내용을 확정한다. 사용자 화면에는 도장, 서명, 위임장 단계가 없다 (2026-10-28 변경). 세무사와
운영자는 관리자 웹에서 접수 건을 검토, 확정하고, 홈택스 자동 신고 작업의 진행 상태를
모니터링하며 실패 건을 재처리한다.

- **플랫폼**: Web(사용자용, 반응형 PC 및 모바일), Web(관리자용, 세무사 및 운영자)
- **포지셔닝**: 셀프 신고의 부담 없이 낮은 수수료로 세무사 대리 신고를 받고, 신고
  후에는 기장대리로 이어지는 부가세 신고대행 서비스
- **자동 제출 모드**: 홈택스 신고 작업은 "자동 제출"과 "인증 대기" 중 선택한다.
  자동 제출은 인증과 제출까지 무인 처리하고, 인증 대기는 입력과 첨부까지만 자동으로
  진행한 뒤 담당 세무사가 확인 후 인증한다. 자동 제출이 실패하면 인증 대기로 넘어간다.
- **제작 목적**: 포트폴리오용 고품질 UI 목업. 실제 홈택스 연동, 공동인증서 처리,
  결제, 백엔드는 구현하지 않으며 mock 데이터로 화면 완성도를 우선한다.

## 2. Non-goals

- 실제 홈택스 연동, 세무 프로그램 연동, 전자신고 파일 생성
- 실제 공동인증서 저장, 인증, 전자서명
- 실제 PG 결제(신용카드, 가상계좌)
- 실제 알림톡 발송
- 실제 OCR, 이미지 처리, RAG 검색 모델 및 세액 계산 엔진
- 로그인, 본인인증 등 실제 인증 로직
- 부가가치세 외 세목(종합소득세, 원천세, 법인세 등)

## 3. Information Architecture

### 3.1 사용자 Web (반응형, PC 및 모바일)

1. **신고 신청** : 서비스 소개 히어로, 간편가입 모달(카카오, 네이버, 이메일, 본인인증,
   약관 동의), 4단계 스텝 폼
   - Step 1 사업자 정보: 사업자등록번호 조회로 상호, 개업일, 과세유형 자동 채움
   - Step 2 대표자 및 담당자: 이름, 연락처, 이메일, 알림톡 수신 동의
   - Step 3 신고 대상: 신고 구분(예정/확정), 과세기간, 신고기한
   - Step 4 사업 내용: 업종, 판매 채널(오프라인/온라인 쇼핑몰/배달앱), 직원 유무
   - 진행바, 임시저장, 입력값 실시간 검증. 모바일은 한 화면에 한 단계, 하단 고정 버튼
2. **준비자료 안내 및 증빙 제출** : 좌측 AI 안내, 우측 체크리스트와 업로드
   - AI 안내: 사업 내용 기반 준비자료 안내, 질의응답, 답변별 출처와 기준일,
     "세무사 확인 필요" 표시, 업종코드 후보 추천과 선택 근거
   - 업로드: 체크리스트 항목별 슬롯(매출, 매입, 카드 내역, 기타 증빙), 드래그 및 모바일
     촬영 업로드, 자동 규격 처리(회전 보정, 해상도 조정, PDF 변환, 용량 압축)와 처리
     전후 비교, OCR 인식값 확인 및 수정, 제출 상태(미제출/제출/읽기 오류/보완 요청)
3. **의뢰 확인 및 결제** : 신청 정보로 자동 생성된 신고대리 의뢰 내역서 미리보기와 PDF
   다운로드(의뢰인 정보, 담당 세무사, 의뢰 내용, 제출자료 목록. 서명란, 도장 없음), 담당
   세무사 자동 지정 카드, 결제 후 진행 안내(의뢰 접수 → 세무사 자료 검토와 보완 요청 →
   신고 내용 확정 → 신고, 접수증 발급), 수수료 자동 산출(기본료, 매출 구간별 추가, 옵션),
   결제수단 선택(신용카드 / 무통장입금 가상계좌), 의뢰 내역 확인 체크, 결제 성공(= 신고
   의뢰 접수), 실패, 입금 대기 상태
4. **내 신고 현황** : 단계 타임라인(접수, 검토 중, 보완 요청, 신고서 확정, 제출 중,
   접수 완료), 보완 요청 카드와 추가 업로드, 세무사 확정 신고 내용 요약(매출세액,
   매입세액, 납부 예정액), 접수증과 의뢰 내역서 다운로드, 결제 내역, 다음 신고 일정 안내,
   기장대리 상담 신청 배너
5. **알림톡 수신** : 사용자가 신고 진행 중 카카오톡으로 받는 안내 메시지를 모바일
   프레임으로 보여 주는 화면, 시간순 메시지 목록, 메시지별 바로가기 버튼으로 해당 화면
   이동
   - 메시지 종류: 결제 완료, 가상계좌 발급 및 입금 기한 임박, 보완 요청(요청 내용과
     업로드 바로가기), 신고 접수 완료(접수증 보기), 다음 신고 기한 안내(D-7)
   - 각 메시지에 고객명, 상호, 금액, 기한 등 신청 정보가 채워진 상태로 표시

핵심 화면은 3. 의뢰 확인 및 결제이다.

### 3.2 관리자 Web (세무사 및 운영자용)

사용자 화면과 분리된 관리자 웹으로 구성한다.

1. **신고 검토** : 상단 요약(오늘 접수, 검토 대기, 보완 요청 중, 입금 대기, 기한 임박),
   신청 목록과 상태 필터, 건별 및 일괄 단계 변경, 행 선택 시 우측 상세 패널
   - 탭: 고객 정보(사업자 정보, 수임동의 상태) / 위임장(PDF 뷰어, 도장 합성 확인,
     재생성) / 증빙(원본과 처리본 비교, OCR 인식값, 읽기 오류) / 근거(RAG 검색 결과와
     고객 자료 나란히 보기)
   - 액션: 보완 요청, 신고 내용 확정(세무사 승인), 반려. 확정 시 자동 신고
     작업으로 이동
2. **자동 신고 작업 관리** : 상단 요약(진행 중, 인증 대기, 실패, 오늘 접수 완료, 실행
   에이전트 연결 상태), 4개 탭
   - 전체 작업: 작업 목록과 모드 배지(자동/대기), 단계 진행 표시(신고 데이터 생성,
     홈택스 로그인, 신고 메뉴 이동, 항목 입력, 부속서류 첨부, 인증, 제출, 접수번호 수신),
     단계별 실행 로그, 단계별로 홈택스에서 처리되는 내용을 설명하는 카드, 입력값
     대조표, 실패 사유(입력 오류, 첨부 실패, 세션 만료, 인증 실패, 결과 미확인), 실패
     단계부터 재처리
   - 인증 대기: 인증 직전 멈춘 건 목록, "자동 제출 실패 후 전환" 구분 표시, 제출 내용
     미리보기, 건별 인증 및 일괄 인증
   - 필드 매핑: 플랫폼 데이터와 홈택스 입력 항목 매핑 표, 첨부 슬롯 규칙, 누락 및 형식
     불일치 점검
   - 자동화 설정: 기본 모드(자동 제출/인증 대기), 조건 규칙(신규 고객, 보완 이력, 검토
     메모가 있으면 대기), 실패 시 대기 자동 전환, 긴급 정지 스위치, 사무소 PC 실행
     에이전트 연결 상태(인증서는 에이전트 PC에만 보관)
3. **회원 및 결제 운영** : 회원 관리(마스킹된 회원 정보, 신고 이력, 기장대리 상담 신청
   여부), 결제 관리(카드 및 가상계좌 내역, 입금 확인, 기한 경과, 환불), 지식자료 관리
   (RAG 기준 문서 버전과 기준일, 검색 테스트)

핵심 화면은 2. 자동 신고 작업 관리이다.

### 3.3 구성 결정 (2026-10-28 골격 확인)

- 관리자는 별도 프로젝트: `/monitoring/taxdesk-admin`. 화면 코드는 이 프로젝트 `components/admin/`에 있고
  `taxdesk-admin`은 엔트리만 둔다. 사용자 웹에는 관리자 진입점이 없다.
- 반응형 모바일은 별도 앱이 아니라 같은 사용자 웹의 모바일 보기(`?view=mobile`, iPhone 프레임)다.
- 사용자 웹 헤더 메뉴는 신고 신청, 신고 현황 두 개 (2026-10-28 수정: "내 신고 현황"에서 이름 변경). 증빙 제출과 의뢰 확인/결제는 신청 흐름의 단계로만 들어간다.
- 알림톡 수신은 **모바일 보기 전용** iPhone 잠금화면 알림(카카오톡 알림 카드 묶음)으로 만든다. 데스크톱에는
  만들지 않고 사이트 메뉴에도 없다. 알림을 누르면 내용이 펼쳐지고 바로가기 버튼으로 해당 화면에 들어간다.
- 신고 현황은 **신청 목록이 먼저** 뜨고, 행을 누르면 그 신고의 상세(타임라인, 서류, 결제)가 열린다 (2026-10-28 수정).
  `?screen=status&filing=<신청번호>` 또는 `state=`를 주면 상세로 바로 연다.
- 의뢰 내역서의 신고 대상은 기수 없이 "2025년 부가가치세 확정신고"로 쓴다 (2026-10-28 수정).
- **목업 기준 시점 (2026-10-28 사용자 지정).** 프로젝트 기간(2025년 말 ~ 2026년 3월)에 맞춰 진행 중인 신고는
  2025년 2기 확정 (2025.07.01 ~ 12.31), 신고 기한 2026.01.26 (월, 01.25가 일요일). 사용자 웹 기준일 2026.01.14 (D-12),
  관리자 기준 2026.01.20 (화) 10:27 (D-6). 지난 신고는 2025년 1기, 2024년 2기. 신청번호는 `TD-26-xxxx`.
- 증빙 제출은 체크리스트를 전폭으로 두고, 준비자료 안내(AI 채팅)는 우하단 채팅 버튼이나 제목 옆 버튼으로 여는
  우측 드로어다 (2026-10-28 수정). 신청서의 상호 칸에 "조회 결과로 채웠어요" 안내는 두지 않는다.

### 3.4 수정 (2026-10-28 사용자 지정)

- 신고 신청 첫 화면 오른쪽 미리보기는 도장 위임장이 아니라 **신고대리 의뢰 내역서**
  (`components/request-summary-document.tsx`)다. 서명란, 도장, 완료 일시, 접수번호를 두지 않는다. 위임장 PDF가
  신고의 필수 절차처럼 보이지 않게 하려는 것. 히어로 위 신고기한 문구는 뺐다.
- 신청 흐름 3단계 이름은 `신청서 / 증빙 제출 / 의뢰 확인, 결제`. 세 화면 모두 데스크톱은 3단계를 왼쪽에 세로로
  둔다(`FlowRail`). 신청서 화면은 현재 단계 아래에 세부 4단계를 펼친다. 좁은 화면은 상단 가로 단계 유지.
  임시저장은 별도 행이 아니라 단계 제목 행 오른쪽 끝에 둔다.
- 3단계는 도장, 손서명, 위임장, 수임동의 진행을 모두 뺐다. 의뢰 내역서 확인 → 결제로 신고 의뢰가 접수되고, 이후
  세무사가 검토, 보완, 확정한다. 홈택스 수임동의는 세무사 쪽 업무로 남는다(관리자 화면은 이번 변경 범위 밖).

## 4. Key Focus

- 사용자가 입력한 정보와 담당 세무사, 제출자료가 신고대리 의뢰 내역서로 자동 정리되어
  결제 전에 의뢰 내용을 분명히 확인할 수 있는 경험 (2026-10-28 변경, 위임장 합성 대신)
- 반복 입력과 첨부는 자동, 인증은 모드에 따라 자동 또는 담당자가 맡고, 자동 제출이
  실패하면 사람에게 넘어가는 안정적인 자동화 운영 구조
- 정상 흐름뿐 아니라 증빙 읽기 오류, 입금 대기, 보완 요청, 자동 입력 실패, 에이전트
  연결 끊김 등 실패와 복구 상태를 함께 설계
- AI(RAG)는 출처와 기준일이 붙은 안내와 검토 보조까지만 맡고, 세액은 세무사가
  확정하는 역할 분리
- 신고 단계, 결제 상태, 자동화 모드 배지를 사용자 화면과 관리자 화면에서 같은 의미와
  모양으로 일관되게 표시
