# SafeSense - Product Spec

## 1. Overview

SafeSense는 스마트폰의 가속도, 자이로, GPS 센서를 활용해 현장 근로자의 낙상, 충격,
장시간 정지 등 위험 상황을 실시간으로 감지하고, 관리자에게 즉시 알림을 전달하는
산업 현장 안전관리 서비스다.

근로자는 스마트폰과 스마트워치를 착용, 소지하는 것만으로 작업 중 위험 상황이
자동으로 감지되고, 위험 발생 시 SOS 신고와 관리자 알림이 즉시 이루어진다. 관리자는
웹 대시보드에서 전체 현장 근로자의 실시간 위치와 안전 상태를 통합 모니터링하고,
이벤트 이력과 통계를 관리한다.

- **플랫폼**: 모바일 앱(Android, 근로자용), Smart Watch(Apple Watch, Wear OS,
  근로자용), Web(관리자 대시보드, 현장 관리자용)
- **포지셔닝**: 별도 산업안전 장비 없이 스마트폰과 스마트워치 센서만으로 구현하는
  현장 근로자 실시간 안전 모니터링 서비스
- **제작 목적**: 포트폴리오용 고품질 UI 목업. 실제 센서 감지 알고리즘, 실시간
  통신, 백엔드는 구현하지 않으며 mock 데이터로 화면 완성도를 우선한다.

## 2. Non-goals

- 실제 가속도, 자이로, GPS 센서 연동 및 낙상, 충격 감지 알고리즘
- 실제 푸시 알림 발송, 근로자, 관리자 실시간 통신
- 실제 긴급 신고(119 등) 연동
- 로그인, 결제 등 인증/과금 로직

## 3. Information Architecture

### 3.1 Android App (근로자용)

1. **홈(안전 현황 대시보드)** 메인 화면, 현재 안전 상태(안전/위험), 센서 연결
   상태, 오늘 작업 시간, 이동 거리, 오늘 감지 이벤트 현황, GPS 위치, 배터리 및
   백그라운드 동작 상태, SOS 긴급 신고 버튼
2. **작업 시작** : 현장(회사) 선택, 작업 시작/종료, 스마트폰 거치 위치 설정,
   센서 캘리브레이션, GPS 권한 및 센서 상태 확인, 작업 전 체크리스트
3. **이벤트 감지** : 낙상 감지, 강한 충격 감지, 장시간 정지 감지, 위험도 표시,
   자동 서버 전송, 긴급 신고 버튼, 이벤트 발생 시간 및 위치 확인
4. **작업 기록** : 이동 경로(Map), 작업 시간, 이동 거리, 이벤트 발생 기록, 일별
   작업 이력, 기간별 검색
5. **알림** : 관리자 공지, 위험 이벤트 알림, 점검 일정 안내, 시스템 알림, 읽음
   처리
6. **마이페이지** : 회원 정보, 소속 현장 변경, 센서 설정, 알림 설정, 개인정보
   및 권한 관리, 로그아웃

핵심 화면은 1. 홈(안전 현황 대시보드)이다.

### 3.2 Smart Watch (Apple Watch, Wear OS, 근로자용)

1. **안전 상태** 워치 메인 화면, 현재 안전 상태 표시, 심플한 상태 UI, 작업
   진행 시간, 배터리 확인, 센서 연결 상태
2. **위험 감지** : 낙상 감지, 충격 감지, 장시간 정지 감지, 카운트다운 표시,
   신고 취소 버튼, 긴급 신고 버튼
3. **SOS 신고** : SOS 즉시 전송, 관리자 위치 전송, 신고 진행 상태, 진동 및
   경고 표시
4. **작업 정보** : 오늘 작업 시간, 이동 거리, 걸음 수(선택), 마지막 동기화
   시간

핵심 화면은 1. 안전 상태이다.

### 3.3 관리자 웹 Dashboard는 별도 영역

현장 관리자용 화면은 근로자 앱, 워치와 분리된 웹 대시보드로 구성한다.

1. **메인 대시보드** : 오늘 근무 인원, 실시간 작업 현황, 위험 이벤트 통계,
   현장별 상태 요약, 이벤트 발생 추이, 긴급 알림 현황
2. **실시간 관제** : 근로자 실시간 위치(Map), 현재 작업 상태, 위험 이벤트 발생
   현황, 긴급 신고 모니터링, 이벤트 상세 보기
3. **이벤트 관리** : 낙상/충격/정지 이벤트 조회, 이벤트 상세 정보, 발생 위치
   확인, 이벤트 처리 상태, 기간별 검색, 이벤트 유형별 필터
4. **근로자 관리** : 근로자 등록, 현장 배정, 작업 상태 확인, 근무 이력 조회,
   계정 관리
5. **통계 분석** : 기간별 이벤트 통계, 현장별 사고 현황, 이벤트 유형 비율,
   근무 시간 분석, 이동 거리 분석, 차트 및 리포트
6. **현장 관리** : 현장 등록, 회사 관리, 관리자 계정 관리, 공지사항, 시스템
   설정

핵심 화면은 1. 메인 대시보드이다.

## 4. Key Focus

- 근로자가 별도 조작 없이도 낙상, 충격, 장시간 정지가 자동으로 감지되는
  무조작(Zero-UI) 안전 경험 설계
- 오감지를 줄이기 위한 위험 감지 후 카운트다운, 신고 취소 절차로 불필요한
  알림과 긴급 대응 사이의 균형 확보
- 근로자, 스마트워치, 관리자 3개 채널 구조에서 각자에게 필요한 정보(현장 상태
  요약, 즉각 알림, 통합 관제)를 역할에 맞게 분리 제공
- 작업 기록과 이벤트 데이터를 단순 기록이 아닌 통계, 리포트로 가공해 현장별
  사고 예방으로 이어지는 경험 제공
