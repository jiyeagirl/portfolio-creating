# CareSignal - Product Spec

## 1. Overview

CareSignal은 스마트폰 센서(가속도, 자이로, GPS)를 활용해 독거노인의 낙상, 장시간
미활동, 생활권 이탈을 실시간으로 감지하고, 보호자와 복지기관이 안전 상태를
모니터링할 수 있는 스마트 시니어 케어 서비스다.

사용자(어르신)는 스마트폰을 소지하는 것만으로 별도 조작 없이 안전 상태가 실시간으로
감지되고, 위험 상황 발생 시 사용자 확인 절차를 거쳐 보호자와 복지기관에 자동으로
알림이 전달된다. 보호자는 활동량과 위치를 상시 확인할 수 있고, 복지기관은 관리자
대시보드에서 담당 사용자 전체의 안전 상태를 통합 모니터링한다.

- **플랫폼**: 모바일 앱(iOS, Android, 사용자용), Web(관리자 콘솔, 복지기관용)
- **포지셔닝**: 웨어러블 기기 없이 스마트폰 센서만으로 구현하는 시니어 안전
  모니터링 서비스
- **제작 목적**: 포트폴리오용 고품질 UI 목업. 실제 센서 감지 알고리즘, 실시간
  통신, 백엔드는 구현하지 않으며 mock 데이터로 화면 완성도를 우선한다.

## 2. Non-goals

- 실제 가속도, 자이로, GPS 센서 연동 및 낙상 감지 알고리즘
- 실제 푸시 알림 발송, 보호자, 사용자 실시간 통신
- 실제 긴급 신고(119 등) 연동
- 로그인, 결제 등 인증/과금 로직

## 3. Information Architecture

### 3.1 사용자 앱 (어르신, 보호자용)

1. **홈 (안전 현황 대시보드)** 메인 화면, 안전 상태(안전/주의/위험), 오늘의
   활동량, 이동거리, 마지막 위치, 위험 이벤트 현황, 센서 연결 상태, 긴급 도움
   요청 버튼, 최근 알림
2. **회원가입 및 로그인** : 회원가입/로그인, 보호자 정보 등록, 비상 연락처 설정,
   약관 동의, 위치, 센서 권한 설정, 스마트폰 휴대 위치 설정
3. **낙상 감지 및 알림** : 낙상 감지, 사용자 확인 카운트다운, 오감지 신고/취소,
   보호자, 복지기관 자동 알림, 사고 위치, 시간, 처리 상태 확인
4. **생활권 이탈 및 위치 확인** : 안심 구역 설정, 실시간 위치, 이탈 알림, 이동
   경로 조회, 최근 방문 기록, 보호자 위치 공유
5. **활동량 모니터링** : 걸음 수, 이동거리, 활동/휴식 시간, 장시간 미활동 감지,
   일, 주, 월 활동량 그래프, 활동 패턴 분석, AI 활동 부족 알림
6. **긴급 도움 요청 (SOS)** : SOS 버튼, 위치 자동 전송, 보호자, 복지기관 즉시
   알림, 긴급 연락처 연결, 신고 진행 상태, 요청 이력 조회
7. **알림 및 이용 내역** : 위험 이벤트 알림, 보호자 알림 발송 이력, 활동/이탈
   기록, 유형별 필터, 기간별 조회, 읽음 처리
8. **건강 리포트** : 주간, 월간 활동량 리포트, 낙상, 위험 이벤트 통계, 생활권
   이탈 횟수 분석, 활동 패턴 변화, AI 건강 코멘트, 보호자 공유용 리포트

핵심 화면은 1. 홈(메인 화면)과 8. 건강 리포트다.

### 3.2 관리자 콘솔은 별도 영역

복지기관 운영자용 화면은 사용자 앱과 분리된 웹 대시보드로 구성한다.

1. **관리자 대시보드** : 전체 등록 사용자 현황, 오늘 발생 위험 이벤트, 낙상,
   이탈, 미활동 통계, 긴급 요청 현황, 사용자 안전 상태 요약, 실시간 알림 모니터링
2. **사용자 관리** : 사용자, 보호자 관리, 생활권 설정 관리, 계정 상태 관리,
   비상 연락처 관리, 이용 이력 조회
3. **실시간 모니터링** : 사용자 위치 지도, 안전 상태 확인, 위험 이벤트 발생
   현황, 긴급 요청 모니터링, 이벤트 상세 조회

## 4. Key Focus

- 어르신이 별도 조작 없이도 낙상, 미활동, 생활권 이탈이 자동으로 감지되는
  무조작(Zero-UI) 안전 경험 설계
- 낙상 오감지를 줄이기 위한 사용자 확인 카운트다운 절차로 불필요한 알림과
  긴급 대응 사이의 균형 확보
- 사용자, 보호자, 복지기관 3자 구조에서 각자에게 필요한 정보(현황 요약,
  실시간 알림, 통합 모니터링)를 역할에 맞게 분리 제공
- 활동 데이터를 단순 기록이 아닌 건강 리포트로 가공해 예방적 케어로 이어지는
  경험 제공
