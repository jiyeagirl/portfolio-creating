# BrandPilot - Product Spec

## 1. Overview
- 플랫폼: Web (뷰티 브랜드 마케팅 운영팀 대상 통합 콘솔)
- 포지셔닝: 업계 레퍼런스 탐색부터 AI 콘텐츠 생성, 승인, SNS 게시, 성과 분석까지 하나로 통합한 AI 기반 마케팅 운영 플랫폼
- 제작 목적: 포트폴리오용 UI 목업, 백엔드 미구현 (AI 생성/SNS 연동/성과 데이터는 목업 데이터로 표현)

## 2. Non-goals
- 실제 AI 모델(이미지/카피 생성) 연동 — UI상 생성 결과는 더미 데이터로 표현
- 실제 SNS 플랫폼 API 연동(인스타그램/틱톡 등 실게시) — 게시 상태는 시뮬레이션
- 결제/과금, 플랜/구독 관리
- 실시간 협업(동시 편집, 실시간 댓글 알림 등) 백엔드 로직
- 다국어/다통화 지원

## 3. Information Architecture
1. 로그인 — 이메일/소셜 로그인, 비밀번호 찾기, 로그인 즉시 대시보드 진입
2. 대시보드 — 진행 캠페인·승인 대기·예약 현황·최근 콘텐츠·AI 추천 작업·성과 요약을 한눈에, Quick Action으로 주요 작업 바로 진입
3. 레퍼런스 탐색 — 플랫폼 공개 API(Meta 광고 라이브러리, Instagram Graph API, YouTube Data API, 네이버 검색 API, TikTok Commercial Content Library)로 업계 광고를 수집·분류해 레퍼런스 데이터베이스 구성, 검색, 캠페인 사례 저장, AI 인사이트 요약, 키워드 분석, 북마크
4. 브랜드 가이드 관리 — 톤앤매너·금지 표현·컬러/폰트·제품 정보·AI 학습 데이터를 브랜드별로 관리해 콘텐츠 일관성 확보
5. AI 콘텐츠 생성 — 캠페인/제품/생성 목적 선택 후 AI 카피·이미지·해시태그를 한 흐름으로 생성
6. 콘텐츠 편집기 — 이미지·카피 수정, 채널별 미리보기, 브랜드 가이드 준수 여부 실시간 확인
7. 승인 워크플로우 — 검토 요청, 승인/반려, 댓글, 버전 관리, 승인 이력 추적
8. SNS 게시 관리 — 예약/즉시 게시, 콘텐츠 캘린더, 게시 상태 확인
9. 콘텐츠 라이브러리 — 전체 콘텐츠 조회, 검색·필터, 복제, 버전 관리
10. 캠페인 관리 — 진행/예정/종료 캠페인 구분, 목표 설정, 관련 콘텐츠 묶음 관리, 담당자·일정 관리
11. 성과 분석 — SNS 성과 대시보드, 콘텐츠별 성과, AI 인사이트, 리포트 다운로드

## 4. Key Focus
- 브랜드 가이드(톤앤매너·금지 표현·컬러/폰트)가 AI 콘텐츠 생성·편집·승인 전 과정에서 일관되게 반영되는 구조를 시각적으로 강조
- 레퍼런스 수집 → AI 생성 → 승인 → 게시로 이어지는 엔드투엔드 워크플로우를 하나의 플랫폼 안에서 끊김 없이 보여주기
- 관리자 중심 대시보드와 승인 큐를 통해 다인원 협업 과정을 효율적으로 관리하는 화면 설계
- 예약 게시·콘텐츠 캘린더·버전 관리 등 운영 편의 기능으로 실무 완성도 어필
