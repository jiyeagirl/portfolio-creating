# MarketFlow Mobile - Product Spec

## 1. Overview
- 플랫폼: Mobile (관리자 승인/알림 전용 앱)
- 포지셔닝: MarketFlow(AI 기반 콘텐츠 자동화 SaaS)의 관리자가 이동 중에도 AI가 생성한 콘텐츠를 검토하고, 승인/반려/수정 요청을 처리하며, 발행·오류 알림을 실시간으로 확인할 수 있는 전용 모바일 앱
- 제작 목적: 포트폴리오용 UI 목업, 백엔드 미구현 (푸시 알림, 승인 처리 결과 반영은 목업 데이터로 표현)
- 기간 : 2025.03 ~ 2025.09 목업 날짜는 이 안에서 진행 (본 프로젝트 `projects/monitoring/marketflow`와 동일 기간).
- 본 프로젝트는 `projects/monitoring/marketflow/spec.md`의 "10. 모바일 승인 및 알림" IA를
  별도 앱으로 분리한 것이다 — 웹 콘솔(관리자/CMS)과 기기 패러다임이 근본적으로 달라
  (사이드바 웹 셸 vs PhoneFrame 단일 기기) 같은 프로젝트에 둘 수 없다. 색상 토큰과 브랜드는
  marketflow 본 프로젝트와 공유하지 않고 이 프로젝트 정체성에 맞게 새로 정의하되, 같은
  제품군임을 알아볼 수 있는 로고/워드마크 어휘는 유지한다.

## 2. Non-goals
- 실제 푸시 알림 서버(APNs/FCM) 연동. 알림은 목업 데이터와 인앱 리스트로만 표현
- 실제 AI 콘텐츠 생성/재생성 로직. 콘텐츠는 이미 생성 완료된 상태로 미리보기만 처리
- 실제 SNS 채널 발행(API 연동). 발행 상태는 시뮬레이션
- 콘텐츠 신규 작성/편집 (에디터는 웹 콘솔 전용, 모바일은 검토·승인만)
- 오프라인 동기화

## 3. Information Architecture
1. 홈 (승인 대기 요약): 오늘의 승인 대기 건수, 채널별 발행 예정 현황, 최근 발행 완료/오류 알림 미리보기, 빠른 진입(승인함/알림함)
2. 승인함: 승인 대기 콘텐츠 리스트, 콘텐츠 유형(블로그/카드뉴스/숏폼)·채널·담당자 필터, 상태(승인대기/수정요청/반려) 표시, 정렬 및 검색
3. 콘텐츠 미리보기 & 승인 처리: AI 생성 콘텐츠(카피/이미지/카드뉴스/숏폼 썸네일) 전체 미리보기, 채널별 발행 미리보기, 승인/반려/수정 요청 액션, 반려·수정 요청 시 코멘트 입력, 처리 완료 확인
4. 알림 센터: 승인 요청 알림, 발행 완료 알림, 발행 오류 알림, 전체/읽지 않음 필터, 알림 탭 시 관련 콘텐츠로 바로 이동
5. 마이페이지: 관리자 프로필, 담당 브랜드/조직 표시, 알림 수신 설정(승인 요청/발행 완료/오류 각각 on/off), 로그아웃

## 4. Key Focus
- 승인함 → 콘텐츠 미리보기 → 승인/반려/수정 요청으로 이어지는 명확한 단계형 검토 플로우
- 이동 중 한 손 조작을 고려한 리스트 우선 UI, 큰 터치 타깃, 스와이프 액션
- 알림 탭 → 해당 콘텐츠로 즉시 이동하는 딥링크형 흐름으로 "빠른 의사결정" 인상 전달
- 웹 콘솔과 동일한 제품군임을 알아볼 수 있는 워드마크/톤이되, 모바일 전용 앱으로서 독립된 비주얼 아이덴티티
