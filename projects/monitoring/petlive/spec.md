# PetLive - Product Spec

## 1. Overview
- 플랫폼: Mobile App (사용자, Android/iOS) + Web (관리자 페이지)
- 포지셔닝: IoT 펫캠을 통해 언제 어디서나 반려동물의 상태를 실시간으로 모니터링하고, 디바이스와 이벤트를 통합 관리하는 반려동물 모니터링 플랫폼
- 제작 목적: 포트폴리오용 UI 목업, 백엔드 미구현 (실시간 영상 스트리밍, IoT 디바이스 연동, ERP 연동은 목업 데이터로 표현)

## 2. Non-goals
- 실제 IoT 디바이스와의 Wi-Fi 페어링 및 펌웨어 업데이트 처리
- 실제 실시간 영상 스트리밍 인프라(WebRTC/RTSP 등) 구현
- 실제 움직임/소리 감지 AI 분석 로직
- 실제 이메일/SNS 로그인 인증 및 본인인증 처리
- 실시간 푸시 알림 발송 및 ERP 시스템과의 실제 데이터 연동

## 3. Information Architecture

### 사용자 App
1. 회원가입 및 로그인: 이메일 및 SNS 계정 로그인, 회원가입 및 본인 인증, 비밀번호 찾기, 자동 로그인, 이용약관 및 개인정보 동의
2. 홈 화면: 등록된 반려동물 및 펫캠 상태 요약, 실시간 연결 상태 확인(온라인/오프라인), 최근 이벤트(움직임 감지, 소리 감지 등) 미리보기, 실시간 모니터링 바로가기, 알림 현황 표시
3. 실시간 웹캠 모니터링: 실시간 영상 스트리밍, 전체 화면 보기, 영상 확대/축소, 스냅샷 촬영, 영상 음소거/음성 듣기, 네트워크 상태 표시, 다중 카메라 전환(여러 대 등록 시)
4. 웹캠 등록 및 연결: QR 코드 또는 시리얼 번호 등록, Wi-Fi 연결 설정, 디바이스 최초 페어링, 연결 상태 확인, 펌웨어 업데이트 안내
5. 웹캠 디바이스 관리: 등록된 펫캠 목록 조회, 디바이스 이름 변경, 설치 위치 설정, 연결 상태 확인, 디바이스 삭제, 배터리 및 네트워크 상태 조회, 펌웨어 업데이트
6. 알림 및 마이페이지: 움직임/소리 감지 알림 조회, 이벤트 발생 시간 확인, 반려동물 정보 관리, 회원 정보 수정, 알림 설정(On/Off), 로그아웃 및 회원 탈퇴
7. 이벤트 기록 (선택): 움직임 감지 이력, 소리 감지 이력, 이벤트 발생 시간순 조회, 이벤트 영상 다시보기, 날짜별 필터 검색

### 관리자 Web
8. 관리자 대시보드: 전체 회원 수 및 신규 가입 현황, 등록된 웹캠 현황, 온라인/오프라인 디바이스 현황, 이벤트 발생 통계, 시스템 운영 현황 모니터링
9. 사용자 관리: 회원 목록 조회, 회원 검색 및 필터, 회원 상세 정보 조회, 계정 활성화/비활성화, 반려동물 및 등록 디바이스 확인
10. 웹캠 관리: 등록 디바이스 목록 조회, 디바이스 상태 모니터링, 연결 오류 확인, 펌웨어 버전 관리, 디바이스 등록 및 삭제, 원격 재연결 지원
11. 로그 관리 및 ERP 연동: 이벤트 로그 조회, 로그인 이력 관리, 디바이스 연결 이력 확인, 장애 및 오류 로그 확인, ERP 회원 정보 연동, 디바이스 및 운영 데이터 연계, 데이터 Export(Excel)

## 4. Key Focus
- 펫캠 등록부터 실시간 모니터링, 이벤트 기록까지 이어지는 흐름을 보호자의 "외출 중 반려동물 상태 확인" 여정 중심으로 강조
- 움직임/소리 감지 알림과 이벤트 기록 화면을 통해 단순 실시간 영상 제공을 넘어 이력 기반의 모니터링 경험을 시각적으로 전달
- 관리자 대시보드에서 회원, 디바이스, 이벤트 현황을 한눈에 파악하고, 웹캠 관리 화면에서 연결 오류·원격 재연결까지 직접 제어할 수 있는 운영 중심 설계 강조
- 로그 관리 및 ERP 연동 화면을 통해 IoT 디바이스 데이터와 회원 데이터가 실제 운영 시스템과 맞물려 돌아가는 구조임을 부각
