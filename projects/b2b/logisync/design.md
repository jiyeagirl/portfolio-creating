# LogiSync Design Notes

## 아키타입

- **고른 것: 단계별로 묶은 아이콘 + 이름 사이드바 (C1 계열, 단계 그룹 제목 추가).** 처음에는 C4 아이콘 레일 + 섹션 리스트였으나 레일은 이름이 없어 메뉴를 찾기 어렵다는 피드백으로 바꿨다. spec의 IA 9개는 평면 목록이 아니라
  데이터가 흘러가는 **파이프라인 단계**다. 수집(1, 7) → 검증(2) → 통합(3, 4, 5, 6) →
  활용(8, 9). 사이드바의 4개 그룹이 곧 파이프라인 단계다. 운영자는 본사 데이터 운영팀(내부, 센터를
  가로질러 봄)이다.
- **배제 1: C1 다크 레일.** 판별 기준상으로는 C1이 맞지만 `projects/b2b/` 안에서
  assetflow, buildbid, genderinsight, orderlog가 이미 C1이다. 236px 레일에 9개를
  평면 나열하면 "수집 → 통합" 흐름이 내비에서 사라진다.
- **배제 2: C3 상단 커맨드 바.** 수평 주내비 상한이 5개라 9개 뷰를 담지 못하고,
  하루 종일 한 섹션에서 triage만 하는 콘솔도 아니다.
- **이 셸에서 쓰지 않는 부품**
  - 236px 라벨 레일, `sideFoot` 유저 칩
  - 전폭 `h-14` 헤더 (헤더는 본문 컬럼 위에만 얹힌다)
  - `fixed inset-0 z-50 lg:hidden` + 264px 드로어 (모바일은 하단 아이콘 바 + 가로 세그먼트)
  - `mx-auto max-w-[1400px]`
  - 헤더 우측 KST 시계. 대신 "마지막 동기화 N분 전" 칩을 둔다. 이 도메인에서 의미 있는
    시각은 벽시계가 아니라 수집 시각이다.
  - 균등 3열 KPI 카드 그리드 (Ferrari `spec-cell`처럼 카드 없이 숫자와 캡션만 늘어놓는다)

## 적용 규칙

해석: 물류 데이터 통합 관리 콘솔 for 매일 센터별 수집 상태와 정합성을 확인하는 본사 데이터 운영팀. 다이얼 V6 / M3 / D7.

- 읽은 skill: `mockup-craft` SKILL.md, references/anti-slop.md, references/console.md. 외부 skill은
  2026-09-18부터 비활성이라 적용하지 않았다. `스타일:` / `프리미엄디테일:` 지정 없음.
- `디자인시스템: farrari_compact` (spec.md). 사용자 요청은 "ferrari_compact"였지만 실제
  파일명은 `design-systems/farrari_compact.md`다.
- 우선순위: CLAUDE.md UI Generation Rules → farrari_compact → `mockup-craft`.
  - Pretendard 고정 (farrari_compact도 이미 Pretendard로 치환해 두었다).
  - farrari_compact는 출발점으로만 쓴다. 0px 샤프 모서리, 흑색 캔버스, 외곽선 버튼은
    "너무 네모나고 까맣다"는 피드백으로 걷어냈고, 레드 한 곳 원칙과 숫자 중심 타이포만 남겼다.
- 다이얼 근거 (`mockup-craft` SKILL.md 2절 정의 기준):
  - `DESIGN_VARIANCE 6`: 블록마다 처리 방식이 다르다 (한 줄 지표, 사진 카드, 표, 추적 타임라인).
    콘솔 프리셋(3~4)보다 높게 잡았는데, 센터 카드의 사진과 파이프라인 단계 레일이 이 도메인의
    정체성이라서다.
  - `MOTION_INTENSITY 3`: 드로어, 진입 한 번, 라이브 점만 움직인다.
  - `VISUAL_DENSITY 7`: 콘솔. 카드 없이 헤어라인과 여백으로 묶고 숫자는 `tabular-nums`.
- 아이콘: Phosphor (`@phosphor-icons/react`) regular 한 굵기. 활성 내비만 fill. 이름은
  `lib/icons.ts`의 `ICONS`에 모아 두고 화면 코드는 키로만 부른다 (2026-10 Iconify Solar에서 전환).
- 페이지 제목 아래에는 설명 문장과 영문, 번호 라벨을 두지 않는다. 단계는 사이드바 그룹 제목(한글)으로만
  드러낸다 (anti-slop 1절).

## Tokens / 팔레트

**팔레트 구성 4: 틴티드 뉴트럴 (웜 스톤) + 어두운 아이콘 레일.** 처음에는 farrari_compact를
그대로 따라 다크 우선(`#181818`)으로 만들었으나 "너무 까맣다"는 피드백으로 밝은 웜 스톤
캔버스로 옮겼다. farrari에서 남긴 것은 레드 액센트 한 곳 원칙, 숫자 중심 스펙 셀, weight 500
디스플레이다. b2b의 앞선 프로젝트들은 구성 1(무채 라이트 + 액센트)이라 겹치지 않는다.

`styles/logisync.css`, `.logisync` 스코프, 접두사 `--ls-`. 어두운 면은 `.ls-dark`가 같은 변수를
덮어써서 만든다. 쓰는 곳은 248px 사이드바와 검증 스코어보드의 선택 칸뿐이다.

최고 구간, 기간 최고 막대), 선택 행 좌측 바와 틴트, 모바일 하단 바의 활성 표시, 알림 점.

### 상태 5단 (의미 고정)

| 톤 | 기준(점, 막대) | 전경(텍스트) | 배경 | 쓰이는 상태 |
| --- | --- | --- | --- | --- |
| `ok` | `#0f9a55` | `#0a7a43` | `#e3f3ea` | 정상, 수집 완료, 매핑 확정 |
| `info` | `#4c98b9` | `#2d6a86` | `#e3eff5` | 처리 중, 재처리 대기, 검토 |
| `warn` | `#d9a21b` | `#8a6100` | `#fbf0d6` | 지연, 누락, 안전재고 근접 |
| `danger` | `#e2382a` | `#c02a1d` | `#fde7e4` | 장애, 오류, 재고 부족 |
| `neutral` | `#9a9ba0` | `#4a4b50` | `#eceae6` | 중복(폐기), 해당 없음, 예정 |

`warn`은 farrari_compact에 없는 색이다. 원본의 경고색은 사실상 빨강이라 지연과 장애를 구분할
수 없어서 앰버를 추가했다. 상태는 항상 점 + 라벨로 표기한다.

API 메서드 태그도 이 톤을 빌린다: GET `info`, POST `ok`, PUT `warn`.

- 히트맵: `#f1efeb` → `#f7d3cf` → `#ec8479` → `#da291c`. 80 이상 칸은 흰 글자.

## Shape

**박스 외곽선은 쓰지 않는다.** 구분은 면의 명도 차(캔버스 → 흰 패널 → 채움)와 옅은 그림자로
한다. 선이 남는 곳은 목록 행 사이의 `--ls-hairline-soft` 가로줄(마지막 행 제외)과 원본 레코드
페이퍼 안의 행 구분뿐이다. 1px 격자(`gap-px` + 선 색 바탕)도 쓰지 않고 `gap-3`/`gap-4`로 띄운다.

- 반경: 패널, 카드 `16px` / 버튼, 입력, 사진 썸네일, 페이지 번호 `10px` /
  레일 아이콘, 원천 데이터 추적 사진, 원본 레코드 `12px` / 코드 칩, 센터 태그, 메서드 태그 `6px` /
  배지, 도메인 칩, 진행 바, 아바타 `full`. CLAUDE.md의 카드 12~16px 규칙으로 돌아왔다.
- 탭은 전폭 밑줄 없이 활성 탭 아래 2px 둥근 바만.
- 세그먼트는 채움 바탕 안에 흰 알약이 떠 있는 형태.
- 드로어는 데스크톱에서 화면 가장자리에서 12px 띄운 둥근 시트, 푸터는 캔버스 톤 면.
- 그라데이션은 쓰지 않는다. 관리자 콘솔이라 사진 히어로와 성과 밴드도 두지 않는다
  (수집 화면에 있던 히어로는 피드백으로 제거).
- 연계 방식은 `API` / `DB` / `파일` 세 가지로만 표기한다. REST, SOAP, SFTP, Kafka 같은
  구체적인 기술명은 화면과 목 데이터에 쓰지 않는다.

## Typography

Pretendard 고정. display는 weight 500. 큰 수치는 `.ls-figure`(600, 거의 기본 자간)로 통일한다.
700 + 좁은 자간 조합과 숫자 옆 단위("1,234건")가 AI 대시보드처럼 보인다는 피드백으로, 단위는 라벨에
"정산 대상 건수 (건)"처럼 괄호로 붙이고 숫자에는 붙이지 않는다. 표도 머리에 "(건)", "(원)"을 단다.

| 역할 | 크기/행간 | 굵기 | 자간 |
| --- | --- | --- | --- |
| Page title | 28 / 36 | 500 | -0.28px |
| Spec number | 32 / 38 (강조 40 / 44) | 600 | -0.01em, tabular (`.ls-figure`) |
| Panel title | 16 / 22 | 700 | 0 |
| Body | **14 / 21** | 400 | 0 |
| Small | 13 / 20 | 400 | 0 |
| Caption | 12 / 17 | 400 | 0 |
| 라벨 (`.ls-eyebrow`, 패널과 카드 윗줄) | 12 / 16 | 600 | 0 (한글이라 양의 자간 없음) |
| Button | 13 / 16 | 700 | 0 |

- 영문 대문자 라벨은 쓰지 않는다. 단계 코드(INGEST, SERVE 등)는 데이터에서도 지웠다. 영문은 ID, 코드,
  기술 용어(API, WMS, SKU)에만 남는다.
- 페이지 맨 위 핵심 지표는 `SpecBand`/`SpecCell`: 정합성 화면의 스코어보드와 같은 규격이다. 흰 카드 하나에 라벨
  (13 / 20)과 숫자(30 / 36, 600). 강조 칸(`highlight`)은 숫자만 레드로 한다. 맨 숫자 한 줄은 묻히고, 라벨 띠를
  두른 큰 숫자(38px)는 과하다는 두 번의 피드백으로 이 크기에 정했다.
- 코드, 수량, 시각은 `.ls-num` (`tabular-nums`)과 `.ls-code` (모노). 본문에는 쓰지 않는다.
- 한글 블록은 `word-break: keep-all; overflow-wrap: break-word`.
- **스케일 복제 금지:** 본문 14/21은 워크스페이스에서 처음 쓰는 쌍이다 (15/22 11개,
  14/20, 14/22, 14.5/21, 17/25와 다름). farrari body-md 14px × 1.5에서 왔다.

## 셸 레이아웃

- 사이드바 248px, `.ls-dark` 캔버스(`#1c1d20`), `sticky top-0 h-dvh`. 콘솔에서 유일한 어두운 면이다.
  상단에 레드 브랜드 마크와 `LogiSync`, 그 아래 파이프라인 단계(수집, 검증, 통합, 활용)별 그룹 제목과
  화면 9개를 아이콘 18px + 이름으로 나열한다. 활성 항목은 한 단계 밝은 채움 + fill 아이콘.
  하단에는 환경 설정 하나만 둔다. 요약 숫자 블록은 실제 서비스 사이드바에 없는 장식이라 두지 않는다.
- 본문 컬럼. 헤더 64px는 본문 컬럼 위에만, 캔버스와 같은 색이라 경계선이 없다. 좌측 브레드크럼
  (`통합 / 통합 물류 데이터`), 우측 흰 검색창 320px, 동기화 알약, 알림, 원형 아바타.
- 본문 패딩 `px-5 py-6` → `lg:px-10 lg:py-8`, `max-w-none`.
- `lg` 미만: 사이드바가 숨고, 단계는 하단 흰 아이콘 바(불투명, 위쪽 옅은 그림자, 60px, 한글 라벨),
  하위 뷰는 헤더 아래 가로 세그먼트로 접힌다. 드로어 없음.
- 1440px 기준 본문 폭: 1440 − 248 − 80(패딩) = **1112px**.

## 표 밀도 / 컬럼 예산

- 1440px 기준 본문 폭: 1440 − 64 − 240 − 80(패딩) = **1056px**.
- 전폭 표: `minWidth` 960, 최대 7열.
- 통합 물류 데이터(대표 화면)는 표 + 우측 원천 데이터 추적 패널 400px + 간격 24px
  → 표 컬럼 632px. `minWidth` 600, **최대 5열**. 수량과 상태는 한 열에 두 줄로 합친다.
- 좁은 반쪽 컬럼(약 516px): `minWidth` 480, 최대 4열.
- 넘치면 값을 보조 줄로 내리고 열을 줄인다. 마지막 열(상태, 액션)이 먼저 잘리기 때문이다.

## Motion

- 화면 진입: **180ms `cubic-bezier(.3,0,.3,1)`** (거의 선형) + opacity + `translateX(-6px)`.
  파이프라인 방향(좌 → 우)을 따라 들어온다.
- 원천 데이터 추적 단계 스태거: 40ms 간격.
- 드로어: 220ms 같은 곡선, `translateX(24px)`.
- 눌림 피드백: 스케일 없음. 버튼과 내비는 hover/active에서 배경만 한 단계 바꾼다
  (`#da291c` → `#b01e0a`, 채움 → 눌림). 표 행 hover는 흰 패널에서 캔버스 톤으로.
- 라이브 점(수집 중) 1.6s 펄스.
- **스케일 복제 금지:** 워크스페이스에 번진 420ms expo-out + `translateY(8px)`과 spring
  300/30 대신 180ms 거의 선형 + 가로 이동을 썼고, `active:scale` 계열 대신 배경 전환만 쓴다.
- `prefers-reduced-motion: reduce`에서 진입, 스태거, 펄스, 드로어 전환을 모두 끈다.
