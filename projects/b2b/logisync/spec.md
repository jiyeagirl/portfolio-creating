# LogiSync - Product Spec

## 1. Overview

LogiSync는 물류센터별로 서로 다른 WMS와 작업 시스템에서 발생하는 입고, 출고,
재고 데이터를 자동으로 수집하고, 정합성 검증과 표준화를 거쳐 하나의 공통 데이터
구조로 통합하는 물류 데이터 수집 및 통합 관리 시스템이다.

기존에는 센터마다 사용하는 시스템이 달라 입고, 출고, 재고 데이터를 각각 따로
확인해야 했고, 시스템마다 상품코드와 데이터 형식이 달라 전체 물류센터의 운영
현황을 한눈에 파악하기 어려웠다. LogiSync는 센터별 원천 데이터를 수집 시점과
원천 정보까지 함께 기록하고, 식별키 기반 중복 검증과 누락, 오류 데이터 분류로
신뢰할 수 있는 데이터만 통합한다. 센터별로 상이한 상품코드, 상품명, 단위,
상태값을 표준화해 본사가 전체 센터의 물류 현황을 동일한 기준으로 조회하고
관리할 수 있도록 하며, 통합 데이터에서 원천 데이터까지 역추적할 수 있는 구조로
데이터에 대한 신뢰도를 확보하는 것을 목표로 한다.

- **플랫폼**: Web(본사 통합 관리 콘솔)
- **디자인시스템**: farrari_compact
- **수행기간**: 2026.01 ~ 2026.04 (목 데이터의 모든 날짜는 이 범위 안. 화면 기준 시각은 2026.04.15 수 14:36)
- **포지셔닝**: 센터별로 흩어진 WMS, 작업 시스템 데이터를 하나로 모으는
  데이터 수집 및 통합 관리 기반의 물류 운영 관리 서비스
- **제작 목적**: 포트폴리오용 고품질 UI 목업. 실제 WMS 연계, 데이터 수집
  배치, 표준화 엔진, API 서버, 백엔드는 구현하지 않으며 mock 데이터로 화면
  완성도를 우선한다.

## 2. Non-goals

- 실제 물류센터 WMS, 작업 시스템과의 데이터 연계 및 자동 수집
- 실제 중복 검증, 정합성 검사, 데이터 재처리 로직
- 실제 상품코드 매핑, 표준화, 데이터 형식 변환 엔진
- 실제 데이터 수신, 조회 API 서버 및 ERP, SCM 연동

## 3. Information Architecture

1. **데이터 수집 및 연계** : 물류센터별 입고, 출고 데이터 자동 수집, 센터별
   운영 시스템 연계, 상품, 거래처, 재고 데이터 수집, 수집 주기 및 연계 상태
   관리, 수집 데이터 원천 및 수집 시점 기록

   보여줄 포인트: 센터마다 다른 WMS가 하나의 수집 파이프라인으로 연결되는
   구조를 센터별 연계 카드와 수집 주기, 마지막 수집 시각으로 한눈에 표현

2. **데이터 정합성 및 중복 관리** : 식별키 기반 중복 데이터 검증, 누락 데이터
   확인, 비정상, 오류 데이터 분류, 수집 실패 이력, 미수집 데이터 재처리.
   정상, 중복, 누락, 오류 상태를 필터로 나눈 검증 결과 리스트로 구성한다.

3. **데이터 표준화 및 통합** : 센터별 상이한 상품코드 통합, 상품명 및 단위
   표준화, 입고, 출고 상태값 통일, 데이터 형식 변환, 공통 데이터 구조 변환

   센터 A의 `SKU-0192`, 센터 B의 `P10192`, 센터 C의 `192-KR`이 하나의 표준
   상품코드로 묶이는 매핑 테이블과, 원천 필드가 공통 스키마로 변환되는
   전후 비교 뷰를 함께 보여준다.

4. **통합 물류 데이터 관리** 이 프로젝트의 핵심 화면, 전체 물류센터 통합 조회,
   센터별 입출고 조회, 상품별 입출고 이력, 기간별 조회, 원천 데이터와 통합
   데이터 간 추적

   통합 데이터 1건을 선택하면 우측 패널에 수집 원천 센터, 원천 시스템, 수집
   시점, 원본 레코드, 적용된 표준화 규칙까지 단계별로 역추적하는 흐름으로
   표시한다.

5. **물류비 자동 정산** : 수집된 입고, 출고 데이터를 기준으로 물류비를 자동
   산정하고 기간별 정산 내역을 조회한다.
   - 정산 기준: 입출고 데이터의 수량, 중량, 운송 건수를 기준으로 쓰고, 물류센터
     및 거래처별 기본 단가를 적용한다. 정산 기간 기준으로 입출고 데이터를 집계한다.
   - 자동 산정: 정산 기간을 선택하면 해당 기간 입출고 데이터를 집계하고
     `정산 대상 수량 × 적용 단가`로 물류비를 계산한다. 기본 물류비와 추가 비용을
     구분하고, 총 물류비와 정산 대상 건수를 함께 표시한다.
   - 정산 내역 조회: 정산 기간, 물류센터, 거래처별로 정산 금액, 대상 건수, 적용
     단가를 조회한다. 정산 건을 선택하면 금액을 산출한 입출고 데이터를 상세
     조회하고, 원천 센터와 수집 시점 등 원본 데이터 정보를 확인한다.
   - 정산 상태: 예정, 검토, 확정 순으로 관리하고, 확정 이후에는 해당 기간
     데이터 기준으로 확정 금액을 보존한다.
   - 데이터 흐름: 입출고 데이터 수집, 정산 대상 집계, 단가 적용, 물류비 자동
     산정, 정산 내역 조회

6. **재고 현황 관리** : 센터별, 상품별 재고 현황, 입고, 출고에 따른 재고 변동
   이력, 기간별 재고 변화, 재고 부족 및 이상 데이터 확인. 현재 재고, 안전
   재고, 변동량, 이상 여부를 함께 보여준다.

7. **데이터 수집 상태 모니터링** : 센터별 연계 상태, 최근 수집시간, 수집 성공,
   실패 건수, 오류 발생 현황, 수집 지연 및 장애 확인. 정상, 지연, 장애 상태를
   색상으로 구분한 센터별 상태 보드 형태로 구성한다.

8. **통합 데이터 조회 및 통계** : 일별, 주별, 월별 물류량, 센터별 물류량 비교,
   상품별 입출고량 분석, 시간대별 물류량, 기간별 추이. Bar, Line, Heatmap
   그래프를 조합한 그래프 위주 화면이다.

9. **데이터 연계 API 관리** : 외부 시스템 데이터 수신 API, 통합 데이터 조회
   API, 상품 및 센터 정보 연계 API, 연계 이력 관리, 향후 ERP, SCM 연동 지원.
   API 명, 엔드포인트, 호출 수, 최근 호출 시각, 상태를 포함한 테이블 중심
   화면이다.

핵심 화면은 1. 데이터 수집 및 연계와 4. 통합 물류 데이터 관리이며, 그중에서도
4. 통합 물류 데이터 관리가 이 프로젝트의 대표 화면이다.

## 4. Key Focus

- 센터마다 다른 WMS, 작업 시스템의 입출고, 재고 데이터를 하나의 수집
  파이프라인으로 모아 본사가 전체 물류센터 현황을 한 화면에서 파악하는 경험
  설계
- 식별키 기반 중복 검증과 누락, 오류 데이터 분류, 재처리 흐름으로 통합되는
  데이터의 정합성을 구조적으로 보장
- 상이한 상품코드, 상품명, 단위, 상태값을 공통 데이터 구조로 표준화해 센터 간
  데이터를 동일한 기준으로 비교, 분석할 수 있도록 지원
- 통합 데이터에서 원천 센터, 원천 시스템, 수집 시점까지 역추적할 수 있는
  구조로 데이터에 대한 신뢰도 확보
- 수집 상태, 지연, 장애를 실시간 모니터링하고 API 기반 연계 구조를 제공해
  향후 ERP, SCM 등 내부 시스템으로 확장 가능한 데이터 허브 경험 제공
