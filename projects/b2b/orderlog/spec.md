# OrderLog - Product Spec

## 1. Overview

OrderLog는 원청, 납품처, 거래처가 발주 1건을 하나의 타임라인 스레드에서
실시간으로 함께 기록하고 확인하는 스냅샷 기반 B2B 수발주 관리 시스템이다.

엑셀과 수작업 위주의 기존 관리 방식에서 빈번하게 발생하는 마감 금액 불일치를
스냅샷 단가 고정 기능으로 원천 차단하고, AI가 중복 발주나 비정상적인 단가 변동을
사전 감지해 사람이 놓치는 실수를 최소화한다. 금융, 거래 데이터를 다루는 서비스
특성에 맞춰 세밀한 권한 제어와 보안 로그인을 설계했으며, 사용자가 직접 오류를
찾던 방식에서 시스템이 먼저 위험도를 매겨 제안하는 구조로 전환해 담당자의 업무
피로도를 낮추는 것을 목표로 한다.

- **플랫폼**: Web(관리자, 원청, 납품처, 거래처 통합 콘솔)
- **포지셔닝**: 엑셀, 수작업 발주 관리를 대체하는 스냅샷 기반 B2B 수발주,
  거래 관리 서비스
- **제작 목적**: 포트폴리오용 고품질 UI 목업. 실제 AI 이상 감지 로직, 알림톡,
  SMS 발송, 결제, 백엔드는 구현하지 않으며 mock 데이터로 화면 완성도를
  우선한다.

## 2. Non-goals

- 실제 AI 이상 발주 감지, 위험도 산정 로직
- 실제 알림톡, SMS, 앱 푸시 발송 및 발송 결과 연동
- 실제 결제, 정산 처리
- 실제 SMS 2단계 인증 및 외부 인증 시스템 연동

## 3. Information Architecture

1. **보안 로그인 및 권한 선택** : SMS 2단계 인증, 권한별 로그인(마스터, 원청,
   납품처, 거래처), 최근 로그인 기록, 접근 권한 안내

   보여줄 포인트: 금융 서비스 같은 신뢰감 있는 로그인 화면, 권한에 따라 다른
   대시보드로 이동

2. **통합 대시보드** 프로젝트 대표 화면, 오늘 발주 현황, 진행중 발주, AI 이상
   발주 건수, 긴급 알림, 거래 금액 요약, 최근 활동, 우측 AI 위험 TOP5, 최근
   스레드, 금일 알림

3. **발주 상세(스레드 타임라인)** 이 프로젝트의 핵심 화면, 발주 생성, 수정
   이력, 댓글, 파일 첨부, 승인 요청, 담당자 변경

   카카오톡처럼 아래로 이어지는 타임라인으로, 원청 발주 등록부터 납품처 납기
   변경 요청, 거래처 승인 완료, AI 단가 변동 감지까지 하나의 흐름으로 표시한다.

4. **품목 관리 및 단가 스냅샷** : 3단계 품목 분류, 단가 수정, 예약 적용일,
   영향도 미리보기, 스냅샷 생성. 현재가, 예약가, 적용일, 영향받는 진행중 발주
   건수를 함께 보여준다.

5. **AI 이상 발주 센터** AI가 감지한 위험 건만 모아서 보여주는 화면, 중복
   발주, 단가 급변, 권한 이상, 위험도, 검토 완료. 카드형 리스트로 구성한다.

6. **거래 통계 대시보드** : 거래처별 매출, 월별 발주, 품목 비율, 미해결 건,
   AI 발생 추이. Bar, Line, Donut 그래프를 조합한 그래프 위주 화면이다.

7. **스마트 알림 센터** : 알림톡, SMS, 앱 알림, 심각도(일반, 주의, 긴급) 표시,
   발송 로그 조회

8. **관리자(CMS)** : 계정 관리, 권한 관리, 거래처 관리, AI 룰 관리, 로그 조회.
   회사명, 권한, 최근 로그인, 상태를 포함한 테이블 중심 화면이다.

핵심 화면은 2. 통합 대시보드와 3. 발주 상세(스레드 타임라인)이며, 그중에서도
3. 발주 상세가 이 프로젝트의 대표 화면이다.

### 관리자(CMS)는 별도 프로젝트

위 8번 관리자(CMS)는 이 프로젝트 안에 없다. `projects/b2b/orderlog-admin/`
(`/b2b/orderlog-admin`)로 완전히 분리했다 — 같은 b2b 카테고리의
`assetflow` / `assetflow-admin`과 같은 구성이다. 원청·납품처·거래처가 쓰는 이
콘솔에는 마스터(관리자) 로그인 옵션과 사이드바 "관리자" 진입점을 두지 않는다.
관리자 콘솔은 별도 로그인 화면으로 마스터 계정만 인증하며, 실제 화면 코드는
`projects/b2b/orderlog/components/admin/`에 있고 `orderlog-admin/src/index.tsx`는
URL을 하나 더 얻기 위한 엔트리다.

## 4. Key Focus

- 발주 1건의 생성부터 승인까지 전 과정을 하나의 스레드 타임라인에 기록해
  원청, 납품처, 거래처가 동일한 맥락을 실시간으로 공유하는 경험 설계
- 스냅샷 단가 고정 기능으로 발주 시점과 마감 시점의 단가 불일치를 구조적으로
  차단
- AI가 중복 발주, 단가 급변, 권한 이상을 먼저 감지해 위험도를 제시하는 구조로
  전환해 담당자가 오류를 직접 찾던 방식에서 벗어나도록 지원
- 거래, 금융 데이터를 다루는 서비스 특성에 맞춘 권한별 접근 제어와 신뢰감
  있는 보안 로그인 경험 제공
- 통계, 알림 데이터를 단순 조회가 아닌 심각도 기반 알림과 시각화된 리포트로
  가공해 빠른 의사결정으로 이어지는 경험 제공
