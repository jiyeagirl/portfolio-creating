# BuildBid - Product Spec

## 1. Overview
- 플랫폼: Web (판매자, 바이어, 관리자) + Mobile (검수원 전용)
- 포지셔닝: 개인 및 기업 보유 건설장비를 국내외 매입업체와 연결하는 2단계 역경매 기반 중고 건설장비 거래 플랫폼
- 개발 기간: 2024.05 ~ 2024.07
- 제작 목적: 포트폴리오용 UI 목업, 백엔드 미구현 (AI 예상 견적, 입찰 매칭, 검수 결과 반영은 목업 데이터로 표현)

## 2. Non-goals
- 실제 AI 시세 산출 엔진 연동. 예상 거래가는 더미 데이터로 표현
- 실제 결제/정산 처리 및 계좌 연동
- 실제 위치 기반 검수원 배정 로직(지도 API 연동)
- 실시간 입찰 알림의 서버 푸시 구현
- 국내외 매입업체 실 거래 매칭 로직

## 3. Information Architecture

### 판매자 Web
1. 대시보드: 진행 중 거래 현황, 최근 등록 장비, 입찰 진행 현황, 거래 완료 내역, 알림
2. 장비 등록(AI 예상 견적): 장비 정보와 사진, 상태 입력, AI 예상 거래가 조회, 등록 요청. 핵심은 AI 자동 견적 엔진
3. 입찰 관리: 1차 입찰 현황, 참여 바이어와 입찰가, 검수 진행 상태와 결과 확인, 2차 최종 입찰 결과, 낙찰자 선택. 핵심은 2단계 역경매 프로세스
4. 거래 완료: 계약 정보, 거래 상태, 거래 이력, 정산 현황

### 바이어 Web
5. 장비 목록: 장비 검색, 조건별 필터, 예상 시세, 관심 등록, 입찰 가능 여부
6. 장비 상세와 입찰: 장비 상세 정보와 사진, AI 예상 시세, 1차 입찰 참여, 검수 리포트 확인, 2차 최종 입찰 참여
7. 낙찰과 거래 관리: 낙찰 결과, 계약 진행, 거래 내역, 거래 완료

### 검수원 Mobile은 별도 프로젝트

위 8~9번 검수원 Mobile은 이 프로젝트 안에 없다. `projects/b2b/buildbid-inspector/`
(`/b2b/buildbid-inspector`)로 완전히 분리했다 — PhoneFrame 단일 기기 캔버스(app 프리셋)와
사이드바 웹 셸(web 프리셋)은 기기 패러다임이 근본적으로 달라 한 프로젝트에 둘 수 없다.
상세 IA는 그쪽 `spec.md`에 있다.

### 관리자 Web

10. 관리자 대시보드: 거래 현황, 회원 현황, 검수 대기 건수, 진행 중 입찰, 거래 통계, 최근 알림
11. 검수와 거래 관리: 장비 등록 승인, 검수원 배정, 검수 결과 승인, 입찰 진행 관리, 낙찰 처리, 거래 완료 처리, 분쟁 및 거래 취소 관리. 핵심은 운영자가 거래 전 과정을 통합 관리하는 백오피스

관리자 Web은 이 프로젝트 안에 있지만 별도 URL이다. `projects/b2b/buildbid-admin/`
(`/b2b/buildbid-admin`)는 URL을 하나 더 얻기 위한 얇은 엔트리이고, 실제 화면 코드는
`projects/b2b/buildbid/components/admin/` 안에 있다(assetflow-admin과 같은 구조).

## 4. Key Focus
- AI 자동 견적 엔진과 2단계 역경매를 결합해 시세가 불투명한 중고 건설장비 거래를 투명하고 공정한 프로세스로 설계
- 판매자, 바이어, 검수원, 관리자 네 역할이 명확히 분리된 화면과 상태 흐름으로 이어지는 통합 플랫폼 구조 강조
- 현장 검수 리포트가 1차 입찰과 2차 최종 입찰 사이에서 실제로 거래 의사결정에 반영되는 신뢰 구조 시각화
- 관리자 백오피스에서 등록 승인부터 검수원 배정, 낙찰, 정산, 분쟁 처리까지 전 과정을 통제하는 운영 중심 설계
