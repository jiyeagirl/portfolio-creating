# AssetFlow — Product Spec

## 1. Overview

AssetFlow는 기업이 보유한 노트북, 서버, 네트워크 장비 등 IT 자산을 전문 리셀러와
연결하는 2단계 역경매 기반 B2B 거래 플랫폼이다.

기업의 노후 IT 자산은 대부분 폐기되거나 낮은 가격에 일괄 매각되고, 객관적인 상태
평가 기준이 없어 적정 매입가를 산정하기 어렵다. AssetFlow는 자산 등록 시 AI 자동
시세를 제공하고, 현장 검수를 거쳐 다수 리셀러가 참여하는 2단계 역경매로 최적의
매각가를 확보하도록 한다. 기업, 리셀러, 검수원, 관리자 4개 역할을 하나의 플랫폼으로
통합했다.

- **플랫폼**: Web (Enterprise Dashboard / B2B Platform)
- **포지셔닝**: 자동 시세 산출 + 2단계 역경매 + 검수 기반 신뢰 거래를 결합한
  기업 IT 자산 처분 플랫폼

## 2. Information Architecture

### 2.1 기업(판매자)용 웹사이트

1. **메인 대시보드** — 보유 자산 현황, 진행 중인 거래·입찰, 최근 등록 자산,
   거래 진행 타임라인, 예상 매각 금액, 알림/공지
2. **자산 등록** — 자산 정보 입력, 제조사·모델명 자동검색, 사진 업로드,
   엑셀 일괄 등록, AI 자동 시세 산출
3. **자산 상세 / 자동 견적** — 시세 산출 근거, 감가 요인 분석, 검수 신청
4. **1차 입찰** — 리셀러 견적 비교, 실시간 입찰 현황, 입찰 마감 시간
5. **검수 결과 & 최종 입찰** — 검수 리포트, 상태 변화 비교, 2차 최종 입찰,
   거래 확정
6. **거래 관리** — 거래 단계별 상태, 계약 진행 현황, 거래 문서 다운로드
7. **리포트 / 거래 분석** — 월별 거래 금액, 자산 유형별 비율, 평균 낙찰가 분석
8. **마이페이지 / 기업 정보** — 기업 정보, 담당자 관리, 인증 정보, 알림 설정

### 2.2 관리자 콘솔은 별도 영역

운영자용 화면은 기업용 웹사이트와 분리된 백오피스로 구성한다.

1. **관리자 대시보드** — 전체 거래 현황, 진행 중 입찰 수, 검수 진행 현황
2. **기업 | 리셀러 관리** — 가입 승인, 등급 관리, 이용 제한
3. **자산 | 검수 관리** — 검수 배정, 결과 승인, 상태 변경 이력
4. **입찰 | 거래 관리** — 입찰 모니터링, 거래 승인/취소, 분쟁 처리
5. **시세 | 운영 정책 관리** — AI 시세 산출 기준, 감가 기준, 수수료 정책

## 3. Key Focus

- 자동 시세 산출과 2단계 역경매를 결합해 기업이 최적의 매각가를 확보할 수 있는
  거래 프로세스 설계
- 기업 · 리셀러 · 검수원 · 관리자 역할 기반 구조로 사용자별 업무 흐름과 운영
  효율성 강화
- 검수 결과 기반의 최종 입찰로 거래 투명성과 신뢰성 확보
- 자동 견적 · 입찰 · 검수 · 거래 현황을 통합 관리하는 관리자 백오피스 구축
