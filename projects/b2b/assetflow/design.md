# AssetFlow — Design Notes

## 적용 규칙

- `디자인시스템: design-systems/vercel_compact.md` (spec.md 지정).
- 워크스페이스 `CLAUDE.md`의 UI Generation Rules가 항상 먼저다. 그래서 타이포는
  Pretendard 고정 — vercel_compact가 지정한 Geist는 쓰지 않는다. 모노스페이스는
  UI 폰트 금지 규칙 대상이 아니라 그대로 유지하고, 자산 코드·금액·일시처럼 자릿수를
  맞춰 읽는 값에만 `.af-mono`로 적용한다. 본문에는 모노를 쓰지 않는다.
- `스타일:` 지정이 없어서 style-variant 스킬(minimalist-ui 등)은 적용하지 않았다.
- 모바일 앱이 아니라 웹 콘솔이므로 `components/shared/phone-frame.tsx`는 쓰지 않는다.

## 토큰 (styles/assetflow.css, `.assetflow` 스코프)

vercel_compact의 색·반경·간격을 그대로 옮겼고 새 색을 만들지 않았다.

| 역할 | 값 |
| --- | --- |
| primary / ink | `#171717` |
| body | `#4d4d4d` |
| mute | `#888888` |
| hairline | `#ebebeb` (1px 고정) · hairline-strong `#a1a1a1` |
| canvas | `#ffffff` · soft `#fafafa` · soft-2 `#f5f5f5` |
| link | `#0070f3` · deep `#0761d1` · soft `#d3e5ff` |
| warn | `#f5a623` · soft `#ffefcf` · deep `#ab570a` |
| error | `#ee0000` · soft `#f7d4d6` · deep `#c50000` |

- 반경은 6px(버튼·입력·소형 블록) / 8px(카드) / full(배지)만. `rounded-full`을 큰
  컨테이너에 쓰지 않는다.
- 폰트 굵기 천장 600. 700/800은 쓰지 않는다.
- 그림자는 미세한 스택(`--af-shadow`, `--af-shadow-pop`)만. 단일 두꺼운 drop-shadow 금지.

### 상태 배지 톤

시스템에 있는 색만 써서 5단계로 고정했다. 초록을 새로 만들지 않고 "완료"는 잉크 채움으로 표현한다.

| 톤 | 색 | 쓰이는 상태 |
| --- | --- | --- |
| `neutral` | 회색 | 작성 중, 견적 완료 |
| `info` | 파랑 | 1차 입찰, 최종 입찰, 회수 대기, 정산 대기 |
| `warn` | 앰버 | 검수 중, 계약 진행, 승인 대기, 마감 임박 |
| `ink` | 잉크 채움 | 거래 확정, 정산 완료, 거래 완료 |
| `danger` | 빨강 | 취소, 유찰, 분쟁, 이용 제한 |

`Stat`의 delta는 `+`/`-`로 시작할 때만 색을 준다. "4건", "조치 필요" 같은 보조 라벨을
빨갛게 칠하면 문제가 있는 것처럼 읽힌다.

## 화면 구성

## 표 폭 규칙 (반복되는 함정)

`Table`은 `overflow-x-auto` 안에 들어 있어서 컬럼 폭보다 넓으면 **마지막 열이 조용히
잘린다.** 1440px에서 사이드바를 뺀 좁은 컬럼이 약 600px이라 기본 `minWidth`를 560으로
잡았다. 열이 6개를 넘으면 값을 보조 줄로 내리고 열 수를 줄인다. 열을 늘리면 마감 시각,
액션 버튼처럼 가장 중요한 정보가 먼저 사라진다.

좌우 컬럼 높이가 다른 그리드는 `items-start`를 준다. 없으면 짧은 쪽 카드가 늘어나
아래쪽이 텅 빈 채로 캡처된다.

## 차트

- 계열이 하나면 범례 없이 제목이 계열을 설명한다. 강조 막대만 ink, 나머지는 `#ebebeb`.
- 자산 유형별 비율은 파이 대신 값으로 정렬된 가로 막대 + 직접 라벨. 색은 단일 색조의
  명도 단계(`--af-chart-1` ~ `-5`)만 쓴다.
- 자동 시세 대비 낙찰가는 단위가 같아(대당 원) 축을 하나만 쓴다. 이중 축은 쓰지 않는다.
- 감가 요인 분석만 0을 가운데 둔 양방향 막대를 쓴다. 부호 자체가 정보라 +는 파랑,
  -는 빨강으로 나눈다.

## 익명화

기업·리셀러·제조사 모두 알파벳 기반이다(A테크놀로지, B소재, C페이 / D리커머스,
E테크사이클, F아이티리퍼브, G디바이스, H리유즈, J글로벌트레이드 / K전자, M테크,
N시스템즈, P네트웍스, S디스플레이). 사람 이름, 사업자번호, 연락처는 실제처럼 보이지만
가상이다.

## 구현 범위

mock 데이터만 쓴다. 인증, 결제, AI 시세 산출 로직, 백엔드 연동은 구현하지 않았다.
자산 등록 화면의 실시간 시세 계산은 입력값에 반응하는 mock 계수 곱이며, 실제 등록
자산(a1: 신품 1,480,000원 → 자동 시세 412,000원)과 비슷한 값이 나오도록 계수를 맞췄다.
