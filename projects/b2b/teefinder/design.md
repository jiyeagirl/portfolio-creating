# TeeFinder 디자인

## 아키타입

- **앱 홈: A7 캘린더 축 (Calendar Spine).** 이유: 핵심이 "날짜별 빈 티타임 조회"다. 상단에 주간 날짜 스트립(날짜별 빈 티타임 수), 아래에 선택한 날짜의 골프장별 아젠다가 세로로 흐른다. 세로축이 카테고리가 아니라 시간이다. spec이 하단 탭 4개(홈 / 골프장 / 알림 / 내 정보)를 지정했으므로 A7의 "탭 최대 3" 권고는 spec이 이긴다.
- **배제한 후보 1, A1 섹션 스택:** 신규 배정 금지(12개 포화), 그리고 홈에 "카테고리별 가로 스크롤 카드 로우"가 필요한 도메인이 아니다.
- **배제한 후보 2, A4 맵 캔버스:** spec의 핵심 차별점이 위치가 아니라 통합 조회와 자동 로그인이다. 골프장은 지역 필터 한 줄로 충분하다.
- **관리자 셸: C2 라이트 워크벤치.** 이유: 운영자는 회원권사 하나(단일 테넌트)를 운영하고 IA 항목이 5개(가입 승인 / 회원 관리 / 골프장 설정 / 수집 모니터링 / 푸시 발송)다. spec이 "좌측 내비게이션"을 지정했다.
- **배제한 후보 (관리자) C1 다크 레일:** 이미 10개 점유이고 테넌트를 가로지르는 슈퍼관리자가 아니다. **C3 상단 바:** spec이 좌측 내비를 지정했다.
- **이 아키타입에서 쓰지 않는 부품:** `SectionHead`(제목 + 더보기), 카테고리별 가로 스크롤 카드 로우, 히어로 배너, 그리팅 헤더. 시간 칩의 가로 스크롤은 카드 안의 칩 줄이라 허용한다(spec 지정). 관리자는 다크 레일, 헤더 전역 시계, KPI 카드 4개 병렬을 쓰지 않는다.
- **앱과 관리자의 분리:** 회원 앱은 `/b2b/teefinder`, 관리자 웹은 `/b2b/teefinder-admin`으로 URL이 따로다. 전환 스위치는 두지 않는다. `-admin`에는 자체 docs를 두지 않고 이 프로젝트의 토큰을 상속한다.

## 적용 규칙

해석: 회원 전용 골프 빈 티타임 통합 앱과 운영 콘솔 for 회원권을 가진 50대 안팎 회원(큰 글자, 한 손 조작)과 매일 수집 상태를 보는 운영자. 앱 다이얼 V4 / M3 / D5, 관리자 다이얼 V3 / M2 / D7.

- 읽은 skill: `mockup-craft` SKILL.md, `references/anti-slop.md`, `app.md`, `console.md`. `스타일:`, `디자인시스템:`, `프리미엄디테일:` 줄은 없다.
- 앱 V4: 사용자층이 시간표를 빠르게 읽어야 해서 파격보다 정렬 일관성을 택했다. M3: 눌림, 시트, 푸시 배너 하강, 웹뷰 단계 진행 외에는 움직이지 않는다(홈 아젠다 스태거 없음). D5: 일반 앱 밀도(블록 간 16~24px).
- 관리자 V3 / M2 / D7: 콘솔 목록 3~4 / 2 / 8과 콘솔 상세 3 / 2 / 6의 중간. 표와 폼이 반반이라 D7.
- 앱의 의미 상태: 카드 안에 카드 금지. 날짜 스트립은 면 없이 하단 선택 표시, 골프장 아젠다는 `divide-y` 그룹, 시간 칩만 면을 가진다.

## Tokens, 팔레트

팔레트 구성 4: **틴티드 뉴트럴.** 무채색이 아니라 그린 슬레이트를 머금은 뉴트럴이고, 계층은 명도로 만든다. 브랜드 잉크(딥 스프루스)는 주 버튼, 선택된 날짜 하나에만 쓰고 넓은 면에 쓰지 않는다. 이유: 도메인은 골프장이지만 상태색(초록 정상, 파랑 취소티, 주황, 빨강, 회색)이 화면 전체에서 의미를 가지므로 브랜드 액센트가 하나 더 붙으면 상태 초록과 충돌한다. 같은 b2b의 logisync가 4를 썼지만 웜 스톤 + 다크 레일이고, 여기는 쿨 그린 슬레이트 + 라이트 레일이라 인상이 다르다.

`styles/teefinder.css` 의 `.teefinder` 스코프, 접두어 `--tf-`.

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| canvas | `#f3f5f2` | 앱 배경, 관리자 본문 |
| surface | `#ffffff` | 시트, 폼, 표 |
| soft | `#e9eee8` | 칩, 입력 바닥, hover |
| line | `#dce2da` | 헤어라인 |
| ink / ink-2 / ink-3 | `#18231d` / `#46554b` / `#64736a` | 본문 3단 (ink-3도 흰 바탕 AA) |
| brand | `#23402f` | 주 버튼, 선택 날짜, 활성 탭 |
| rail | `#eaefe8` | 관리자 레일 (밝은 면) |

상태색(앱과 관리자 모두 고정): 초록 정상/승인/예약 가능, 주황 승인 대기/점검 필요, 빨강 반려/오류/로그인 실패, 회색 이용 정지/마감, 파랑 인증 필요/취소티. 배지는 파스텔 바닥 + 짙은 글자, 취소티만 채운 파랑.

## Shape

- 앱: 시트와 카드 16px, 시간 칩 10px, 버튼 14px, 입력 12px. 알약(999px)은 시간 칩과 상태 배지가 아닌 주 CTA에만 쓰지 않는다(CTA는 14px 모서리).
- 관리자: 패널 8px, 입력과 버튼 6px, 배지 4px. 앱보다 각진 이유: 콘솔은 표 밀도가 우선이고, 앱의 부드러움과 대비를 둔다.
- 그림자: 시트와 푸시 배너만 `0 1px 2px, 0 8px 24px` 옅은 2단. 카드에는 그림자 없이 헤어라인.

## Typography

Pretendard 단일. 앱은 연령대를 고려해 **본문 16px / 24px / 400**(번진 값 15/22 회피), 캡션 13px, 시간 칩 17px 600 `tabular-nums`, 화면 제목 22px 700 자간 -0.02em. 탭 라벨은 11.5px(번진 10.5 회피). 관리자는 본문 13.5px / 20px, 표 셀 13px, 캡션 12px, 페이지 제목 20px 600.

앞선 프로젝트와 다르게 한 것: 본문 16/24(번진 15/22와 다름), 탭 라벨 11.5px, 관리자 본문 13.5/20.

## 사진 매핑

골프장 사진은 쓰지 않는다. 맞는 사진을 직접 확인해 매핑할 수 없고 비슷한 사진을 억지로 넣지 않는다는 규칙 때문이다. 골프장 행의 시각 요소는 골프장 이름 글자의 모노그램 타일(로고 자리에 허용된 용도)이다. 상세 화면은 사진 없이 코스 구성(레이크 / 힐 / 밸리 칩)과 잔여 티타임 수로 구성한다. 사진 요청은 최종 요약에 둔다.

## 기기 프레임 안쪽 규칙

- 좌우 거터 20px가 화면 전체의 좌측 정렬선이다. 터치 타깃 44px 이상, 주 CTA 높이 52px.
- 하단 탭바(앱 셸 하단)와 고정 CTA 바는 불투명 `bg-surface`, `backdrop-blur` 없음. 탭바는 홈 인디케이터 34px 위가 아니라 그 영역을 포함해 `pb-[34px]`.
- 푸시 배너는 상태바 아래 `top-[52px]`에서 내려오고 가장자리에 붙지 않는다(양옆 12px 여백).
- 웹뷰 화면은 상단 주소 표시줄(상태바 아래)과 닫기 버튼이 있고 탭바가 없다.
- 로그인 / 승인 대기 화면은 탭바가 없다.

## 셸 레이아웃 (관리자)

- 레일 248px, 밝은 면(`--tf-rail`) + 우측 헤어라인. 헤더 56px, 캔버스와 같은 배경 + 하단 헤어라인, 좌측에 회원권사 스위처(고정 표기 "A회원권 운영"), 우측에 운영자 계정. 헤더에 시계 없음.
- 본문은 풀블리드(`max-w-none`), 마스터-디테일 화면은 좌 목록 + 우 패널.
- `lg`(1024px) 미만에서는 레일이 상단 가로 스크롤 세그먼트로 접힌다(드로어 없음).
- 사용자 콘솔이 따로 없으므로 사용자 화면 셸과의 차이는 해당 없음. 앱과 관리자를 전환하는 스위치는 이 목업의 최상단 바 하나이고, 앱 화면 안에는 관리자 진입점이 없다.

## 표 밀도, 컬럼 예산

1440px에서 레일 248을 뺀 본문 1192, 좌우 패딩 32씩 빼면 표 영역 1128px. 우측 상세 패널을 열면 약 760px.

- 열 상한 6. 패널이 열리는 화면(승인, 회원)의 표는 5열 이하.
- 가입 승인 표(패널 열림 기준 760px): 이름 / 연락처, 회원권 번호, 신청일, 상태 4열. 연락처는 이름 아래 보조 줄.
- 회원 관리 표(패널 열림): 이름 + 연락처 보조 줄 200, 회원권 정보 180, 가입일 112, 상태 96, 합계 약 588 + 패딩. 최소폭 640.
- 수집 모니터링 골프장 표(풀폭): 골프장 + 지역 보조 줄 260, 24시간 성공률 (%) 120 우측 정렬, 마지막 성공 140, 상태 112, 최소폭 760.
- 골프장 설정은 좌 목록 320 + 우 폼, 표 없음. 폼 필드는 2열 그리드.
- 행 높이 52px(셀 세로 패딩 12px), 한 페이지 10행.

## Motion

- 화면 전환(앱 탭, 서브 화면): 280ms `cubic-bezier(0.25, 0.8, 0.3, 1)` 페이드 + translateY 12px. 스태거 없음. (앞선 프로젝트의 420ms expo-out과 다름)
- 시트와 푸시 배너: 320ms 같은 이징으로 translateY. 관리자 패널 슬라이드: 220ms.
- 눌림: 앱 `translateY(1px)` + 배경 톤 한 단계. 관리자는 hover 배경 톤만. (scale 계열과 다름)
- 웹뷰 단계 진행: 선형 진행 막대. `prefers-reduced-motion`에서 전환 애니메이션을 끄고 진행 막대는 즉시 단계 전환.
