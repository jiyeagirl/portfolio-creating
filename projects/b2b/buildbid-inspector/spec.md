# BuildBid Inspector - Product Spec

## 1. Overview
- 플랫폼: Mobile (검수원 전용 앱)
- 포지셔닝: BuildBid 플랫폼의 현장 검수원이 오늘의 검수 일정을 확인하고, 현장에서 장비 상태를 체크리스트·사진·등급으로 기록해 제출하는 전용 모바일 앱
- 제작 목적: 포트폴리오용 UI 목업, 백엔드 미구현 (검수 일정 배정, 제출 결과 반영은 목업 데이터로 표현)
- 본 프로젝트는 `projects/b2b/buildbid/spec.md`의 "8. 검수원 Mobile" IA를 별도 앱으로
  분리한 것이다 — 웹 콘솔(판매자/바이어)과 기기 패러다임이 근본적으로 달라
  (PhoneFrame 단일 기기 vs 사이드바 웹 셸) 같은 프로젝트에 둘 수 없다. 색상 토큰과
  브랜드는 buildbid 본 프로젝트와 공유하지 않고 이 프로젝트 정체성에 맞게 새로 정의한다.

## 2. Non-goals
- 실제 위치 기반 검수원 배정 로직(지도 API 연동)
- 실시간 입찰 알림의 서버 푸시 구현
- 실제 사진 업로드 서버 연동(선택한 사진은 로컬 상태로만 표현)

## 3. Information Architecture

1. 검수 일정: 오늘 검수 일정 리스트, 판매자 정보(업체명·담당자·연락처), 장비 정보 요약,
   위치 확인(주소·지도 썸네일), 검수 시작
2. 검수 리포트 작성: 항목별 체크리스트(엔진/유압/전기/외관 등), 장비 사진 촬영(다중),
   손상 부위 기록(사진 마킹 또는 위치 태그 + 메모), 특이사항 작성, 장비 상태 등급 입력
   (S/A/B/C 등급), 검수 완료 제출

## 4. Key Focus
- 이동 중·현장에서 한 손으로 조작 가능한 리스트 우선 UI, 큰 터치 타깃
- 체크리스트 → 사진 → 등급 → 제출로 이어지는 명확한 단계형 플로우
- 제출 직전 요약 화면으로 누락 항목을 스스로 확인할 수 있게 해 신뢰도 있는 검수 리포트라는
  인상을 준다
