# GenderInsight - Product Spec

## 1. Overview
- 플랫폼: 반응형 Web (관리자 페이지 + 참여자 화면)
- 포지셔닝: 기업 및 공공기관을 대상으로 성인지감수성 진단을 실시하고, 응답 데이터를 분석해 개인 및 조직 단위 PDF 리포트를 제공하는 B2B 성인지감수성 진단 플랫폼
- 수행기간: 2025.11 ~ 2026.02 (목업에 사용되는 모든 날짜/기간 데이터는 이 범위 내에서 표현)
- 제작 목적: 포트폴리오용 UI 목업, 백엔드 미구현 (통계 분석, AI 결과 요약, PDF 리포트 생성, 이메일 발송은 목업 데이터로 표현)

## 2. Non-goals
- 실제 통계 분석 엔진 및 조직/부서/직급별 집계 로직 구현
- 실제 AI 기반 결과 요약 모델 연동
- 실제 PDF 자동 생성 파이프라인 구현
- 실제 대량 이메일 발송(SMTP) 연동 및 PIN 인증 백엔드
- 실제 Excel 일괄 등록 파싱 로직
- 실제 감사 로그 및 개인정보 접근 제한 백엔드 처리

## 3. Information Architecture

### 관리자 Web
1. 관리자 로그인: 이메일/비밀번호 로그인, 비밀번호 찾기 및 재설정, 관리자 권한 인증, 로그인 상태 유지, 계정 잠금 및 보안 정책 적용
2. 관리자 대시보드: 진행 중인 진단 현황 요약, 전체 참여율 및 응답률, 부서별 응답률 차트, 직급별 응답률 차트, 이메일 발송 현황, 미응답자 현황, 최근 생성된 진단 목록, 기간별 참여 추이 그래프
3. 진단 관리: 진단 생성, 진단명 및 설명 작성, 진행 기간 설정, 대상 조직 선택, 공개/비공개 설정, 진행 상태 관리(준비/진행 중/종료), 진단 복제, 진단 삭제
4. 진단 문항 관리: 문항 템플릿 관리, 영역별 문항 구성, 객관식/척도형 문항 설정, 문항 순서 변경, 필수 문항 설정, 문항 미리보기, 템플릿 저장 및 재사용
5. 참여자 관리: 참여자 일괄 등록(Excel), 참여자 정보 수정, PIN 자동 생성, PIN 재발급, 이메일 초대 발송, 참여 여부 확인, 참여자 검색 및 필터, 부서/직급 관리
6. 응답 현황 관리: 실시간 응답 현황, 부서별 응답률, 직급별 응답률, 미응답자 목록, 리마인드 이메일 발송, 응답 완료 여부 확인, 기간별 응답 추이
7. 결과 분석: 조직 결과 분석, 부서별 비교 분석, 직급별 비교 분석, 영역별 평균 점수, 조직 통계 시각화, 종합 분석 인사이트, AI 기반 결과 요약
8. 리포트 관리: 개인 리포트 일괄 생성, 조직 리포트 생성, PDF 자동 생성, 개인/조직 리포트 일괄 다운로드, AI 결과 요약, 종합 분석 리포트 제공, 리포트 생성 이력 관리
9. 권한 및 개인정보 보호 설정: 관리자 권한 관리, 역할(Role)별 접근 권한 설정, 익명 응답 정책 설정, 최소 응답 인원 기준 설정, 조직 통계 공개 기준 설정, 개인정보 접근 제한, 관리자의 개별 응답 조회 차단, 감사 로그 확인

### 참여자(User) Web
10. 참여자 로그인: PIN 인증 로그인, 진단 정보 확인, 참여 가능 여부 확인, 진행 중인 진단 안내
11. 성인지감수성 진단 참여: 모바일/PC 반응형 설문, 영역별 문항 응답, 진행률 표시, 이전/다음 문항 이동, 임시 저장, 필수 문항 검증, 최종 제출, 제출 완료 안내
12. 개인 결과 및 리포트: 개인 진단 결과 확인, 영역별 점수 및 그래프, AI 기반 결과 요약, 개인 맞춤 피드백 제공, 개인 PDF 리포트 다운로드

## 4. Key Focus
- 진단 생성 → 참여자 등록/초대 → 응답 수집 → 결과 분석 → 리포트 생성까지 이어지는 흐름을 관리자의 "진단 운영" 여정 중심으로 강조해, 수작업으로 처리되던 대량 참여자 관리 업무가 하나의 플랫폼으로 통합됐음을 시각적으로 전달
- 응답 현황 관리 화면에서 실시간 응답률과 미응답자 리마인드 발송을 함께 노출해, 진행 중인 진단을 관리자가 능동적으로 관리할 수 있는 운영 중심 설계를 부각
- 결과 분석·리포트 관리 화면에서 부서별/직급별 비교 분석과 AI 기반 결과 요약, PDF 자동 생성을 함께 강조해, 단순 통계 제공을 넘어선 인사이트 도출 플랫폼임을 전달
- 권한 및 개인정보 보호 설정 화면을 통해 PIN 인증, 익명 응답 정책, 관리자의 개별 응답 조회 차단 등 B2B 진단 서비스에 필수적인 신뢰성·보안 설계를 시각적으로 강조
- 참여자 화면은 PIN 로그인부터 설문 응답, 개인 리포트 확인까지 최소한의 단계로 단순화해, 관리자 화면의 복잡도와 대비되는 참여자 경험의 간결함을 부각

## 5. 관리자 분리

관리자(2번 항목의 9개 화면)는 `projects/b2b/genderinsight-admin` URL로 완전히 분리했다.
실제 코드는 `projects/b2b/genderinsight/components/admin/`에 있고, `genderinsight-admin/src/index.tsx`는
`/b2b/genderinsight-admin` 주소를 하나 더 얻기 위한 얇은 엔트리다(assetflow/assetflow-admin과
동일 구조). 참여자(User) Web 쪽에는 관리자 진입점(내비 항목, 로그인 역할 선택지)을 두지 않았다 —
실제 서비스처럼 주소와 계정이 분리되어 있다는 전제다.
