# StudySpot - Product Spec

## 1. Overview
- 플랫폼: Mobile App (사용자) + Web (점주 관리자) + Web (본사 관리자)
- 포지셔닝: 자유석·고정석·스터디룸을 실시간으로 예약하고 QR 체크인으로 이용하며, IoT 장비 제어와 다국어 콘텐츠 자동 생성까지 지원하는 코워킹/스터디카페 통합 운영 플랫폼
- 제작 목적: 포트폴리오용 UI 목업, 백엔드 미구현 (실시간 좌석 동기화, IoT 장비 연동, PG 결제, AI 콘텐츠 생성은 목업 데이터로 표현)

## 2. Non-goals
- 실제 IoT 장비(출입문, 냉난방, 조명, CCTV, 공기질 센서)와의 하드웨어 연동
- 실제 PG 결제 처리 및 간편결제 연동
- 실제 QR 체크인 하드웨어(리더기) 연동
- 실제 AI 다국어 콘텐츠 생성 모델 연동 (생성 결과를 보여주는 화면 UI까지만 구현)
- 실제 위치 기반 지점 검색(GPS) 로직 및 실시간 재고 동기화

## 3. Information Architecture

### 사용자 App
1. 로그인 및 실시간 지점 조회: 소셜 로그인/일반 로그인, 위치 기반 주변 지점 조회, 현재 운영 여부(영업중/마감), 실시간 좌석 현황 확인, 자유석/고정석/스터디룸 보유 여부, 즐겨찾기 지점 관리, 지점 상세 정보 조회, 이용권 보유 현황
2. 자유석 이용 / 스터디룸 예약: [자유석] 좌석 현황 실시간 조회, 원하는 좌석 선택, 이용권 선택, 시간권/기간권 적용, 예상 이용요금 확인 · [스터디룸] 날짜 선택, 시간 선택, 인원 선택, 룸 종류 선택, 예약 가능 여부 확인, 예약 정보 확인
3. 고정석 신청 / 고정석 관리: [신청] 고정석 배치도 조회, 이용 가능 좌석 확인, 이용 기간 선택, 월 단위 신청, 신청 내역 확인 · [관리] 이용 기간 확인, 남은 이용일 표시, 계약 정보 조회, 좌석 변경 신청, 연장 신청
4. 간편결제 / 결제 완료 및 QR 체크인: [결제] 이용권 선택, 쿠폰 적용, 포인트 사용, 간편결제(PG), 결제 내역 확인 · [QR 체크인] QR 생성, 출입 인증, 입실 처리, 퇴실 처리, 체크인 상태 표시
5. 실시간 이용 세션 관리: 현재 이용시간 표시, 남은 시간 표시, 좌석 정보 확인, 이용 종료 시간 안내, 이용 연장, 퇴실하기, 이용 내역 조회, 영수증 확인

### 점주 관리자 Web
6. 운영 대시보드: 오늘 이용 현황, 좌석 이용률, 예약 현황, 매출 현황, 실시간 이용자 현황, 시설 이용 통계, 알림 현황
7. 콘텐츠 관리(CMS): 공지사항 등록, 이벤트 등록, 배너 관리, FAQ 관리, 팝업 관리, 게시 기간 설정, 노출 여부 설정, 미리보기
8. IoT 장비 현황: 출입문 상태, 냉난방 상태, 조명 상태, CCTV 연결 상태, 공기질 센서, 전력 사용량, 장비 이상 알림, 장애 이력 조회
9. 자동화 및 원격제어: 영업시간 자동 운영, 조명 원격 제어, 냉난방 원격 제어, 출입문 원격 제어, 장비 재시작, 자동 운영 정책 설정, 긴급 제어, 예약 기반 자동 운영

### 본사 관리자 Web
10. 통합 운영 대시보드: 전국 지점 현황, 전체 좌석 이용률, 전체 예약 현황, 통합 매출 현황, 지역별 운영 통계, 실시간 장애 현황, 주요 KPI 모니터링
11. 지점 관리: 지점 등록, 지점 정보 관리, 운영시간 관리, 좌석 구성 관리, 이용권 정책 관리, 가격 정책 관리, 점주 계정 관리, 지점 운영 상태 관리
12. 장비 통합 관리: 전체 IoT 장비 모니터링, 장비 상태 조회, 장애 감지, 장애 이력 관리, 원격 장비 제어, 장비 펌웨어 관리, 유지보수 일정 관리, 장비 설치 현황
13. 통합 콘텐츠 관리(CMS): 공지사항 통합 배포, 이벤트 관리, 배너 관리, FAQ 관리, 지점별 콘텐츠 배포, 예약 게시, 콘텐츠 버전 관리, 게시 이력 관리
14. AI 다국어 콘텐츠 작성: AI 콘텐츠 초안 생성, 공지사항 자동 작성, 이벤트 문구 생성, 다국어 번역, 톤앤매너 선택, 번역 언어 선택, AI 결과 수정, CMS 즉시 게시

## 4. Key Focus
- 지점 조회부터 좌석/룸 예약, QR 체크인, 실시간 세션 관리, 퇴실까지 이어지는 흐름을 "빈 좌석을 찾아 바로 이용하는" 사용자 여정 중심으로 강조
- 자유석·고정석·스터디룸이라는 서로 다른 이용 방식을 하나의 예약 플로우 안에서 자연스럽게 분기시켜, 다양한 좌석 상품을 하나의 앱으로 통합했음을 시각적으로 전달
- 점주 관리자의 IoT 장비 현황·자동화 원격제어 화면을 통해 매장을 직접 방문하지 않아도 운영이 가능한 무인/반무인 운영 구조를 부각
- 본사 관리자의 통합 대시보드와 AI 다국어 콘텐츠 작성 화면을 통해, 다지점 프랜차이즈 운영과 콘텐츠 확산을 본사가 중앙에서 통제하는 구조적 차별성 강조

## 5. 관리자 콘솔은 두 개, 모두 별도 프로젝트

점주 관리자와 본사 관리자는 이 프로젝트 안에 없다. `buildbid`의 선례처럼 기기 패러다임이
같은 웹 콘솔 두 개를 URL만 분리해 별도 프로젝트로 뒀다.

- 점주 관리자: `projects/platform/studyspot-admin`(`/platform/studyspot-admin`) — 얇은
  엔트리, 실제 화면은 `projects/platform/studyspot/components/admin/`.
- 본사 관리자: `projects/platform/studyspot-hq`(`/platform/studyspot-hq`) — 얇은 엔트리,
  실제 화면은 `projects/platform/studyspot/components/hq/`.

사용자 앱 쪽에는 두 관리자 콘솔 어디로도 진입점을 두지 않는다. 실제 서비스처럼 주소도
계정도 다르다. 상세는 `design.md`의 "3개 화면군" 절 참고.
