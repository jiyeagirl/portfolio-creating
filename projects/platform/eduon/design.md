# EduOn 디자인

## 아키타입

- **웹 홈 골격: 좌정렬 분할 히어로(민트 밴드) + 가로 레일 + 편집 그리드와 목록 분할 + 조건 목록.** 이유: 첫 화면이
  "지금 볼 것"을 보여 줘야 한다(운영자 추천 강좌 한 개). 디자인시스템 jobright의 hero(민트 밴드, 좌 카피, 우 비대칭
  라운드 미디어 카드, 블랙 필 CTA)를 그대로 쓴다. 처음에는 다크 캔버스 위 풀블리드 사진이었으나 사용자가 "강의 사이트에
  어두운 화면이 어색하다"고 해서 바꿨다(2026-10-28). 그다음
  블록이 이어보기(가로 레일, 페이지에서 한 번), 관심 주제 추천(큰 대표 강좌 + 썸네일 목록 3개), 신규 강의(전체 폭
  4열 카드, 공개일 표시. 처음에는 오른쪽 세로 목록이었으나 위계가 어색하다는 사용자 지적으로 옮김), 마지막이 검색과 필터 칩 + 결과 그리드다. 인접한 블록끼리 레이아웃이 전부 다르다.
- **화면별 골격:** 홈 = 위 조합, 강의 상세 = detail-hero(좌 미디어 + 소개, 커리큘럼, 강사, 추천 탭 / 우 sticky 구독 카드,
  모바일은 하단 고정 구독 CTA), 시청 = media-led(플레이어가 화면 대부분 + 우측 회차 목록), 구독 = 폼 + 고정 요약 패널
  (결제 단계), 내 학습 = list-first(탭 3개: 이어보기, 학습 완료, 찜한 강의), 구독 관리 = 상태 + 우측 결제 내역(헤더 프로필 메뉴에서 진입, 2026-10-28 사용자 지정으로 내 학습에서 분리).
- **구독은 메뉴가 아니다(사용자 지정, 2026-10-28).** 헤더에 구독 안내 메뉴가 없다. 강의 상세의 `무료 미리보기`와
  `할인 받고 구독 시작하기`, 미리보기가 끝난 뒤 플레이어 위 구독 안내가 결제 단계로 들어가는 길이다. 첫 달 19,900원,
  이후 월 29,000원. `할인 받고 구독 시작하기`가 DS의 민트 그린 필(시그니처 액션)이고 나머지 CTA는 블랙 필이다.
- **실제 서비스로 설계한다(사용자 지시).** 홍보용 섹션, 링크 농장 푸터, 사용자와 관리자 전환 스위치가 없다.
  사용자, 제작자, 관리자는 URL이 셋이다. 스펙이 요구한 시연 상태 전환(구독 상태, 재생 오류)과 데모 초기화는
  화면 왼쪽 아래 작은 `시연 도구` 버튼 안에만 둔다.
- **관리자 셸: C2 워크벤치(짙은 좌측 사이드바).** 이유: 메뉴가 셋(콘텐츠 검수, 구독 운영, 보안 검증)이고
  각 화면이 master-detail이라 풀블리드 본문이 필요하다. 사이드바에는 메뉴마다 그 섹션 고유의 큐 잔량(검수 대기,
  권한 확인 필요, 승인 대기)을 숫자로 둔다. 시연용 역할 전환(콘텐츠 운영자 / 최고관리자)은 하단 계정 칩 메뉴에 둔다.
- **제작자 스튜디오 셸:** 좌측 짙은 콘텐츠 목록(내비 면) + 중앙 등록 폼 + 우측 처리 현황 3열. 스튜디오의 내비가
  곧 "내 콘텐츠 목록"이라 별도 아이콘 레일을 두지 않는다.
- **배제한 후보 (웹 홈):** 검색 우선 히어로는 예약, 렌탈처럼 조건이 먼저인 도메인용이고 이 서비스는 발견이
  먼저다. 풀블리드 사진 히어로는 다크 버전에서 썼다가 위 사용자 지시로 뺐다.
- **디자인시스템에서 쓰지 않는 랜딩 부품:** 밴드 교차 리듬 전체(통계 밴드, 블랙 티커, 후기, FAQ, CTA 밴드, 푸터 검색바),
  80px display, 손그림 장식과 이모지. 제품 화면이라 민트 밴드는 홈 히어로 한 곳과 결제 복귀 안내에만 쓴다.
- **배제한 후보 (관리자):** C1은 포화(10개)이고 IA가 3개라 236px 라벨 레일이 비어 보인다. C4는 섹션 3개에 하위
  뷰가 2~3개라 섹션 리스트 컬럼이 거의 빈다. C3는 사용자 지정으로 신규 배정 금지다.
- **카테고리 중복:** platform 안에 C2(drawqty-admin)와 C4(dressday-admin)가 이미 있어 어느 셸을 골라도 겹친다.
  drawqty와 구분점: 사이드바 항목별 큐 숫자, 역할 전환 칩, 우측 상세 패널 안의 탭 구조.
- **이 아키타입에서 쓰지 않는 부품:** `SectionHead` + 더보기 링크의 반복(섹션 제목만 쓰고 더보기는 레일 하나에만),
  하단 탭바(웹이다), 같은 카드 3열 그리드 띠, CTA 띠, 이용 흐름 설명 섹션, 후기 블록, 4열 링크 푸터,
  KPI 카드 4개 병렬, 헤더 시계, 관리자 드로어.
- **사용자, 제작자, 관리자 분리:** 사용자 화면 `/platform/eduon`, 제작자 `/platform/eduon-studio`,
  관리자 `/platform/eduon-admin`. `-studio`, `-admin`은 얇은 엔트리이고 화면 코드는 이 프로젝트의
  `components/studio/`, `components/admin/`에 있다. 두 엔트리에는 docs와 styles가 없고 이 프로젝트의 토큰을
  상속한다. 세 URL은 `localStorage`(`eduon:v1`) 하나로 콘텐츠, 이용 설정, 구독, 검수 상태를 공유한다.

## 적용 규칙

해석: 구독형 교육 영상 플랫폼 for 저녁에 강의를 이어 보는 직장인 학습자, 강의를 올리는 강사, 검수와 결제를
보는 운영자. 사용자 화면 다이얼 V6 / M5 / D4, 시청 V5 / M5 / D4, 스튜디오와 관리자 V3 / M2 / D7.

- 읽은 skill: `mockup-craft` SKILL.md, `references/anti-slop.md`, `references/web.md`, `references/console.md`.
  `디자인시스템: jobright_compact` 적용(색, 라운드, 버튼, 그림자, 타입 위계). `스타일:`, `프리미엄디테일:` 줄은 없다.
- 디자인시스템 우선순위: CLAUDE.md UI Generation Rules(Pretendard, 8px, 금지 문자)가 이기고, 그다음 jobright 문서,
  나머지는 mockup-craft. 플레이어처럼 영상 위에 놓이는 면만 `.eo-dark` 토큰을 쓴다.
- 사용자 V6 / M5 / D4: SKILL.md 2절의 웹 홈(6/5/4) 그대로. 홈은 블록마다 처리가 다르고(풀블리드 하나, 레일
  하나, 편집 그리드 하나, 결과 그리드 하나) 좌측 정렬선은 하나다. 모션은 슬라이드오버, 시트, 오버레이, 섹션 진입
  1회까지.
- 시청 V5 / M5 / D4: 웹 상세(5/4/4)에서 모션을 하나 올렸다. 재생 진행, 오류 오버레이, 주소 재발급처럼 상태 전환
  자체가 화면의 내용이다.
- 스튜디오와 관리자 V3 / M2 / D7: 콘솔 목록(3/2/8)과 상세(3/2/6)의 중간. 표와 상세 패널이 반반이다. 업로드와
  변환 진행 막대만 선형으로 움직인다.
- 카피는 해요체 하나(사용자, 스튜디오 안내). 관리자 라벨과 버튼은 명사형이다.
- **이용 범위 표시는 한 모양이다:** `무료 공개` 배지(민트 필, 검정 글자), `구독 전용` 배지(블랙 필, 흰 글자), `미리보기` 텍스트 칩, 잠금
  아이콘(`LockSimple`). 홈 카드, 상세, 회차 목록, 내 학습, 관리자 목록이 같은 `AccessBadge`를 쓴다.
- **재생 권한 규칙은 하나:** `lib/access.ts`의 `canPlay(course, episode, subscription)`. 무료 공개 강좌, 미리보기
  회차, 구독 대상 + 이용 중 구독(활성, 갱신 해지 잔여 기간) 중 하나면 재생된다.
- 목업 표기 없음(사용자 지정, 2026-10-28): 실제 서비스처럼 `목업`, `테스트 시나리오`, `샘플` 표기를 화면에 두지 않는다.
  결제 실패, 스토어 구매 실패, 구매 복원 결과 같은 상태는 URL(`?pay=`, `?store=`, `?restore=`)로만 고른다. 구독 상태와 재생
  오류는 왼쪽 아래 `화면 상태` 버튼에서 바꾼다. DRM이 녹화를 막는다고 쓰지 않는다.

## Tokens, 팔레트

디자인시스템 지정(`design-systems/jobright_compact.md`)이라 팔레트 구성은 **1: 화이트 캔버스 + 액센트 하나**이고 이유는
"디자인시스템 지정"이다. 액센트는 스프링 민트 `#00f0a0` 하나, CTA는 블랙 필이다. 스튜디오와 관리자는 CLAUDE.md
"관리자/콘솔 색 배치"에 따라 내비 면만 브랜드 블랙 계열이고 본문은 흰색이다.

`styles/eduon.css`, 루트 클래스 `.eduon`(사용자), `.eduon-console`(스튜디오, 관리자), `.eo-dark`(영상 위 면), 접두어 `--eo-`.

| 토큰 | 값 | 출처, 용도 |
| --- | --- | --- |
| canvas | `#ffffff` | DS canvas. 페이지 |
| mint-band | `#ecffe0` | DS canvas-mint. 홈 히어로 밴드, 결제 복귀 안내 |
| raised / raised-2 | `#f2f4f5` / `#e9ecee` | DS surface-soft. 회차 목록, 결제 요약, 결제 내역 패널 / 호버 |
| hair / hair-2 | `#e5e7eb` / `#d3d7dc` | DS hairline / 입력 테두리 |
| fg / fg-2 / fg-3 | `#000000` / `#3c434b` / `#69727d` | DS ink / 본문 보조 / 캡션. DS muted `#86909c`는 흰 바탕 AA 미달이라 한 단 짙게 |
| brand | `#00f0a0` | DS primary. 로고 `On`, 무료 공개 배지, 진행 막대, 구독하기 그린 필, 토글 |
| brand-ink | `#007a50` | 민트를 글자로 쓸 때(링크, 미리보기 칩, 구독 중 라벨). 흰 바탕 AA |
| ink | `#000000` | 블랙 필 CTA, 구독 전용 배지, 선택된 칩 |
| side / side-3 | `#0b0d0e` / `#282c2f` | 콘솔 내비 면 / 활성 항목 |

상태 5색은 의미 고정: 초록(완료, 공개, 활성), 파랑(진행), 주황(조치 필요), 빨강(실패, 만료), 회색(대기, 중단).
`-fg`/`-bg`는 흰 바탕 배지, `-dk`는 글자색(라이트에서 `-fg`와 같고 `.eo-dark`에서 밝아진다). DS 금지 사항대로 이 파스텔
상태색은 제품 UI 배지에만 쓰고 헤더, 버튼 같은 크롬에는 쓰지 않는다.

## Shape

- DS rounded 그대로: 버튼과 칩 전부 필(`rounded-full`, 헤더 작은 필은 18px), 입력 12px, 썸네일과 미디어 카드 16px,
  패널(회차 목록, 결제 요약, 결제 내역) 24px, 홈 히어로 미디어 카드는 DS feature-card 실루엣(좌상단 직각, 나머지 40px)
  + 1px 블랙 테두리(DS video-card).
- 그림자는 DS soft-float 하나(`0 4px 16px rgba(0,0,0,.06)`)를 히어로 카드, 슬라이드오버, 모달, 토스트에만.
- 배지는 필 형태 64px 고정 폭, 가운데 정렬(사용자 지정).
- 콘솔: 패널 10px, 버튼과 입력 8px, 배지 6px 고정 폭. 콘솔은 표 밀도가 우선이라 DS 필 라운드를 따르지 않는다.
- 썸네일 비율은 16:9 하나.

## Typography

Pretendard 단일. DS 타입 스케일에서 제품 화면에 맞는 단을 골랐다(80px display, 60px heading-1은 랜딩용이라 쓰지 않는다).

- 홈 히어로 제목: DS heading-2 48px / 56px 700 (모바일 32 / 40)
- 화면 제목: 32px / 40px 700 (DS heading-4 크기, 무게는 제목이라 700)
- 섹션 제목: 24px / 32px 600 (DS에 없는 단. 48과 16 사이 위계를 위해 추가)
- 본문: DS body-md **16px / 26px / 500**, 긴 소개 문단은 DS body-lg 18px / 29px / 300
- 버튼: DS button 16px 600 (작은 필 14px 600), 내비: DS nav-link 14px 600, 캡션: DS caption 13px 500
- 콘솔 본문 13px / 20px, 표 헤더 12px 500, 화면 제목 20px / 28px 600.
- 숫자는 전부 `tabular-nums`, ID와 이벤트 ID만 모노.

앞선 프로젝트와 다르게 한 것: 사용자 본문은 디자인시스템 지정(16/26 500, 무게가 drawqty 14/22 400과 다르다), 콘솔 본문
13/20(drawqty 13/19와 다름).

## 사진 매핑

공개 강좌 썸네일은 사용자가 `assets/`에 넣은 1280x720 이미지다(2026-10-28, `lib/thumbs.ts`). 한 장씩 열어 강좌와 맞는지
확인했다. 썸네일 안에 강좌 제목이 들어 있어서 히어로 카드와 강의 상세 미디어 위에는 글자 라벨을 올리지 않는다.

- c10 TypeScript 실무 패턴은 이미지가 없어 썸네일과 같은 톤의 짙은 타이틀 타일(`CourseFill`)로 두고 사진 요청에 올렸다.
- 관리자와 스튜디오에만 보이는 미공개 강좌: c14 노코드는 picsum 48(덮은 맥북), 스튜디오 c13 포스터는 picsum 355(빈티지
  카메라), 스튜디오 변환본 미리보기는 picsum 250(피아노 건반 위 카메라). 나머지 미공개 강좌는 글자 타일.
- 재생 영상은 MDN CC0 샘플(`flower.mp4`)이고 포스터는 강좌 썸네일이다. 교체 요청 목록에 있다.

## 반응형 기준

기준 폭 393 / 768 / 1024 / 1440. 모바일 우선. 본문 `max-w-[1328px]`, 거터 모바일 16px, 데스크톱 32px.

- 헤더 64px 한 줄(로고, 홈, 탐색, 내 학습, 구독 안내, 검색, 프로필, 무료 회원이면 블랙 `구독 시작` 필). `md` 미만은 로고, 검색 아이콘, `구독 시작` 필, 메뉴 버튼만
  남고 메뉴는 위에서 내려오는 불투명 패널이다. 헤더는 `sticky`이고 불투명(`backdrop-blur` 없음).

## Motion

- 화면 진입: 200ms 페이드만(이동이 있으면 transform이 고정 바와 모달의 기준을 바꿔서 뺐다). 섹션 진입: 260ms `cubic-bezier(0.2, 0, 0, 1)` 감속, 페이드 + translateY 12px. 섹션 진입은
  `IntersectionObserver`로 1회. 스태거는 홈 히어로 텍스트 3요소에만 40ms. (drawqty 220ms standard 16px,
  번진 420ms expo-out 8px와 다르다)
- 슬라이드오버와 시트: 300ms 같은 감속 곡선, translateX 32px(데스크톱) / translateY 100%(모바일). 콘솔 패널 200ms.
- 눌림 피드백: **배경 톤**. 버튼은 hover와 눌림에서 한 단 밝거나 어두운 면으로만 바뀐다(블랙 필은 #23272b, #3a3f45). (drawqty `scale(0.98)`,
  teefinder `translateY(1px)`와 다르다)
- 플레이어 오버레이(구독 안내, 오류): 200ms 페이드. 주소 재발급, 업로드, 변환 진행 막대는 선형.
- `prefers-reduced-motion`에서 진입, 패널, 오버레이 이동을 끄고 진행 막대는 즉시 전환한다.
