# EduOn Product Spec

## 1. Overview

EduOn은 강사와 교육 콘텐츠 제작사가 강의 영상을 등록하고, 운영자가 검수 후 공개하며, 이용자가 웹과 앱에서 강의를 발견하고 시청하는 교육 영상 플랫폼이다. 무료 회원은 무료 공개 강의와 미리보기 회차를 시청하고, 구독 회원은 구독 대상 전체 강의를 이용한다.

이 프로젝트는 영상 콘텐츠 플랫폼 구축 역량을 보여 주는 **포트폴리오용 인터랙티브 목업**이다. 카드 정기결제, 앱 인앱 구독, DRM, 영상 스트리밍, 보안 검증 대응의 주요 화면과 처리 흐름을 목업 데이터로 보여 준다. 실제 결제, DRM, 스트리밍 인프라, 보안 검증을 구현하거나 수행한 것으로 표현하지 않으며, 화면에는 목업이나 테스트 표기를 두지 않고 실제 서비스처럼 보여 준다 (2026-10-28 결정).

- **플랫폼**: 사용자 반응형 웹, 사용자 앱 미리보기, 제작자 및 관리자 웹.
- 디자인시스템: jobright_compact
- **핵심 화면**: 사용자 4개, 제작자 1개, 관리자 3개. 상세 정보와 예외 상태는 패널, 모달, 탭으로 처리한다.
- **사용자**: 일반 회원, 강사 및 제작자, 콘텐츠 운영자, 최고관리자.
- **구독 모델**: 월 29,000원 구독, 첫 달은 할인가 19,900원. 무료 회원은 무료 공개 강의와 각 강좌의 미리보기 회차만 시청하고, 구독 회원은 구독 대상 전체 강의를 시청한다. 웹 카드 정기결제와 iOS 및 Android 인앱 구독을 구분한다.
- **데이터**: 전부 목업 데이터. 실제 로그인, 결제, 파일 전송, 서버 저장은 없다.
- **상태 공유**: 제작자 제출 → 관리자 검수 및 구독 설정 → 사용자 공개, 구독 변경 → 구독 전용 강의 이용 권한 변경이 같은 브라우저에서 연결된다.
- **포트폴리오 표현**: 화면 설계와 목업 시연을 실제 구축 및 연동 경험과 명확히 구분한다.

## 2. Information Architecture

사용자 화면은 상단 내비게이션(홈, 탐색, 내 학습, 프로필)으로 이동한다. 구독은 별도 메뉴가 아니라 강의 상세의 "무료 미리보기", "할인 받고 구독 시작하기" 버튼과 미리보기 종료 안내에서 시작한다 (2026-10-28 결정). 제작자 화면과 관리자 화면은 각각 별도 URL과 자체 내비게이션을 쓴다.

### 사용자 화면

1. **홈 및 콘텐츠 탐색** (`home`)
   - 강의 콘텐츠 플랫폼의 성격과 개인화된 탐색 경험을 보여 주는 첫 화면
   - 관심 주제 기반 추천 섹션, 이어보기, 신규 강의, 운영자 추천
   - 검색과 주제, 난도, 강사 필터, 이용 범위 필터(전체 / 무료 공개 / 구독 전용)
   - 콘텐츠 카드: 썸네일, 제목, 강사, 영상 길이, 시리즈 정보, 이용 범위 배지(무료 공개 / 구독 전용)
   - 카드를 누르면 강의 상세 화면(`course`)으로 이동: 좌측 미디어와 소개, 커리큘럼, 강사, 추천 탭, 우측 고정 구독 카드
     - 강의 소개, 강사, 강의 목록, 제작정보, 자막 지원
     - 무료 공개 / 구독 전용 배지
     - 강의 목록에서 미리보기 회차는 "미리보기" 표시, 나머지 구독 전용 회차는 잠금 아이콘 표시
     - 찜 버튼, 시청 시작 버튼, "무료 미리보기" 버튼과 "할인 받고 구독 시작하기" 버튼(구독 전용 강좌에서 무료 회원에게 노출)
   - 비공개, 검수 중, 게시 중단 콘텐츠는 일반 사용자 목록과 검색에서 제외
   - 신규 회원은 관심 분야와 운영자 추천을 활용한 기본 추천 제공
2. **강의 시청** (`watch`)
   - 영상 재생 품질과 이용 권한 및 DRM 예외 처리를 보여 주는 핵심 화면
   - 중앙 플레이어와 우측 시리즈 및 회차 목록(미리보기 회차 표시, 구독 전용 회차 잠금 표시)
   - 재생, 일시정지, 탐색, 배속, 전체 화면
   - 화질 선택: 자동 / 1080p / 720p / 480p
   - 자막 켜기와 끄기, 다음 강의 자동 재생
   - 재생 위치 저장 및 이어보기 안내
   - 무료 회원: 무료 공개 강의와 미리보기 회차 재생. 미리보기 종료 후 다음 회차로 넘어가거나 잠긴 회차를 누르면 구독 안내 표시
   - 구독 안내: 플레이어 위 오버레이로 구독 혜택(구독 대상 전체 강의 이용)과 첫 달 19,900원, 이후 월 29,000원 안내, "할인 받고 구독 시작하기" 버튼(구독 결제 단계로 이동)
   - 구독 회원: 구독 대상 전체 강의 재생
   - 강의 정보, 찜, 댓글 영역
   - 시연용 상태: 정상 재생 / 구독 필요(구독 전용 강의 접근) / 네트워크 오류와 재시도 / 재생 주소 만료와 주소 재발급 연출 / 재생 권한 없음 / DRM 라이선스 발급 실패 / 미지원 환경 안내
   - 실제 DRM 대신 오류와 복구 흐름만 시뮬레이션하며, 영상은 재생 가능한 샘플 클립 사용
3. **구독 및 결제** (`subscription`)
   - 메뉴에 없는 결제 단계. 강의 상세와 구독 안내의 "할인 받고 구독 시작하기"로만 들어온다
   - 웹 카드 정기결제와 앱 인앱 구독의 차이를 보여 주는 화면
   - 월 29,000원 구독 상품과 구독 대상 전체 강의 이용 혜택
   - 자동 갱신, 해지, 이용기간 안내
   - 웹 버전: 카드 정기결제 버튼, 모의 결제수단 등록 및 동의 모달, 결제 성공 / 실패 / 확인 중 상태
   - 앱 미리보기 버전: iOS 또는 Android 선택, 모의 스토어 구매 확인창, 구매 완료 / 취소 / 실패 상태, 구매 복원 버튼
   - 구매 복원 결과: 복원 성공 / 복원할 구매 없음 / 다른 서비스 계정에 연결된 구매
   - 구독 성공 후 사용자 상태와 관리자 구독 목록에 반영하고, 구독 안내를 보고 들어온 경우 보던 강의로 돌아가 이어서 재생
   - 결제 입력에는 등록된 카드 선택만 쓰고 카드번호 입력은 받지 않음. 앱 구매창은 스토어 확인창 모양으로 표시 (목업 표기 없음)
4. **내 학습** (`mypage`) / **구독 관리** (`membership`)
   - 2026-10-28 결정: 내 학습에는 학습 기록만 두고, 구독 상태와 결제 내역은 헤더 프로필 메뉴의 별도 화면 "구독 관리"로 뺀다
   - 내 학습 탭 3개: **이어보기** / **학습 완료** / **찜한 강의**
   - 이어보기: 최근 시청 강의와 재생 위치, "이어서 시청" 버튼. 구독 만료로 이용할 수 없는 강의는 잠금 표시와 재구독 안내
   - 구독 관리: 구매 경로(웹 카드 / App Store / Google Play), 현재 상태와 이용 종료일 또는 다음 갱신 예정일, 결제 내역 패널
   - 웹 구독은 갱신 해지 확인 모달, 앱 구독은 해당 스토어 관리 안내 모달
   - 상태 표현: 구독 중 / 갱신 해지 후 잔여 기간 이용 가능 / 갱신 실패 / 만료 / 환불 처리
   - 갱신 해지만으로 즉시 이용 종료되지 않도록 표현하고, 만료 후에는 구독 전용 강의 재생 제한 상태로 연결(무료 공개 강의와 미리보기 회차는 계속 시청 가능)

### 제작자 화면

5. **콘텐츠 등록 및 제출** (`studio`)
   - 대용량 업로드, 변환, 자료 제출, 보완 요청을 한 화면에서 보여 줌
   - 좌측 콘텐츠 목록, 중앙 등록 폼, 우측 처리 현황
   - 콘텐츠 정보: 강좌 및 영상 제목, 소개, 주제, 난도, 회차, 포스터, 제작방식, 사용 도구
   - 영상 업로드: 파일 선택 또는 "예시 영상으로 체험", 진행률과 전송량, 업로드 중단 및 이어 올리기
   - 업로드 완료 후 별도 변환 상태 표시: 대기 → 변환 중 → 완료, 변환 실패 → 재처리 → 완료, 1080p / 720p / 480p 출력 상태
   - 자막과 권리자료 첨부, 변환본 미리보기와 필수 입력 점검
   - "검수 제출" 버튼을 누르면 관리자 검수 목록에 추가됨
   - 보완 요청 시 운영자 의견과 수정 및 재제출 버튼 표시
   - 제출본 버전과 검토 이력 표시

### 관리자 화면

6. **콘텐츠 검수 및 영상 운영** (`admin-content`)
   - 제작자 제출 이후의 검수와 공개, 이용 범위, 영상 보호 상태를 확인하는 화면
   - 콘텐츠 목록: 제목, 제작자, 제출일, 검수 상태, 공개 상태, 이용 범위(무료 공개 / 구독 전용), 변환 상태. 검수 상태와 공개 상태는 별도로 표시
   - 행을 누르면 우측 상세 패널: 영상 미리보기, 메타데이터, 자막, 권리자료, 제출 버전과 검토 이력, 보완 요청 / 승인 / 반려, 승인 후 공개 / 게시 중단 / 재게시
   - **이용 설정** 탭:
     - 강의별 무료 공개 여부
     - 미리보기 회차 지정(회차 목록에서 선택, 예: 1강)
     - 구독 대상 여부
     - 저장 시 사용자 홈 배지, 강의 상세 잠금 표시, 플레이어 접근 제한에 반영
   - **영상 처리** 탭: 업로드 및 변환 결과, 출력 화질, 실패 원인, 재처리
   - **재생 보호** 탭: 재생 권한 확인 여부, 임시 재생 주소 정책, DRM 적용 상태, 라이선스 요청 성공 및 실패 기록과 오류 코드
   - 승인 후 공개한 콘텐츠가 사용자 홈에 노출됨
   - 키, 토큰, 개인정보 원문은 표시하지 않음
7. **구독 및 결제 운영** (`admin-billing`)
   - 결제 결과뿐 아니라 서버 알림, 중복 처리, 권한 동기화를 보여 주는 화면
   - 상단 요약: 활성 구독, 갱신 실패, 권한 확인 필요
   - 구독 목록: 마스킹된 계정, 구매 경로, 상태, 유효기간, 권한 반영 상태
   - 행을 누르면 우측 상세 패널: 결제, 갱신, 해지, 만료, 환불 이력, 서비스 구독 권한 변경 이력, 구매 복원 결과
   - **결제 이벤트** 탭: 이벤트 ID, 수신 시각, 유형, 검증 결과, 처리 결과. 중복 이벤트는 "중복 수신, 추가 처리 없음", 실패 이벤트는 재확인 및 재처리
   - 모의 시나리오 실행: 갱신 성공 / 갱신 실패 / 만료 / 환불. 상태 변경을 사용자 내 구독과 구독 전용 강의 이용 권한에 반영
   - 실제 카드번호와 스토어 인증정보는 표시하지 않음
8. **보안 및 운영 검증** (`admin-security`)
   - 권한 차단, 고위험 승인, 검증 조치, 복구 기록을 보여 주는 화면
   - 탭 3개: **권한 및 승인** / **접근 기록** / **검증 및 복구**
   - 권한 및 승인: 콘텐츠 운영자와 최고관리자의 역할별 접근 범위, 개인정보 대량 반출 및 핵심 권한 변경 요청, 서로 다른 두 승인권자의 승인 상태, 개발사 접근의 목적, 범위, 기간, 만료, 회수
   - 접근 기록: 수행자, 시각, 대상, 작업, 결과. 권한 없는 조회의 차단 기록
   - 검증 및 복구: 보안 점검 항목, 심각도, 담당자, 발견 → 수정 → 재검증 → 종료 상태, 자체 시험과 외부 검증 구분, 백업 상태와 복구 시험 기록, 복구 목표와 실제 측정 결과 비교
   - 일반 운영자가 제한 메뉴에 접근하면 접근 불가 안내
   - 실제 데이터 반출, 권한 변경, 복구 작업은 수행하지 않음 (화면에 샘플 표기는 두지 않음)

## 3. Key Focus

- **업로드부터 공개까지 한 바퀴**: 제작자 영상 등록 → 업로드 중단 및 재개 → 변환 → 검수 제출 → 관리자 보완 요청 → 재제출 → 이용 설정(무료 공개 여부, 미리보기 회차, 구독 대상) 및 공개 → 사용자 시청이 끝까지 이어져야 한다.
- **구독 상태와 시청 경험 연결**: 무료 미리보기 → 구독 안내 → 구독 결제 → 전체 강의 시청 → 만료 시 이용 제한의 흐름이 끊기지 않아야 한다. 갱신 해지 시 잔여 기간은 전체 강의를 계속 이용하고, 만료 처리 후 구독 전용 강의는 다시 잠긴다. 웹 카드결제와 앱 인앱 구독은 구매 경로가 다르지만 동일 서비스 계정의 구독 권한으로 연결되는 모습을 보여 준다.
- **이용 범위 표시의 일관성**: 무료 공개 / 구독 전용 배지, 미리보기 표시, 잠금 아이콘을 홈, 강의 상세, 플레이어 회차 목록, 내 학습, 관리자 목록에서 같은 의미와 모양으로 쓴다.
- **보호 기술의 역할 구분**: 재생 권한은 이 사용자가 해당 영상을 볼 수 있는지(구독 여부 포함) 확인하고, 임시 주소는 재생 주소의 사용 시간을 제한하며, DRM은 암호화된 영상의 재생 라이선스를 통제한다. DRM이 모든 녹화와 복제를 완전히 방지한다고 표현하지 않는다.
- **정상, 실패, 복구 상태를 함께 제공**: 단순 완료 화면보다 아래 상태 전환을 중요하게 다룬다.
  - 업로드 중단 → 이어 올리기
  - 변환 실패 → 재처리
  - 구독 전용 강의 접근 → 구독 안내 → 구독 반영 후 재생
  - 구매 확인 중 → 구독 반영
  - 결제 이벤트 중복 → 중복 처리 차단
  - 라이선스 오류 → 안내 및 재시도
  - 권한 없는 접근 → 차단 및 기록
- **목업과 실제 경험 구분**: 시연은 제품 흐름과 운영 설계 역량을 보여 주는 목업이다. 실제 결제 연동, DRM 적용, 외부 보안 검증 통과 실적으로 설명하지 않는다.

## 6. 구현 메모 (워크스페이스)

- **사용자, 제작자, 관리자는 별도 URL이다.** 사용자 화면은 `/platform/eduon`, 제작자 화면은 `/platform/eduon-studio`, 관리자 화면은 `/platform/eduon-admin`이다. 서비스 화면 내부에는 사용자와 관리자를 오가는 전환 스위치를 두지 않는다.
- **앱 구독 시연.** 앱 구독은 사용자 화면의 모바일 프레임에서 iOS 및 Android 상태를 시연한다. 실제 네이티브 앱으로 표현하지 않는다.
- **데이터 공유.** 백엔드가 없어서 콘텐츠, 이용 설정(무료 공개 여부, 미리보기 회차, 구독 대상), 구독, 검수 상태는 브라우저 `localStorage`(`eduon:v1`)로 세 화면이 공유한다. 같은 브라우저에서 URL을 오가면 제출, 승인, 이용 설정, 구독 변경 결과가 바로 반영된다.
- **이용 권한 판단.** 재생 가능 여부는 강의의 무료 공개 여부, 미리보기 회차 여부, 구독 대상 여부와 사용자 구독 상태(활성, 갱신 해지 잔여 기간 포함)를 조합해 화면 공통 규칙 하나로 판단한다.
- **업로드 및 변환 연출.** 실제 대용량 파일 대신 샘플 영상을 사용하고, 업로드 및 변환 진행률은 타이머로 연출한다.
- **데모 초기화.** 초기 샘플 상태로 돌아가는 "데모 초기화" 기능은 시연용 도구 영역에 둔다.
- 시작 화면과 상태는 `?screen=home|course|watch|subscription|mypage|membership`(사용자, `course`는 `&course=c01`), `?state=uploading|paused|transcoding|failed|review|revision`(제작자), `?screen=content|billing|security`(관리자), `?subscription=free|active|cancelled|expired`(구독), `?playback=normal|locked|network-error|drm-error|denied`(플레이어, `locked`는 구독 안내 상태)로 고른다.
