# LUMI — Product Spec

## 1. Overview

LUMI(루미)는 사주·타로·신점 전문가와 사용자를 연결하는 **정액 상담권 기반 전화 상담
플랫폼**이다.

- **슬로건**: 오늘의 물음에 답하는 15분
- **플랫폼**: 사용자 앱(iOS/Android, 모바일 393pt) + 관리자 백오피스(웹, 1920/1440/1024/393 대응)
- **상담권**: Lite 15분 / Standard 30분 / Premium 60분. 분 단위 과금이 아니라 정액권을
  구매해 두고, 예약 상담이나 즉시 상담에 소진한다.
- **가명 처리**: 상담사는 `백담`, `소윤`처럼 실제 인물과 무관한 활동명을 쓴다. 제휴사·정산
  은행·결제사는 `A페이`, `B은행`처럼 알파벳 기반 가명을 쓴다. 후기 작성자는 `김*민` 형태로
  마스킹한다. 전화번호, 사업자번호, 정산 계좌는 모두 가상 데이터다.
- **제작 목적**: 포트폴리오용 고품질 UI 목업. 실제 통신(PSTN/VoIP) 연결, PG 결제, 정산
  이체는 구현하지 않으며 내부 state 기반 mock 데이터로 화면 완성도를 우선한다.

## 2. Non-goals

- 실제 전화 연결(안심번호 중계), 실제 결제 승인, 실제 정산 이체
- 상담사 포털(전문가용 앱)은 이번 범위에서 제외. 사용자 앱과 관리자 백오피스만 만든다.
- 딥링크 가능한 하위 라우트. 모든 화면 전환은 `src/index.tsx` 내부 state로 처리한다.

## 3. Information Architecture

### 3.1 사용자 앱 — `/platform/lumi`

하단 탭 5개(홈 / 상담사 / 상담권 / 내 상담 / 마이)를 축으로 내부 상태 전환한다.

1. **홈 · 상담사 탐색** — 보유 상담권 요약, 즉시 상담 가능 상담사, 추천 상담사,
   카테고리(사주/타로/신점) 진입, 고민 테마별 진입, 인기/신규 상담사, 이벤트 배너
2. **상담사 탐색** — 검색, 카테고리 탭, 정렬(인기순/신규순/평점순/후기순),
   즉시 상담 가능 필터, 상담권 종류 필터, 상담사 카드 리스트
3. **상담사 상세** — 프로필, 전문 분야, 상담 스타일, 소개, 이력, 평점 분포, 후기,
   상담 가능 시간, Lite/Standard/Premium 선택, 예약하기 / 즉시 상담 신청
4. **상담권 구매 · 결제** — 상담권 선택, 수량, 쿠폰, 결제 수단, 결제 확인, 구매 완료
5. **예약** — 날짜 선택, 시간 슬롯 선택, 사용할 상담권 선택, 상담 전 유의사항 동의,
   예약 정보 확인, 예약 완료
6. **상담 진행** — 예약 정보 확인, 전화 연결(연결 중 → 통화 중), 남은 상담 시간 표시,
   종료 안내, 상담 이력 저장, 후기 작성 유도
7. **내 상담** — 예정/완료/취소 탭, 예약 변경·취소, 상담 기록, 후기 작성 진입
8. **후기 작성** — 별점, 상담 태그 선택, 본문, 등록
9. **마이페이지** — 프로필, 보유 상담권, 찜한 상담사, 결제 내역, 프로필 수정, 고객센터

### 3.2 관리자 백오피스 — `/platform/lumi-admin`

좌측 내비게이션 기반 콘솔. 사용자 앱과 완전히 분리된 프로젝트 엔트리를 갖는다.

1. **대시보드** — 오늘 상담 건수, 예약 현황, 매출 현황, 상담 완료율, 신규 회원 수,
   정산 예정 금액, 실시간 운영 현황(진행 중 상담, 대기, 이슈)
2. **상담사 관리** — 승인 대기 심사(승인/반려), 상담사 목록, 등급 관리, 상담 가능 상태
   변경, 활동 내역, 정산 정보
3. **예약 · 상담 관리** — 예약 현황, 진행 상태, 예약 취소 처리, 노쇼 관리, 상담 기록 조회
4. **정산 관리** — 상담사별 정산 금액 계산, 정산 내역, 지급 완료 처리, 수수료 관리,
   월별 정산 리포트
5. **운영 정책 관리** — 상담권 가격(Lite/Standard/Premium), 상담 시간 정책, 수수료 정책,
   공지사항, 이벤트, FAQ

## 4. 폴더 구조

요청대로 두 서비스의 코드는 모두 `projects/platform/lumi/` 안에 둔다.

```
projects/platform/lumi/
  assets/            공용 사진 (앱 사용)
  lib/               types, mock-data, navigation (앱·관리자 공용)
  styles/lumi.css    디자인 토큰
  components/        screens/ (앱 화면), admin/ (관리자 화면), ui.tsx, bottom-nav.tsx
  src/index.tsx      사용자 앱 엔트리
projects/platform/lumi-admin/
  src/index.tsx      관리자 콘솔 엔트리 (lumi/components/admin 를 렌더링만 한다)
```

워크스페이스 라우트가 `projects/<category>/<project>/src/index`만 렌더링하므로,
관리자 콘솔에 별도 URL을 주려면 `lumi-admin` 프로젝트 엔트리가 반드시 필요하다.
그래서 `lumi-admin/src/index.tsx`는 라우트 등록용 3줄짜리 파일이고, 실제 관리자 UI는
전부 `lumi/components/admin/`에 있다.
