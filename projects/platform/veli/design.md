# VELI — Design Notes

## 아키타입

**A2 — 크리덴셜 월렛** (`ARCHETYPES.md`). 셸 C1(관리자), 팔레트 구성 5(하이컨트라스트).

사용자가 가진 안심번호는 1~3개다. 홈에서 훑을 목록 자체가 없다. 이전 구현은 A1(섹션
스택)으로 6개 섹션을 쌓아 **안심번호 2개 / 이용권 1개 / 통화 3건**을 보여줬고,
두 번째 번호가 `secondary && (...)` 조건부 렌더였다는 점이 "이건 리스트가 아니다"라는
증거였다. 그러면서 제품의 정체성인 QR → CTI 연결 상태 기계(`spec.md` 3.사용자App-3)는
홈 최하단 CTA 하나로 밀려 있었다.

A2로 바꾸면서 홈은 크리덴셜 카드 한 장(복수면 가로 스냅 덱)이 되고, 주 액션(QR 연결)이
카드 바로 아래로 올라왔다. 화면은 1.2화면 안에서 끝난다.

**배제한 후보 2개**

- **A6(오늘 하나)** — 홈에 오늘의 객체 하나 + 주 액션 하나라는 점은 맞지만, 안심번호는
  "오늘"이라는 시간 축이 없다. 상시 유효한 크리덴셜이라 진행 링/게이지가 표현할 상태가
  없다. 습관/복약처럼 매일 리셋되는 도메인의 아키타입이다.
- **A7(캘린더 축)** — 통화 기록이 시간순이라 잠깐 후보였으나, 세로축이 시간인 것은
  기록 화면 하나뿐이고 홈이 아니다. 홈을 캘린더로 만들면 제품이 "통화 로그 앱"이 된다.

**이 아키타입에서 쓰지 않는 부품**

- **하단 탭바** — `components/bottom-nav.tsx` 삭제. `lib/navigation.ts`의 `TabKey` /
  `TAB_OF_VIEW` / `TAB_ROOTS`도 함께 제거했다.
- **`SectionHead`** — 홈에 섹션 반복이 없다. `ui.tsx`에는 시트 안 화면들이 아직 쓰므로
  남아 있지만, **홈에서는 쓰지 않는다.**
- **화면별 `AppBar`** (시트로 뜨는 8개 화면) — 헤더는 `Sheet`가 소유한다. 전체 화면인
  로그인 플로우만 `AppBar`를 계속 쓴다.
- **가로스크롤 카드 로우** — 덱(크리덴셜 카드) 외에 가로 스크롤을 만들지 않는다.

**네비게이션 모델**: 지갑(홈)은 항상 배경에 살아 있고, 나머지는 `components/sheet.tsx`의
드래그 시트로 올라온다(`SHEET_TITLE` / `SHEET_PARENT`). 전체 화면은 둘뿐이다
(`FULLSCREEN_VIEWS`) — 로그인은 아직 지갑이 없는 상태고, 통화 플로우는 실제 통화 중이라
지갑을 덮는 것이 맞다.

## Design read

차량번호와 070 안심번호를 매칭해 실제 연락처를 노출하지 않는 개인정보 보호
유틸리티 프로덕트. 소비자 라이프스타일 앱이 아니라 신뢰가 핵심인 프라이버시/보안
도구이므로, 장식보다 명료함과 상태 전달이 우선이다.

- **디자인시스템**: `apple_compact` — 색상 팔레트, 타이포 스케일, radius 문법(sm=유틸리티
  버튼, lg=카드, pill=액션), 단일 그림자 정책의 최우선 출처.
- **스타일**: `minimalist-ui` — 웜모노크롬 절제, 얇은 1px 보더, 무거운 그림자·그라디언트
  금지, 파스텔 상태색이라는 "톤"의 출처. Apple 원본의 pill 버튼 문법과 충돌하는 지점
  (minimalist는 큰 컨테이너의 rounded-full을 금지)은 CLAUDE.md의 우선순위 규칙에 따라
  디자인시스템(apple_compact)의 radius 문법을 따른다 — 버튼/인풋/칩만 pill, 카드는 12px.

Dials: `DESIGN_VARIANCE 7` / `MOTION_INTENSITY 4` / `VISUAL_DENSITY 3`
(A2 전환으로 변주를 5 → 7로 올렸다 — 탭바 없는 지갑 골격 자체가 워크스페이스에서 유일하다.
밀도는 5 → 3으로 내렸다: 홈이 카드 1장 + 액션 1개로 끝나므로 정보를 채우는 게 아니라
비우는 쪽이 이 아키타입의 요구다. 모션은 통화 연결 상태, QR 스캔 진행처럼 상태를
설명하는 곳에만 쓴다.)

**팔레트 구성 5 — 하이컨트라스트 / 무액센트** (CLAUDE.md `## Color`).

44개 중 41개가 "라이트 뉴트럴 + 액센트 1개"라 색이 전부 달라도 인상이 같아진다.
veli는 그 구성에서 빠진다: 잉크와 종이 두 색 + 상태색만 쓰고, 강조는 크기와 굵기로 한다.

- `apple_compact`의 Action Blue(`#0066cc`)는 **장식용 액센트가 아니라 링크/포커스 링이라는
  기능 역할로만** 남긴다(`--vl-link`, `--vl-focus`). 파란 채움 버튼을 만들지 않는다.
- 팔레트 5에서 "액센트" 역할은 잉크로 접힌다. `styles/veli.css`에서 토큰 이름을 유지한 채
  의미만 바꿔 기존 호출부 119곳이 자동으로 이 규칙을 따르게 했다:
  `--vl-accent: var(--vl-ink)` / `--vl-accent-fg: var(--vl-canvas)` /
  `--vl-accent-soft: var(--vl-surface)`. 주요 CTA는 잉크 솔리드가 된다.
- 순서가 있는 값(라이트/스탠다드/프리미엄 등급, 차트 램프)은 색조가 아니라 잉크 명도
  단계로 간다: `--vl-step-1/2/3`.
- **색을 가진 표면은 크리덴셜 카드 하나뿐이다**(`--vl-card` `#131417` →
  `--vl-card-edge` `#262a31`). A2에서 카드가 곧 제품이므로 화면의 시각적 무게를 그 한 장에
  몰아준다. 다크 모드에서는 카드가 밝은 표면으로 뒤집히므로, 카드 위 요소는 흰색
  하드코딩 대신 `--vl-card-ink` / `--vl-card-muted`를 쓴다.

## Shape

A2 전환으로 반경 사다리에 두 단이 추가됐다. 크리덴셜 카드와 시트는 실물 물성을 가진
표면이라 일반 카드와 같은 반경을 쓸 수 없다.

| 반경 | 쓰는 곳 |
| --- | --- |
| 8px (`rounded.sm`) | 유틸리티 버튼, 인풋 |
| 12px (`rounded.lg`) | 시트 안 일반 카드, 리스트 컨테이너 |
| **14px** | 홈의 주 CTA, 숏컷 타일, 마지막 연결 행 |
| **20px** | 크리덴셜 카드 (`components/credential-card.tsx`) |
| **24px (상단만)** | 시트 (`rounded-t-[24px]`, 하단은 `PhoneFrame`이 클립) |
| full pill | 상태 배지, 칩, 시트 그래버 |

- 그림자는 3단계로 나뉜다. 일반 카드는 여전히 **그림자 없음** + 1px `--vl-border`
  헤어라인이 기본이고, 실제로 떠 있어야 하는 두 표면만 예외다:
  `--vl-shadow-card`(크리덴셜 카드), `--vl-shadow-sheet`(시트, 위쪽으로만 퍼지는 그림자).
- 버튼 active 상태는 `translate-y-[1px]` + `opacity-70` (Motion 절 참고). `apple_compact`의
  `scale(0.95)`를 그대로 쓰지 않는다 — 크리덴셜 카드가 축소되면 실물 카드의 물성이 깨진다.

## Typography

Pretendard 고정(워크스페이스 규칙, SF Pro 대체). 폰트 굵기 사다리는 `apple_compact`
규칙대로 300/400/600/700만 쓰고 500은 쓰지 않는다. 안심번호, 통화 시간, 결제 금액,
날짜는 `.vl-num`으로 tabular-nums를 강제해 자릿수가 흔들리지 않게 한다.

**앞선 프로젝트와 다르게 한 것** (CLAUDE.md `## Motion` → "스케일 복제 금지"):

- **본문 16px / 행간 24px.** 워크스페이스의 13개 프로젝트가 `15/22`를 쓴다. 이 앱은
  화면당 정보량이 적고(크리덴셜 1장 + 액션 1개) 신뢰가 핵심이라, 본문을 한 단 키워
  여백이 남는 쪽을 택했다.
- **캡션 13/20, 마이크로 라벨 11px + `tracking-[0.14em]` 대문자.** 7개 프로젝트가 쓰는
  `Micro 11/14`를 그대로 쓰지 않고, 크리덴셜 카드의 각인된 라벨 느낌을 내기 위해
  자간을 크게 벌린 대문자 마이크로 라벨로 바꿨다.
- **크리덴셜 번호 32px / `tracking-[-0.02em]` / tabular.** 카드가 곧 제품이므로 이 한
  덩어리가 화면에서 가장 큰 타입이다.

## 사진 매핑

이 환경에서는 외부 이미지 소스(picsum 등)에 네트워크로 접근해 내용을 직접 확인할
방법이 없었다 — CLAUDE.md의 "실제로 보고 매핑" 원칙을 지킬 수 없는 상태에서 확인 안 된
사진을 배치하면 실제 실패 사례(무관한 사진 매칭)를 반복하는 것이므로, 검증 불가능한
스톡 사진은 이번 프로젝트에서 의도적으로 쓰지 않는다.

대신 프라이버시/보안 유틸리티 제품이라는 컨셉에 맞춰 **아이콘 · 그라디언트 타일 ·
모노그램**으로 시각적 밀도를 채운다(핀테크/보험 성격의 프로덕트 UI에서 흔한, 사진에
의존하지 않는 정당한 대안):

| 요소 | 표현 | 쓰이는 곳 |
| --- | --- | --- |
| 크리덴셜 카드 (홈, 214px) | `--vl-card` → `--vl-card-edge` 딥 그라디언트 + `ShieldCheck` 워터마크 5% | 홈 덱 (`components/credential-card.tsx`) |
| 안심번호 히어로 (시트 안 축약형) | 같은 `--vl-card-*` 표면, 높이·타입만 축소 | 안심번호 상세 시트 |
| QR 스캔 뷰파인더 | 코너 브래킷 + 스캔 라인 애니메이션(`.vl-scan-line`) | 통화 연결 플로우 |
| CTI 연결 링 펄스 | 아이콘 중심 + 링 펄스(`.vl-pulse-ring`) | 통화 연결 중 |
| 차량 썸네일 | 색상 틴트 타일 + `Car` 아이콘, 차량 색상값을 타일 색으로 반영 | 홈, 마이페이지, 관리자 회원 상세 |
| 프로필 아바타 | 이니셜 모노그램, 원형 | 마이페이지, 관리자 회원 테이블 |
| 이용권 등급 타일 | 등급별 **잉크 명도 단계**(`--vl-step-1/2/3`) 배경 + 아이콘. 팔레트 5에서 색조 램프를 쓰지 않는다 | 이용권, 구매 |

## 기기 프레임 안쪽 규칙

A2에는 하단 탭바가 없다. 엣지에 고정되는 것은 **시트**(`components/sheet.tsx`), 통화 연결
화면의 상단 상태 바, 스티키 CTA 바 셋이고, 전부 **불투명 배경**(`--vl-elevated` 고정값)을
쓴다. 시트는 `absolute inset-0`으로 화면 박스 안쪽에 고정하고 상단만
`rounded-t-[24px]`한다 — 하단은 `PhoneFrame`의 클립이 처리하므로 여기서 다시 둥글리면
코너가 이중으로 파인다. 스크림도 `backdrop-blur` 없이 불투명도만 있는 순수 검정이다.
`backdrop-blur`는 쓰지 않는다 — Chromium에서
`PhoneFrame`의 `overflow-hidden` + `rounded-[50px]` 클리핑을 벗어나 기기 하단/상단
모서리 바깥으로 흰 테두리가 삐져나온다(CLAUDE.md "Portfolio Mobile Output" 항목과 동일
규칙). 반투명 채움(`bg-white/95`류)도 스크롤된 콘텐츠가 비쳐 스크린샷에서 렌더링
버그처럼 보이므로 쓰지 않는다.

## Motion

**앞선 프로젝트와 다르게 한 것** (CLAUDE.md `## Motion` → "스케일 복제 금지"):

- **진입 이징 계열을 바꿨다.** 워크스페이스 CSS 11개가 `cubic-bezier(.16, 1, .3, 1)`
  (expo-out) + `translateY`를 쓴다. veli는 짧은 emphasized-decelerate
  `160ms cubic-bezier(0.2, 0, 0, 1)` + 미세 `scale(0.985)`로 간다 — translateY를 쓰지 않는다.
- **시트는 별도 곡선으로 분리했다.** `280ms cubic-bezier(0.32, 0.72, 0, 1)`(`.vl-sheet-in`).
  "화면이 바뀐다"(`.vl-enter`)와 "시트가 올라온다"가 다르게 읽혀야 A2의 네비게이션 모델이
  이해된다.
- **눌림 피드백을 `active:scale-*`에서 바꿨다.** 워크스페이스가 `0.95`~`0.99`로 갈리는데,
  veli는 `active:translate-y-[1px] active:opacity-70`을 쓴다. 크리덴셜 카드가 축소되면
  실물 카드의 물성이 깨지기 때문이다. (관리자 콘솔은 셸 C1의 별도 규칙이라 그대로 둔다.)
- 지속 애니메이션은 CTI 연결 대기 링 펄스(`.vl-pulse-ring`)와 QR 스캔 라인
  (`.vl-scan-line`) 둘뿐이다 — 둘 다 "지금 연결을 시도하고 있다"는 실제 상태를 설명한다.
- 전부 `prefers-reduced-motion`에서 즉시 정지한다(`styles/veli.css`).

## 관리자 콘솔 — 별도 프로젝트로 분리

관리자 백오피스는 사용자 앱과 완전히 분리된 프로젝트 엔트리 `projects/platform/veli-admin`
(`/platform/veli-admin`)를 갖는다. 실제 화면 코드는 전부 이 프로젝트의
`components/admin/` 안에 있고, `veli-admin/src/index.tsx`는 라우트 등록용 엔트리일
뿐이다(`lumi`/`lumi-admin`과 동일한 워크스페이스 관례). 사용자 앱 쪽에는 관리자 진입점
(내비 항목, 로그인 역할 선택지)을 두지 않는다 — 실제 서비스처럼 주소도 계정도 다르다.
`veli-admin` 프로젝트에는 `styles/`·자체 `design.md`를 두지 않고, 이 문서의 토큰을
그대로 상속한다.

같은 토큰을 쓰되 밀도를 올린다(`VISUAL_DENSITY 7`). 사이드바는 CLAUDE.md 웹 콘솔
구조 베이스라인대로 **잉크 반전(다크)** — `--vl-rail` 계열 전용 토큰을 쓴다(위 팔레트
표와 별개, `components/admin/admin-ui.tsx`에서 정의). 카드 남용 대신 1px 라인 구분과
데이터 테이블, 마스터-디테일 레이아웃을 쓴다. 사진은 쓰지 않는다.

### 셸 레이아웃

- 사이드바 240px, `lg:` 미만에서는 숨기고 `fixed inset-0 z-50 lg:hidden` 드로어(패널
  264px)로 대체.
- 헤더 60px, `sticky top-0 z-30`, `border-b` + 캔버스 배경.
- 본문 `max-w-[1400px] mx-auto`, 패딩 `px-4 py-6 lg:px-8 lg:py-8`.
- 사용자 콘솔은 없음(관리자 전용 단일 콘솔) — 밝은 사이드바 셸을 별도로 두지 않는다.

### 표 밀도 · 컬럼 예산

- `Table` `minWidth` 960px 기준(1440px에서 사이드바 240px + 본문 패딩을 뺀 실제 폭에
  여유를 둔 값). 컬럼 상한 6열.
- 넘칠 것 같으면 보조 정보(가입일시, 최근활동)를 값 아래 보조 줄로 내리고 열 수를
  줄인다. 좌우 높이가 다른 그리드(대시보드 통계 카드 + 사이드 위젯)에는 `items-start`.
