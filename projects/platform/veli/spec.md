# Veli - Product Spec

## 1. Overview
- 플랫폼: Mobile App (사용자) + Web (관리자 백오피스)
- 포지셔닝: 차량 소유자의 개인정보를 보호하기 위한 070 안심번호 기반 차량 연락 관리 플랫폼. 차량번호와 안심번호를 매칭해 실제 휴대전화 번호 노출 없이 긴급 연락이 가능하도록 설계
- 제작 목적: 포트폴리오용 UI 목업, 백엔드 미구현 (CTI 연동, 실제 통화 연결, 본인인증, 결제는 목업 데이터로 표현)

## 2. Non-goals
- 실제 CTI(Call Telephony Integration) 서버 연동 및 실시간 통화 연결
- 실제 휴대폰 본인인증, 카카오/Apple 소셜 로그인 인증 로직
- 실제 PG 결제 처리 및 카드 등록 연동
- 실제 QR 코드 스캔 하드웨어 연동
- 실시간 스팸 탐지 및 신고 처리 로직

## 3. Information Architecture

### 사용자 App
1. 로그인과 회원가입: 휴대폰 번호/이메일 로그인, 간편 로그인(카카오, Apple), 자동 로그인, 아이디/비밀번호 찾기, 휴대폰 본인인증, 약관 동의, 차량번호 등록, 최초 안심번호 발급 안내
2. 홈과 내 안심번호: 발급된 070 안심번호와 상태(사용중/만료예정), 차량번호 확인, 이용권 남은 기간, 최근 통화내역 요약, 긴급 연락 이용 안내, 안심번호 상세정보와 재발급, 번호 연결 상태 확인, QR 주차번호판 보기, 번호 공유/출력
3. 통화 연결 플로우(CTI): 차량 QR 스캔부터 안심번호 확인, CTI 연결 요청, 실제 휴대폰 연결, 연결 상태 표시(연결중/통화중/종료), 연결 실패 안내, 부재중 알림, 통화 종료 후 결과 표시, 스팸 신고와 번호 차단
4. 통화내역: 수신/발신 내역과 날짜별 조회, 통화 시간과 연결 성공 여부, 검색과 기간 필터, 통화 상세정보, 신고 내역 확인, 통화 기록 삭제 요청(개인정보 정책 반영)
5. 이용권과 결제: 현재 이용권 상태와 만료일, 자동 연장 여부, 이용권 변경, 이용권 구매, 카드 등록과 관리, 결제 내역 조회, 영수증 확인, 결제 실패 재시도
6. 프로필과 설정: 회원정보와 차량 정보, 휴대폰 번호 변경, 비밀번호 변경, 알림 설정, 개인정보와 보안 설정, 회원 탈퇴, 고객센터 문의

### 관리자 Web
7. 관리자 대시보드: 전체 회원 수, 발급된 안심번호 현황, 사용중/미사용 번호, 오늘 통화 건수, 신규 가입자, 이용권 판매 현황, CTI 서버 상태, 통화 성공률, 장애 알림, 실시간 운영 현황
8. 회원 관리: 회원 조회와 상세정보, 차량 정보 관리, 안심번호 매핑 정보, 이용권 상태 변경, 계정 정지/해제, 회원 활동 이력
9. 안심번호 관리: 번호 발급과 회수, 번호 재할당과 상태 관리, 번호 검색, CTI 연결 상태 확인, 번호 사용 이력
10. 통화 관리: 전체 통화 이력 조회, 통화 성공/실패 현황, 신고된 통화 확인, 통화 로그 조회, 비정상 이용 탐지, 스팸 차단 관리
11. 결제 및 운영 관리: 이용권 판매 내역과 환불 처리, 결제 실패 관리, 매출 통계, 공지사항과 FAQ, 고객 문의 관리, 이벤트/프로모션 관리, 시스템 로그 확인

## 4. Key Focus
- 차량번호와 안심번호를 매칭해 실제 연락처를 노출하지 않는 개인정보 보호 설계를 사용자 플로우 전면에 강조
- QR 스캔부터 CTI 연결 요청, 실제 연결, 종료까지 이어지는 통화 연결 플로우를 단계별로 시각화해 긴급 연락 편의성 전달
- 번호 발급, 회수, 재할당과 통화 이력, 결제, 회원 상태까지 한 화면에서 관리하는 관리자 백오피스로 운영 효율성 강조
- 이용권 상태와 결제 흐름을 사용자 앱과 관리자 화면 양쪽에서 일관되게 연결해 서비스 운영 신뢰성 전달

## 5. 관리자 분리

관리자 백오피스는 사용자 앱과 완전히 분리된 프로젝트 엔트리 `projects/platform/veli-admin`(`/platform/veli-admin`)를 갖는다. 실제 화면 코드는 이 프로젝트(`projects/platform/veli`)의 `components/admin/` 안에 있고, `veli-admin/src/index.tsx`는 라우트 등록용 엔트리일 뿐이다. 자세한 내용은 `design.md`의 "관리자 콘솔" 절 참고.
